# 为曲线补齐折线同等的端点吸附能力

## 需求概要

绘图白板中的 PolylineTool、PolylineElement 和 SelectTool 已形成端点吸附、绑定持久化、拖动重绑及目标移动联动的完整链路，而 CurveTool 当前直接使用指针坐标，CurveElement 也没有保存 SnapBinding，导致曲线创建和编辑时虽可命中端点交互，却无法像折线一样稳定吸附到图形连接点。需要为曲线补齐起点与终点的吸附预览、绑定数据、序列化、编辑解绑/重绑和被连接图形移动后的同步能力，同时保持现有贝塞尔控制点、箭头样式及旧文档兼容性。

## 任务拆解

- [x] P001: 扩展曲线元素的端点绑定模型与文档持久化 <!-- scope: lib/src/elements/curve_element.dart,lib/src/serialization/canvas_serializer.dart -->
  - 验收要点：CurveElement 可分别保存可空的 startBinding 和 endBinding，并在构造、copyWith、平移、缩放等现有元素变换过程中正确保留绑定信息。
  - 验收要点：曲线 JSON 仅在绑定存在时写入对应字段，反序列化后可还原 elementId 与 anchorId。
  - 验收要点：不含绑定字段的既有曲线文档仍能按未绑定曲线载入，现有控制点、画笔样式、箭头样式、图层和分组字段保持兼容。
- [x] P002: 在曲线绘制流程中接入起终点吸附与预览 <!-- scope: lib/src/tools/curve_tool.dart -->
  - 验收要点：按下、移动和抬起指针时均使用当前画布缩放比例解析附近连接点，曲线起点与终点落在吸附位置并保存各自绑定。
  - 验收要点：绘制预览使用已吸附的端点坐标并同步显示 SnapPreview，完成、取消或无效短距离绘制后清除临时吸附状态和预览。
  - 验收要点：关闭吸附或超出屏幕阈值时曲线继续使用原始世界坐标，行为与现有自由绘制一致。
  - 验收要点：吸附只改变曲线端点来源，现有二次贝塞尔控制点计算、画笔样式和创建后选中行为保持不变。
- [x] P003: 补齐曲线端点编辑、解绑重绑与目标移动联动 <!-- scope: lib/src/tools/select_tool.dart,lib/src/canvas/canvas_controller.dart -->
  - 验收要点：选中曲线后拖动任一端点可显示吸附预览，并将该端点更新到命中的连接点及保存对应绑定，另一端点绑定不受影响。
  - 验收要点：把已绑定端点拖离所有连接点时使用自由坐标并清除该端绑定，端点编辑仍作为单次可撤销操作提交。
  - 验收要点：被绑定的图形连接点因移动或更新而改变位置时，曲线对应端点自动跟随，未受影响的端点、控制点和曲线样式保持不变。
  - 验收要点：端点拖动完成或交互取消后清除 SnapPreview，曲线控制点编辑和折线、直线、箭头的既有端点编辑行为不回退。
- [x] P004: 补充曲线端点吸附与绑定生命周期的自动化覆盖 <!-- scope: test/curve_element_test.dart,test/snap_resolver_test.dart,test/serialization_test.dart -->

  - 验收要点：覆盖选中曲线拖动起点或终点进行吸附、改绑和拖离解绑，并验证撤销可恢复编辑前状态。
  - 验收要点：覆盖绑定目标移动后曲线端点跟随，且另一端点、控制点、箭头及样式数据保持稳定的场景。
  - 验收要点：覆盖曲线绑定 JSON 往返还原和缺少绑定字段的旧数据兼容场景。
