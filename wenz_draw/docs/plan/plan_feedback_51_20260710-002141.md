# 区分思维导图与曲线插入图标

## 需求概要

绘图白板当前曲线工具在工具栏中使用 Icons.timeline，思维导图从特殊组件插入菜单触发。需要为思维导图插入入口提供独立且可识别的图标，确保它不再与曲线插入图标混淆，同时保持原有插入回调和其他组件菜单行为不变。

## 任务拆解

- [x] P001: 为思维导图插入入口配置独立图标 <!-- scope: lib/src/ui/toolbar/toolbar.dart -->
  - 验收要点：曲线工具按钮继续使用当前曲线图标和选中态逻辑，activeTool 为 CurveTool.idValue 时仍能正确高亮。
  - 验收要点：特殊组件插入菜单中的思维导图项显示独立图标，图标不得使用 Icons.timeline，也不得与曲线工具视觉表现一致。
  - 验收要点：点击思维导图菜单项仍只触发 onAddMindmap，不影响便签和计数器菜单项的回调分发。
- [x] P002: 统一特殊组件插入菜单的图标行布局 <!-- scope: lib/src/ui/toolbar/toolbar.dart -->
  - 验收要点：便签、计数器、思维导图菜单项在同一菜单中保持一致的图标加文字排列，文本仍完整显示。
  - 验收要点：菜单项的点击区域、弹出位置和关闭行为与现有 showAnchoredMenu 流程一致。
  - 验收要点：新增图标布局不引入额外业务依赖，也不改变 Toolbar 对外构造参数。
- [x] P003: 补充工具栏插入图标的回归覆盖 <!-- scope: test/toolbar_test.dart -->

  - 验收要点：覆盖思维导图图标与曲线工具图标不同的场景，防止后续再次复用 Icons.timeline。
  - 验收要点：覆盖选择思维导图菜单项后 onAddMindmap 被调用，且曲线工具按钮行为不受影响。

  - 验收要点：从特殊组件菜单插入思维导图、便签和计数器的回调行为保持正确，现有画布工具选择逻辑不回退。
