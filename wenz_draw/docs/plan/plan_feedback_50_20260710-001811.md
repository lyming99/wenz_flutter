# 曲线箭头配置支持

## 需求概要

为现有 CurveElement 补齐与 PolylineElement 相近的末端箭头开关和箭头尺寸能力，覆盖画布渲染、属性面板、序列化、SVG 导出和回归测试，确保曲线可设置箭头且保存加载后不丢失。

## 任务拆解

- [x] P001: 扩展曲线元素的箭头数据与画布渲染 <!-- scope: lib/src/elements/curve_element.dart -->
  - 验收要点：CurveElement 增加 endArrow 和 headSize，并在 copyWith、translate、scaleElement、bounds、hitTest、toJson 中保持语义一致。
  - 验收要点：启用箭头时曲线末端按二次贝塞尔终点切线方向绘制箭头，控制点与终点重合等退化曲线不产生异常或错误方向。
  - 验收要点：未启用箭头的既有曲线渲染、命中测试和缩放行为保持兼容。
- [x] P002: 补齐曲线箭头的控制器和检查器入口 <!-- scope: lib/src/canvas/canvas_controller.dart,lib/src/ui/panels/right_inspector_panel.dart,lib/src/ui/panels/inspector_utils.dart,lib/src/ui/panels/inspector_fields.dart -->
  - 验收要点：选中 CurveElement 时右侧检查器显示箭头开关，并正确回显当前 endArrow 状态。
  - 验收要点：启用箭头后可调整 headSize，关闭箭头后不会破坏已保存尺寸值，重新启用仍可使用上次尺寸。
  - 验收要点：通过控制器更新曲线箭头时只修改 endArrow 和 headSize，并纳入现有历史撤销/重做链路。
- [x] P003: 接入曲线箭头的序列化、Schema 与 SVG 导出 <!-- scope: lib/src/serialization/canvas_serializer.dart,lib/src/serialization/exporters/svg_exporter.dart,docs/canvas_document.schema.json -->
  - 验收要点：CurveElement JSON round-trip 保留 endArrow 和 headSize，旧文档缺少字段时默认加载为无箭头且使用默认箭头尺寸。
  - 验收要点：SVG 导出对带箭头曲线输出曲线路径和末端箭头图形，箭头方向沿曲线终点切线。
  - 验收要点：无箭头曲线的 JSON 和 SVG 输出保持向后兼容，文档 schema 不收紧未知字段兼容策略。
- [x] P004: 补充曲线箭头回归覆盖 <!-- scope: test/serialization_test.dart,test/svg_exporter_test.dart,test/curve_element_test.dart,test/canvas_controller_test.dart -->
  - 验收要点：覆盖曲线启用和关闭箭头、headSize 缩放、边界和命中测试包含箭头影响的模型行为。
  - 验收要点：覆盖 CanvasSerializer 对 curve endArrow 和 headSize 的 round-trip，以及旧 JSON 默认值加载场景。
  - 验收要点：覆盖 SvgExporter 输出带箭头曲线且 SVG 可解析，并验证未启用箭头的曲线不会新增箭头图形。
- [x] P005: 完整验收 <!-- scope: validation -->
  - 验收要点：最终验收命令为 flutter test
  - 验收要点：所有 Flutter 测试通过，覆盖曲线箭头模型、检查器更新入口、序列化恢复和 SVG 导出。
  - 验收要点：在编辑器中选中曲线可开启或关闭末端箭头并调整箭头大小，撤销和重做后状态一致。
  - 验收要点：旧版不含箭头字段的曲线文档仍可加载为无箭头，现有折线、直线和 ArrowElement 行为不回退。
