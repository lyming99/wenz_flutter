# 修复文字编辑悬浮工具栏的焦点与字体样式设置

## 需求概要

当前文字编辑覆盖层已经提供预设颜色、自定义颜色、字号和字体族控件，但悬浮工具栏以固定 320 像素宽度渲染，画布指针处理却按文字元素自身宽度估算工具栏命中区，窄文本或不同缩放下点击工具栏两侧会被误判为点击编辑区外；同时 TextField 失焦会立即提交编辑，打开下拉菜单或颜色对话框时也可能提前结束编辑，导致颜色、字号等样式无法可靠设置。需要统一悬浮栏的布局与命中边界，区分工具栏内部的临时焦点转移和真正离开编辑区，并保证 TextElement 与可编辑图形标签的样式更新、焦点恢复、提交和撤销形成一致链路。

## 任务拆解

- [x] P001: 修复文字编辑悬浮工具栏的命中边界与焦点生命周期 <!-- scope: lib/src/infinite_canvas/infinite_canvas_widget.dart -->
  - 验收要点：悬浮工具栏的可交互命中区域与实际固定宽度、位置和当前画布缩放保持一致；即使文字框很窄，点击预设颜色、调色板、字号或字体族控件的任意可见区域也不会被画布误判为外部点击并结束编辑。
  - 验收要点：TextField 自动聚焦后，打开字号或字体族下拉菜单、打开或关闭自定义颜色对话框等工具栏内部焦点转移不会提前提交编辑；完成选择或取消弹层后输入焦点能够安全返回编辑框，编辑标识和当前文本保持有效。
  - 验收要点：预设颜色、自定义颜色、字号和字体族选择会立即刷新当前 TextElement 或可编辑图形标签的显示与模型样式，连续修改多个样式时悬浮工具栏持续可用并正确反映当前值。
  - 验收要点：只有提交输入或点击文字编辑区域与悬浮工具栏之外的位置才结束编辑；一次编辑会话中的文字与字体样式变更作为一次可撤销修改提交，不会因弹层焦点变化重复提交、遗漏历史记录或访问已释放的 FocusNode。
