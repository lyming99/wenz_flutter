⑥ Electron 设计 Token（Flutter 落地对齐）

容器 Chrome圆角 10px（由 12 收敛）；内边距 6px；描边 outlineVariant 14%；背景 surfaceContainerLow。
阴影 Shadow两层、收敛贴近：0 6px 18px / .12 + 0 1px 4px / .08；等价 elevation ≈ 3（原 6），shadow alpha ≈ 24。
条目 Tile圆角 8px；高 34–38px；内边距 10px × 7px；图标位 20px；图文间距 10px。
层级 Typography标题 13px / 600；描述 11.5px / 400，色用 onSurfaceVariant；按下位移 1px。
选中色 Selection键盘高亮背景 primary 12%（暗色 16%）；标题与图标回退 primary。
悬停 / 按下 Hover悬停 onSurface 5% 中性；按下 primary 18%；均不改变尺寸/圆角。
动效 Motion背景/前景/位移 120ms ease；仅轻量反馈，不改 overlay 定位与尺寸。
约束 Constraints宽度 184–320px；长列表 maxHeight ≈ 320 滚动，保留容器圆角与内边距。
