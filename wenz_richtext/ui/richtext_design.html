3段落对齐与缩进 Alignment & Indent

对应 BlockAttributes.alignment（left / center / right / justify）与 indent（0–8）。

左对齐：设计与代码，本质都是把复杂的问题拆成简单的小块。

居中对齐：行到水穷处，坐看云起时。

右对齐：春风又绿江南岸，明月何时照我还。

两端对齐：富文本编辑器需要同时处理内容结构、样式渲染、手势交互与输入法协作等多个维度的复杂度，每一个细节都决定了最终的书写体验。

缩进 1 级：第一层引用或层级嵌套。

缩进 2 级：更深的层级。

5列表 Lists

对应 BlockType.listItem + listType：无序（unordered）/ 有序（ordered）/ 任务（task，带 checked）。

无序列表 Unordered

  • 需求分析与数据建模
  • 核心编辑能力
    • 文本输入与光标管理
    • 块级结构操作
  • 渲染与手势

有序列表 Ordered

  1. 打开编辑器
  2. 输入内容
  3. 应用样式
  4. 导出 HTML / Markdown / JSON

任务列表 Task

  • 完成文档调研
  • 搭建基础框架
  • 编写单元测试
  • 性能优化与回归

6代码块 Code Block

对应 BlockType.code，带 language 字段；深色背景、等宽字体。

dart// 创建一个加粗的段落
final run = TextRun(
  text: 'Hello, world',
  attributes: TextAttributes(bold: true),
);
final block = TextBlockNode(
  type: BlockType.paragraph,
  content: [run],
);
controller.replaceSelection([block]);
