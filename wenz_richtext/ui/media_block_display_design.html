图片/视频块显示 · Electron 桌面端风格设计稿

覆盖编辑器内图片块（BlockType.image）与视频块（BlockType.video）的「显示」全集：figure chrome（圆角/阴影/最大宽度）、 caption / altText、显示尺寸、状态（空占位 / 加载上传中 / 已加载 / 加载失败）、选中描边、只读裁剪、宽高比处理。 风格与 ui/slash_popup_electron_design.html 同源（扁平克制、弱化高程、两层阴影、紧凑节奏），复用 colorScheme token，全部文案为简体中文。 纯 HTML/CSS 无外部依赖，可直接浏览器打开。本稿为后续 docs/design/media_block_display_spec.md 与 Flutter 落地的唯一视觉来源。

Electron 风格 弱化高程 / 两层阴影 figure chrome 状态全集 明色 + 暗色 token 全中文文案

① 图片块 figure chrome：圆角 / 阴影 / 最大宽度 / caption / altText

figure + figcaption（caption 渲染）

figure 外框：surface 底 + _kMediaCornerRadius（12px）圆角 + _kSurfaceBoxShadow 两层阴影 + ClipRRect。 caption 在 figure 外框下方以 figcaption 呈现，居中、onSurfaceVariant 小号文案、受 maxWidth 约束。 altText 经 Semantics(label:) 朗读（与本块无障碍标签协同）。

空 caption 无占位 + 显示尺寸 showWidth/showHeight

↑ caption 为空时不渲染 figcaption，figure 高度与正文紧凑衔接，不产生额外占位。

空 caption → 不渲染 figcaption、不占空间；showWidth/showHeight 经 SizedBox 包装生效， 行为不变，仅外层 chrome 与 caption 收敛。

② 图片块状态全集（× 默认 / 悬停 / 选中描边 / 只读裁剪）

空占位（待上传 / 无资源）

撑满内容宽度的 figure chrome 空态；图标 + 简体中文提示。_ImageBlockPlaceholder 由 112×72 重做为整宽 chrome。

加载上传中

环形进度 + 中文「上传中」；uploadStatus = uploading。新增态，区别于空占位。

已加载（默认）

MediaResolver 返回非空 widget 胜过任何占位；resolver 注入优先级不变。

加载失败（resolver 抛错 / 无 resolver 回退）

对接 media_resolver.dart 的 catch-and-fallback：无 resolver 或 resolver 抛错 → 失败态。新增态，与空态在视觉/语义上区分。

「已加载」块 × 交互态：默认 / 悬停 / 选中描边 / 只读裁剪

默认 Default

无描边；仅 surface chrome + 弱阴影。

悬停 Hover

onSurface 5% 中性反馈；不改变尺寸/圆角，120ms ease。

选中描边 Selected

_MediaSelectionStroke：在框自身矩形绘 primary 2px 描边，圆角对齐 _kMediaCornerRadius；禁用通用 overlay。

只读裁剪 Readonly

readOnly / canEdit=false：裁剪与圆角不变，仅安全动作（预览），无破坏性 mutation 入口。

加载失败（新增，区别于封面占位）

_VideoBlockContent / _VideoBlockPlaceholder 收敛同一组 media token；新增加载失败回退态（对接 resolver catch-and-fallback）， 保留封面背景、渐变、封面 chip、播放按钮逻辑。宽高比归一（_safeVideoAspectRatio / _videoFrameHeight）与帧回退宽度（_kVideoFrameFallbackWidth）不变。

宽高比处理（aspectRatio 归一 + 帧高夹紧）

21 : 9（宽屏，归一后）
16 : 9（默认）
1 : 1
9 : 16（竖屏，夹紧 1/3~4）

effectiveAspectRatio 经 _safeVideoAspectRatio 夹紧到 [1/3, 4]，帧高 _videoFrameHeight 夹紧在 [96, 420]；宽度优先取编辑器内容宽，无限宽回退 _kVideoFrameFallbackWidth = 320。LayoutBuilder 帧约束与溢出夹紧语义不变。

④ 明色 + 暗色双 token 版本

明色 Light

surface #fffdfb；选中描边 primary 2px；caption onSurfaceVariant。

暗色 Dark

surface #1b1d23；primary 偏亮 #7a93f5；阴影加深；caption onSurfaceVariant。

暗色版仅替换 colorScheme token，圆角 / 阴影层数 / 描边线宽 / caption 布局与明色一致；选中描边口径统一（_MediaSelectionStroke primary 2px）， 只读裁剪口径统一。视频 frame 在明暗两色下均为黑色（Colors.black），仅 chrome 外框与 caption 文字随主题切换。

⑤ 设计 Token 参数面板（逐项映射 Flutter 常量名）

figure 圆角_kMediaCornerRadius = 12.0；图片/视频共享同一圆角入口。
figure 阴影_kSurfaceBoxShadow：两层弱阴影（alpha 8% / 6%，blur 3 / 2，offset 0,1），等价弱高程。
垂直外边距_kMediaBlockMarginVertical = 16 × 1.2 = 19.2；块上下各 9.6。
最大宽度figure maxWidth 受编辑器内容宽约束；建议正文 ≤ 720px，无限宽回退内容宽。
播放按钮尺寸_kVideoPlayButtonSize = 64；图标 _kVideoPlayIconSize = 24（按帧宽 _videoPlayButtonSizeFor 缩放）。
视频帧回退宽_kVideoFrameFallbackWidth = 320；帧高夹紧 [96, 420]，宽高比夹紧 [1/3, 4]。
选中描边_MediaSelectionStroke：primary 2px，圆角 _kMediaCornerRadius；框自身矩形，非通用 overlay。
悬停 / 按下悬停 onSurface 5%；按下 primary 18%；不改尺寸/圆角。
caption（仅图片）figure 下方 figcaption：居中、onSurfaceVariant、小号（~12.5px）、受 maxWidth 约束；空 caption 不占空间。
altText（无障碍）图片 altText 经 Semantics(label:) 朗读，与 _imageAccessibleLabel 协同。
占位 chrome图片占位底 surfaceContainerHighest + outlineVariant，圆角/阴影对齐 figure token；撑满内容宽。
动效 Motion悬停/按下/描边 120ms ease；仅轻量反馈，不改定位与几何。
