# 开发计划：反馈 #3 富文本选择、代码高亮与附件渲染优化

## 来源
- 类型：用户反馈
- 编号：#3
- 生成时间：2026-06-25 01:49:05
- 原始反馈：
  1. 将正文切换为引用后，引用内容无法被选择，重新输入文字后恢复正常。
  2. 代码没有实现高亮效果。
  3. 将界面的 tooltip 改成中文。
  4. 图片不需要显示标题，要最小化渲染，选中状态（单独选中图片状态）要在图片上方显示悬浮操作菜单即可。
  5. 附件组件，只显示图片和文件名称、操作菜单。

## 问题理解
- 引用选择问题发生在“正文块切换为引用块”之后，而重新输入文字后恢复，说明转换后的块渲染、选择注册、命中测试或文本 offset 映射可能未及时刷新。
- 代码高亮属于渲染能力缺失，需要明确默认支持语言、无法识别语言的降级策略，以及选区、复制、编辑体验不被高亮层破坏。
- tooltip 本地化属于界面文案规范，需要覆盖工具栏、悬浮菜单、图片/附件操作、表格/代码等可见交互入口。
- 图片与附件需要弱化信息展示，仅保留必要内容与操作入口；图片单独选中时只在图片上方显示悬浮操作菜单，不在正文流中显示标题或多余控件。

## 任务计划
- [x] P001: 复现并定义反馈边界 <!-- scope: unknown -->
  - 验收要点：构造最小文档，覆盖正文切换引用、直接输入引用、代码块、图片块、附件块和所有已知 tooltip 入口。
  - 验收要点：记录“正文切换为引用后不可选择”与“重新输入后恢复”的稳定复现步骤、实际选区状态和预期选区状态。
  - 验收要点：梳理当前图片与附件组件展示元素，明确哪些标题、说明、按钮或占位信息需要移除或改为悬浮操作。

- [x] P002: 修复引用转换后的选择能力 <!-- scope: unknown -->
  - 验收要点：普通段落切换为引用后，引用内文字可立即点击定位、拖拽选择、Shift+方向键扩展选择和复制。
  - 验收要点：引用块内的普通文本、内联样式、emoji、mention、链接等内容均保持可选择，不因块类型切换丢失选择注册。
  - 验收要点：切换引用、取消引用、撤销/重做、保存后重载等场景中，引用文本选择行为稳定且不需要重新输入触发刷新。
  - 验收要点：修复不回退普通段落、todo、info/callout、表格单元格和代码块的既有选择能力。

- [x] P003: 实现代码块语法高亮 <!-- scope: unknown -->
  - 验收要点：代码块根据语言标识渲染关键字、字符串、注释、数字、类型等基础 token 高亮，至少覆盖 Dart/JavaScript/JSON/Markdown 或项目约定的默认语言集合。
  - 验收要点：无语言标识或不支持语言时降级为等宽纯文本渲染，不报错、不丢内容。
  - 验收要点：高亮渲染不影响代码块内光标定位、拖拽选区、键盘选择、复制文本和滚动布局。
  - 验收要点：高亮颜色适配明暗主题或当前 `ColorScheme`，避免低对比度、硬编码导致的不可读问题。

- [x] P004: 将界面 tooltip 文案中文化 <!-- scope: unknown -->
  - 验收要点：工具栏、浮动菜单、图片操作、附件操作、表格操作、代码块操作等所有用户可见 tooltip 使用中文文案。
  - 验收要点：中文 tooltip 语义准确、短句一致，不混用英文、拼音或调试占位文案。
  - 验收要点：tooltip 修改不改变按钮行为、快捷键、可访问性 label 和现有布局尺寸的稳定性。
  - 验收要点：新增或更新文案集中管理位置，避免同一操作在不同组件中出现多套不一致翻译。

- [x] P005: 最小化图片块渲染与选中菜单 <!-- scope: unknown -->
  - 验收要点：图片块默认只展示图片本体和必要的加载/失败状态，不再显示标题、文件名、说明或固定操作栏。
  - 验收要点：图片未选中时不占用额外正文空间，视觉上保持最小化渲染，并与相邻段落保持合理间距。
  - 验收要点：单独选中图片时，在图片上方显示悬浮操作菜单，菜单位置随滚动和布局变化保持贴近图片顶部且不遮挡主要内容。
  - 验收要点：图片悬浮菜单包含现有必要操作入口，点击操作不误触正文选区，不影响图片块选中态、删除、复制等行为。

- [x] P006: 简化附件组件展示 <!-- scope: unknown -->
  - 验收要点：附件组件只显示文件图标或缩略图、文件名称和操作菜单，不显示标题、描述、大小等非必要信息，除非已有业务明确要求。
  - 验收要点：长文件名能够省略显示或换行策略明确，不撑破编辑器宽度，不影响菜单点击区域。
  - 验收要点：附件操作菜单保留下载、预览、删除或项目既有必要操作，未选中与选中状态均可稳定触发。
  - 验收要点：图片附件与普通文件附件展示规则一致，避免与图片块的最小化渲染产生重复标题或双操作栏。

- [x] P007: 补充自动化与手工回归验证 <!-- scope: unknown -->
  - 验收要点：新增或更新 widget 测试，覆盖正文切换引用后立即选择、引用撤销/重做后选择、代码高亮降级、图片单独选中菜单、附件简化展示。
  - 验收要点：新增或更新 tooltip 文案测试或快照检查，确保主要操作入口显示中文 tooltip。
  - 验收要点：执行 `flutter analyze`、相关 widget 测试和必要的选择器/渲染回归测试；失败项需明确是否与本次改动相关。
  - 验收要点：记录验证命令、验证结果、未覆盖风险和后续建议，便于后续开发者接续处理。

## 总体验收标准
- 所有任务 checkbox 均完成，且每个任务的验收要点都有明确结论。
- 正文切换为引用后，引用内容无需重新输入即可立即被点击定位、拖拽选择、键盘扩展选择和复制。
- 代码块具备可识别语言的语法高亮效果，不支持语言时安全降级，并保持编辑与选择体验稳定。
- 用户可见 tooltip 全部完成中文化，同一操作文案一致且不影响原有交互。
- 图片块默认最小化渲染，不显示标题；单独选中图片时仅在图片上方出现悬浮操作菜单。
- 附件组件仅展示图标/缩略图、文件名称和操作菜单，布局紧凑且操作可用。
- 相关自动化测试、静态检查和必要手工验证通过；若存在非本次变更导致的失败，需在进度区记录失败命令、原因和处理建议。
