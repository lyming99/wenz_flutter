## 原始内容
要支持快捷键配置

## 需求理解
- 当前编辑器已有 `EditorShortcutManager` 将键盘事件解析为 `EditorShortcutIntent`，但默认映射基本写死，调用方难以按业务场景调整。
- 本需求目标是提供稳定的快捷键配置能力，让业务侧可以覆盖、追加、禁用或透传部分快捷键，同时保持未配置时的默认行为不变。
- 配置应兼容 Flutter 桌面/Web/移动外接键盘场景，处理 Ctrl/Cmd 主修饰键、Shift/Alt/Meta 组合、KeyDown/KeyRepeat、IME 输入、只读态、查找替换、斜杆菜单和代码块 Tab 等优先级关系。
- 实现应优先扩展现有 `lib/src/input/shortcut_manager.dart` 与 `WenzRichTextEditor` 入参，不绕过现有命令、选区、剪贴板和输入系统。

## 总体验收标准
- 未配置快捷键时，现有测试应继续通过，编辑器默认快捷键行为与需求前保持一致。
- 调用方可以通过公开 API 配置快捷键，包括覆盖默认绑定、追加新绑定、禁用默认绑定、将指定组合键返回 `passThrough`。
- 配置能力不破坏现有输入系统：IME composing、只读态、剪贴板、撤销/重做、选区扩展、查找/替换、斜杆菜单、代码块 Tab 均按预期优先级工作。
- 快捷键配置具备明确冲突策略和自动化测试覆盖，异常或无效配置不会导致编辑器崩溃或产生不可预测行为。
- 文档和示例足以让包外使用者完成常见业务配置，并清楚知道哪些场景应通过宿主 `Focus`/`Actions` 处理。
