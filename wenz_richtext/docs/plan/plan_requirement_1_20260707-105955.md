# 编辑器默认桌面工具栏改为左对齐单行水平滚动

## 需求概要

当前默认桌面工具栏在 lib/src/widgets/default_desktop_toolbar.dart 中将主按钮组放入 Wrap，窄宽度时会自动换行，并把无序列表、对齐和插入菜单作为 trailing 区域固定在右侧。需求要求默认工具栏所有图标左对齐、不自动换行，内容超出时通过水平滚动查看。因此本计划聚焦调整桌面默认工具栏布局为单行、左起排列、水平滚动，并同步更新桌面工具栏 widget 测试。移动端默认工具栏主轨道已是水平 ListView，不作为本次主要改动范围。
