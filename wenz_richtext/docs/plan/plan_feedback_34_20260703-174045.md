## 背景与现状

项目是 Flutter 富文本编辑器包，尾部空白点击由 `SelectionGestureOverlay` 判断单击位置是否超过 `BlockGeometryRegistry.contentExtent()`，再回调 `WenzRichTextEditor._handleTapBeyondContent` 处理。当前编辑器实现已经支持尾部图片、表格等非文本块后方点击空白追加空段落，相关 widget 测试已有 `tap below a trailing image appends a paragraph` 和 `tap below a trailing table appends a paragraph`。

当前缺口集中在 `lib/src/widgets/wenz_rich_text_editor.dart`：`_handleTapBeyondContent` 在最后一个块是 `TextBlockNode` 或 `CodeBlockNode` 时直接返回 `false`，因此文档以代码块结尾时，点击代码块下方的编辑器空白区域不会追加普通文本行。代码块本身是可编辑文本承载块，点击代码块内部仍应定位到代码文本；本次只处理代码块视觉内容下方、文档内容区域之外的空白点击。

## 目标

- 当文档最后一个块是 `CodeBlockNode` 时，单击代码块下方空白区域追加一个空段落，并把光标放入该段落。
- 保持普通文本块结尾的现有行为，不在段落下方重复追加空段落。
- 保持只读模式、空文档、代码块内部点击、拖拽选择、双击/三击选择等既有交互不变。
- 用 widget 回归测试覆盖尾部代码块路径，并复用现有尾部图片/表格测试模式。
