## 原始内容
菜单样式、悬浮工具栏，要先通过html做个设计稿，然后按照设计稿样式进行优化；简约风；

## 需求理解
- 本需求目标是统一编辑器内菜单与悬浮工具栏的视觉语言，先产出可独立预览的 HTML 设计稿，再按设计稿落地到 Flutter 组件。
- 设计风格定位为简约风：低噪声、轻阴影、少色彩、清晰层级、紧凑但不拥挤，避免复杂装饰和过度拟物。
- 影响范围预计覆盖 slash 菜单、block 操作菜单、表格/代码等悬浮工具栏，以及相关 golden 或 widget 测试。
- 优化应保持现有功能、快捷键、焦点、命中区域、只读态、禁用态和可访问性语义不退化。

## 总体验收标准
- 设计流程符合“先 HTML 设计稿、后 Flutter 样式优化”的顺序，HTML 设计稿位于 `ui/menu_toolbar_minimal_design.html` 并能作为视觉对照来源。
- 菜单和悬浮工具栏整体呈现简约风，视觉层级清晰，状态反馈明确，控件密度合理，未引入明显视觉噪声。
- slash 菜单、block 操作菜单、表格悬浮工具栏和编辑器内通用悬浮按钮组在核心状态下与设计稿一致或有明确实现差异说明。
- 优化不改变文档数据结构、命令语义、插件注册机制、选区逻辑、只读权限和已有编辑行为。
- 最终验收命令范围：`flutter analyze` 覆盖静态检查；`flutter test test/widgets/slash_menu_overlay_test.dart`、`flutter test test/widgets/wenz_rich_text_editor_test.dart`、`flutter test test/widgets/editor_golden_test.dart` 覆盖相关交互和视觉回归。
