## 原始需求
代码块要按照设计稿风格，左边要支持显示语言类型，右侧是复制内容

## 需求理解
- 当前编辑器已支持 `CodeBlockNode.language`、代码块渲染、语法高亮、行号、横向滚动正文、语言切换和复制代码；本需求聚焦代码块顶部/外观按设计稿重排。
- 目标视觉结构为代码块左侧展示语言类型，右侧提供复制内容入口；语言展示应来自 `CodeBlockNode.language`，为空时需要有稳定的默认展示或占位策略。
- 复制入口应复制代码内容本身，不包含语言标签、行号或 UI 文案，并保持现有剪贴板、只读/编辑模式、选区和代码编辑行为不回归。
- 实现应优先限制在代码块默认渲染层，不引入模型字段变化，不影响 Markdown/HTML/JSON 编解码结果。
