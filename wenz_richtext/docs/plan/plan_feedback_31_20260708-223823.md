# 支持 Mermaid 非预览模式源码编辑

## 需求概要

反馈 #31 要求 Mermaid 在非预览模式下支持编辑代码。当前项目在启用 `enableMermaidDiagrams` 后由 `MermaidDiagramPlugin` 拦截语言为 mermaid 的 `CodeBlockNode`，并用 `MermaidCodeBlockWidget` 替换普通代码块渲染；该 widget 默认 source 模式只渲染只读 `_MermaidSourceView`，因此失去了普通代码块的选择、输入、IME、撤销和粘贴编辑管线。计划需要让 Mermaid source 模式复用或桥接普通代码块的可编辑源码 surface，同时保留 preview 模式的纯 Flutter Mermaid 图表渲染、切换、错误恢复和非 Mermaid 代码块委托行为。

## 任务拆解

- [x] P001: 打通 Mermaid source 模式与普通代码块编辑管线 <!-- scope: lib/src/plugins/mermaid_diagram_plugin.dart,lib/src/widgets/mermaid/mermaid_code_block_widget.dart,lib/src/widgets/block_renderer_registry.dart -->
  - 验收要点：Mermaid 插件在拦截 mermaid 代码块时，将捕获到的原始代码块 renderer 或等价的可编辑源码 builder 传入 Mermaid 渲染路径，source 模式不再只显示只读 `_MermaidSourceView`。
  - 验收要点：非预览/source 模式下，点击 Mermaid 源码可以按普通代码块规则定位 caret，键盘输入、删除、换行、粘贴和 IME composition 会通过现有 controller/command 管线更新同一个 `CodeBlockNode.code`。
  - 验收要点：源码行号仍是展示层能力，不进入 `CodeBlockNode`、codec、复制文本或 offset mapping；选择范围、caret、find highlight 和组合输入下划线与普通代码块保持一致。
  - 验收要点：readOnly 或不可编辑状态下，Mermaid source 模式允许查看/选择但不产生代码变更；非 mermaid 代码块继续委托给原始 renderer，不受插件影响。
- [x] P002: 调整 Mermaid 源码与预览切换 UI 状态 <!-- scope: lib/src/widgets/mermaid/mermaid_code_block_widget.dart,lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：Mermaid source 模式提供可访问的预览切换入口，同时不遮挡普通代码块已有的语言切换、复制、选择和行号区域交互。
  - 验收要点：source 模式和 preview 模式的容器 chrome、边框、间距与行级拖拽 handle 对齐，不出现嵌套重复代码块外框或工具栏错位。
  - 验收要点：preview 模式继续使用 `InteractiveViewer` 与 `MermaidDiagram`，保留平移、缩放、焦点和 16:9 稳定视口行为；从 preview 返回 source 后源码仍可编辑。
  - 验收要点：当源码模式中将语言从 mermaid 改为其他语言时，下一次渲染回到普通代码块路径；大小写、空白、`language-mermaid`、`{.mermaid}` 等 Mermaid 标记仍能被识别。
- [x] P003: 同步编辑后的 Mermaid 预览渲染 <!-- scope: lib/src/widgets/mermaid/mermaid_code_block_widget.dart,lib/src/plugins/mermaid_diagram_plugin.dart -->
  - 验收要点：源码编辑导致 `CodeBlockNode.code` 变化后，会使 Mermaid preview 缓存失效，并按 `MermaidDiagramConfig.debounce` 基于最新源码重新解析和布局。
  - 验收要点：连续快速编辑后切换到 preview，只展示最新源码对应的图表、加载态或错误态，不显示旧图、旧错误或过期解析结果。
  - 验收要点：空源码、语法错误和不支持图表类型仍显示现有反馈；通过查看源码返回 source 后修复代码，再切回 preview 可以正常恢复渲染。
  - 验收要点：纯 Flutter preview 路径继续不调用 legacy `MermaidRenderer.renderSvg`，自定义 renderer 注入仅保持兼容性。
- [x] P004: 补充 Mermaid 源码编辑测试覆盖 <!-- scope: test/widgets/mermaid_code_block_test.dart,test/mermaid/mermaid_diagram_plugin_test.dart,test/integration/wenz_editor_bootstrap_test.dart,test/widgets/wenz_rich_text_editor_test.dart -->

  - 验收要点：测试覆盖 readOnly 或不可编辑场景下 Mermaid source 模式不会修改文档。
