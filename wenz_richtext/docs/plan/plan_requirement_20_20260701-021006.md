## 项目分析
- `wenz_richtext` 已具备完整且经过验证的自定义组件接入能力（README「扩展点与派生控制器」、`docs/integration_guide.md` §5/§10、`example/lib/main.dart` 中的 CRM 卡片 embed 均已落地），本需求的本质是「把这套能力沉淀成明确的接口设计方案 + 以流程图为样本的具体实现方案」，而不是从零造接口。
- 接入契约由四层组成，均已在源码中稳定：
  - 数据层：`lib/src/core/model/block_node.dart` 的 `BlockEmbedNode({id, embedType, data, fallbackText, attributes})`，`type == BlockType.embed`，`normalizedEmbedType`/`displayText` 提供归一化与纯文本降级；`toJson`/`fromJson` 自动往返，`lib/src/core/schema/document_schema.dart` 的 `_normalizeBlockEmbed` 在文档归一化时保留 `data`。
  - 渲染层：`lib/src/widgets/block_renderer_registry.dart` 的 `BlockRendererRegistry.registerEmbed(embedType, builder)`；`lib/src/integration/wenz_editor_bootstrap.dart` 先 `installDefaultRenderers`，再依次合并插件与宿主 `blockEmbedRenderers`（顺序：默认 → 插件 → 宿主，宿主覆盖插件）。builder 收到 `BlockRenderContext`（含 block、selection、canEdit、mediaResolver、inlineEmbedRenderer、onObjectBlockAction 等），业务 widget 用 `WenzObjectBlockSurface` 包裹即可获得与内置 image/video/file 一致的选区、光标、几何与块把手；未注册时回退到通用 `BlockType.embed` renderer。
  - 插入层：`lib/src/controller/wenz_rich_text_controller.dart` 的 `insertBlockEmbed(...)`（底层 `insertBlocks`/`InsertBlocksCommand`，受权限闸门），配合 `SlashMenuItem`、`WenzToolbarItem`（`lib/src/controller/slash_menu_controller.dart`、`toolbar_controller.dart`）提供命令面板与工具栏入口。
  - 插件层：`lib/src/plugins/editor_plugin.dart` 的 `WenzRichTextPlugin.install(WenzPluginContext)`，可在一次装配中注册 renderer / slash item / toolbar item / 命令 / 快捷键 / 粘贴转换。
- 已识别的接口缺口：自定义 embed 目前「能插、能渲染、能持久化」，但缺少与 `updateImageBlock`/`updateVideoBlock`/`updateFileBlock`（`wenz_rich_text_controller.dart` 已有的 typed media helper）对称的通用「就地更新 data」helper，业务侧只能退回到低层 `replaceBlocks`（`wenz_rich_text_controller.dart:1307`）。对流程图这类需要原地拖拽改节点坐标的场景，补一个 `updateBlockEmbed` 能让接入面闭合、对称。
- 结论：最优工程方案是「写一份聚焦的自定义组件接入指南（接口设计方案）+ 补齐 `updateBlockEmbed` + 在 example 以流程图为样本产出可运行的具体实现（配置注入路径 + 可复用插件路径）」，复用既有四层契约，不改动核心数据模型 / codec / 命令体系结构。

## 接口设计方案

### 接入选型：三种接入位
| 业务形态 | 推荐接入位 | 数据落点 | 适用示例 |
| --- | --- | --- | --- |
| 整行级业务块（块级对象） | `blockEmbedRenderers: Map<String, BlockRendererBuilder>` + `BlockEmbedNode` | `embedType` + `data` | 流程图、CRM 卡片、审批单、看板卡片 |
| 行内片段 | `inlineEmbedRenderers: Map<String, InlineEmbedSpanBuilder>` + `InlineEmbed` | `embedType` + `data` | @mention chip、状态标签、inline 图标 |
| 改写内置块外观 | `blockRenderers: Map<BlockType, BlockRendererBuilder>` | 复用既有 `BlockType` 模型 | 自定义图片解码、自定义代码块 |

流程图属于「块级对象」，走 `BlockEmbedNode` + `blockEmbedRenderers` 路径。

### 四层契约（流程图映射）
1. **数据层**：`BlockEmbedNode(embedType: 'flowchart', data: {...}, fallbackText: '流程图')`。`data` 为 JSON 友好结构，rich JSON 自动持久化；HTML/Markdown/纯文本经 `displayText`/`fallbackText` 降级。
2. **渲染层**：`BlockRendererBuilder` 返回 `WenzObjectBlockSurface(child: FlowchartView(...))`。`BlockRenderContext` 提供 `block`、`selection`、`canEdit`、`mediaResolver`、`onObjectBlockAction` 等；只读态按 `canEdit` 收敛交互。
3. **插入层**：`controller.insertBlockEmbed(blockId, embedType: 'flowchart', data: {...}, fallbackText: '流程图')`，并经 `SlashMenuItem`（`/流程图`）与 `WenzToolbarItem` 暴露入口；全部走命令层、受权限闸门。
4. **更新层**：`controller.updateBlockEmbed(blockId, data: {...})`（本计划新增，对齐 typed media helper），底层 `replaceBlocks`，原地编辑（拖拽节点）通过它回写。
5. **复用层（可选）**：封装为 `FlowchartPlugin extends WenzRichTextPlugin`，`install` 内一次性注册 renderer/slash/toolbar，多宿主共享。

### 合并顺序与覆盖语义
bootstrap 装配顺序固定为「默认能力 → 插件贡献 → 宿主配置」（见 `wenz_editor_bootstrap.dart:95-139`），因此同 `embedType`/同 id 冲突时宿主覆盖插件、插件覆盖默认值；粘贴转换是顺序 pipeline（返回 `null` 才交给下一级）。

## 具体实现方案（流程图样本）
- **数据契约**：`data = {nodes: [{id,label,x,y,kind}], edges: [{from,to,label?}], direction: 'TB'|'LR', version: 1}`；`fallbackText = '流程图'`；`displayText` 读取 `title`/`label`/`name`。
- **renderer**：`FlowchartView`（`CustomPainter` + `Stack` 定位节点 + 手势拖拽），用 `WenzObjectBlockSurface` 包裹，仅当 `renderContext.canEdit` 时允许拖拽改坐标。
- **回写**：拖拽结束 `onChanged` → `controller.updateBlockEmbed(block.id, data: 更新后的 map)`（P002），命令层记录历史、触发 `onChanged`/`onCommandExecuted`。
- **插入入口**：`SlashMenuItem(id:'flowchart', title:'流程图', keywords:['flowchart','图'])` 与 `WenzToolbarItem`，`action` 调用 `insertBlockEmbed`。
- **持久化验证**：`toJson()` → `loadJson()` 后 `data`（含节点/边/坐标）完整保留；`toMarkdown()`/`toPlainText()` 降级为 `fallbackText`/`displayText`。
- **两条接入路径**：
  - 一次性配置：宿主在 `WenzEditorConfiguration` 直接填 `blockEmbedRenderers` + `slashMenuItems` + `toolbarItems`。
  - 可复用插件：`plugins: [FlowchartPlugin()]`，install 内集中注册；example 同时演示二者。
