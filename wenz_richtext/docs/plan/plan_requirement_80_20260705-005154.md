# 工具栏支持插入图片和视频

## 需求概要

基于现有 ImageBlockNode、VideoBlockNode、WenzRichTextController.insertImage/insertVideo、ToolbarController 和 WenzDefaultDesktopToolbar 的媒体块能力，补齐默认工具栏中的图片与视频插入入口、宿主回调接入、插入位置语义和测试覆盖。图片/视频资源选择继续由宿主回调负责，工具栏负责按钮展示、启用禁用状态、上下文透传，并最终调用控制器插入对应媒体块。
