## 原始内容
空白行要支持点击

## 需求理解
- “空白行”指编辑器中可见但文本长度为 0 的文本承载区域，例如空段落、空列表项、空引用/标题文本面，以及表格单元格内的空文本行；它们应像普通文本行一样可以被点击并放置光标。
- 当前点击链路主要由 `SelectionGestureOverlay` 接收指针事件，再通过 `BlockGeometryRegistry.positionFromGlobalOffset` 映射到 `DocumentPosition`，具体文本 offset 由 `_TextSelectionSurface` 和 `TextLayoutService` 计算。
- 需求目标是点击空白行的可见行高区域时，编辑器获得焦点并把选区折叠到对应 block/path 的 offset `0`，而不是命中相邻 block、落到文档末尾、触发“内容区域外点击”或无响应。
- 实现应优先修正命中区域和空文本 offset/caret fallback，不改变文档模型、序列化格式、输入命令语义或非空文本的点击/拖拽选择行为。
- 需重点保护列表 marker、todo checkbox、标题折叠按钮、表格单元格 padding、隐藏折叠内容、滚动条 gutter、选择排除区和 block 间隙点击的既有行为。

## 总体验收标准
- 计划中的所有 checkbox 任务完成，且每个任务的验收要点均有对应实现、测试或记录说明。
- 用户点击任意可见空白文本行时，编辑器获得焦点并把 caret 放到该空白行对应位置，选区折叠到正确 block/path 的 offset `0`。
- 空段落、空列表项、空 todo 列表项、空引用/标题文本区域和表格单元格内空文本均支持点击；非文本对象块继续保持既有对象选择行为。
- 空白行点击不再误命中上下相邻 block、文档末尾或内容区域外处理逻辑，也不会抢占 checkbox、折叠按钮、列表 marker、滚动条 gutter、block handle 和选择排除区事件。
- 非空文本点击、拖拽选择、双击选词、三击选块、block 间隙点击、表格 padding 点击、隐藏折叠内容、组合输入、查找高亮、选区绘制和 caret 绘制行为不回归。
- 相关定向测试、`flutter analyze` 和全量 `flutter test` 通过，或已清晰记录与本需求无关的环境/历史失败。
