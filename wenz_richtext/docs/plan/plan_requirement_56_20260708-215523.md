# wenz_richtext 支持拖拽图片到编辑器内部

## 需求概要

在现有 Flutter 富文本编辑器中补齐外部图片拖拽插入能力。项目已具备 ExternalImageInput、ExternalImageStore、ClipboardService.parseExternalImages、WenzRichTextController.pasteExternalImages、图片块模型与 super_drag_and_drop 依赖，实施应复用这条外部图片输入管线：在 WenzRichTextEditor 桌面编辑区域接入外部 DropRegion，把拖拽的 file:// 图片或图片 bytes 转为 ExternalImageInput，经 store 校验/落盘后插入 ImageBlockNode。重点覆盖多个图片顺序插入、非图片拒绝、只读/权限/配置禁用不插入、drop overlay 生命周期、移动端不挂载 DropRegion，以及内部块排序拖拽不受影响。

  - 验收要点：WenzRichTextEditor 在可编辑、非只读、enableExternalImageInput=true、enableExternalDragDrop=true 且 controller.canEdit=true 时，为桌面编辑区域挂载外部图片 drop 目标
  - 验收要点：DropRegion 的启用开关通过 WenzEditorConfiguration 透传到 WenzEditorBootstrap，再传入 WenzRichTextEditor，默认不破坏现有调用方
  - 验收要点：只读、comment/read 权限、enableExternalImageInput=false 或 enableExternalDragDrop=false 时不接受外部图片拖拽，也不会调用外部图片 store
  - 验收要点：移动端或触屏紧凑布局不挂载外部 DropRegion，避免影响现有文字选择和触屏手势

  - 验收要点：无法读取、空数据、目录、远程 URI、非图片扩展名或不支持 MIME 的候选项被安全忽略，不抛异常打断编辑器
  - 验收要点：同一次拖拽里的多个图片候选保持平台提供顺序，并只把可插入图片继续交给后续存储/插入流程

  - 验收要点：拖拽图片替换已选中的对象块时不会留下旧对象块，多图片拖拽按顺序插入多个图片块
