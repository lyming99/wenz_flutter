# Mermaid 支持思维导图

## 需求概要

反馈 #46 要求 Mermaid 增加思维导图支持。当前项目的 Mermaid 能力已拆分为 parser、model、layout、painter、widget 和插件预览层，已支持 flowchart、sequence、pie、gantt、timeline、kanban、radar、xychart 等类型，但 `MermaidParser` 尚未识别 `mindmap`，`DiagramType` 也没有思维导图类型，`MermaidDiagram` 与 `MermaidCodeBlockWidget` 的布局/绘制分发链路无法渲染该语法。计划新增 Mindmap 数据模型与解析器，支持 Mermaid `mindmap` 根节点和基于缩进的层级节点，补齐布局、Painter、公共导出和编辑器代码块预览接入，使思维导图在纯 Dart/Flutter Mermaid 渲染路径中可解析、可预览、可交互缩放。

## 任务拆解

- [x] P001: 扩展 Mermaid 思维导图数据模型与类型识别 <!-- scope: lib/src/mermaid/models/diagram.dart,lib/src/mermaid/models/mindmap.dart,lib/src/mermaid/parser/mermaid_parser.dart -->
  - 验收要点：`DiagramType` 新增 mindmap 类型，`MermaidParser.detectDiagramType` 能识别以 `mindmap` 开头的 Mermaid 源码。
  - 验收要点：`MermaidParseResult` 能携带思维导图专用数据，且不影响现有 flowchart、sequence、pie、gantt、timeline、kanban、radar、xychart 的返回结构。
  - 验收要点：解析失败描述中包含 mindmap 的稳定错误信息，空内容、未知语法和既有不支持类型的提示保持原行为。
  - 验收要点：新增模型能够表达根节点、父子层级、节点标签、节点 id、深度和常见节点外观信息，便于后续布局与绘制使用。
- [x] P002: 实现 Mermaid mindmap 语法解析 <!-- scope: lib/src/mermaid/parser/mindmap_parser.dart,lib/src/mermaid/parser/mermaid_parser.dart,lib/src/mermaid/models/mindmap.dart -->
  - 验收要点：支持标准 `mindmap` 块中基于缩进的父子层级解析，能构建单根或明确根节点下的多级子节点树。
  - 验收要点：支持常见 Mermaid mindmap 节点写法的标签提取，包括普通文本以及方括号、圆括号、双圆括号等包裹形式，渲染标签不应保留结构分隔符。
  - 验收要点：同一层级多个兄弟节点、跨多层嵌套、空行和 `%%` 注释场景均能稳定解析。
  - 验收要点：缩进异常、缺少有效根节点或只有 `mindmap` 关键字时返回 null 或稳定失败信息，不抛出未处理异常。
- [x] P003: 新增思维导图布局与绘制能力 <!-- scope: lib/src/mermaid/layout/layout_engine.dart,lib/src/mermaid/layout/mindmap_layout.dart,lib/src/mermaid/painter/mindmap_painter.dart,lib/src/mermaid/painter/mermaid_painter.dart -->
  - 验收要点：思维导图布局能按树形层级从根节点向左右或向外展开，节点之间保持可读间距，整体尺寸包含 padding 且宽高为有限正数。
  - 验收要点：布局能处理至少三层嵌套和多分支兄弟节点，不发生节点重叠、连线穿过主要文本或画布尺寸小于实际内容的问题。
  - 验收要点：Painter 能绘制根节点、普通节点、父子连接线和文本，颜色、字体、背景色优先复用 `MermaidStyle` 体系。
  - 验收要点：深色、浅色和响应式字号/间距配置下，节点文本可读，思维导图不会因为移动端宽度较小而出现无效布局。
- [x] P004: 接入 MermaidDiagram 与代码块预览分发链路 <!-- scope: lib/src/widgets/mermaid/mermaid_diagram.dart,lib/src/widgets/mermaid/mermaid_code_block_widget.dart,lib/src/mermaid/mermaid.dart,lib/wenz_richtext.dart -->

  - 验收要点：`InteractiveMermaidDiagram` 和 Mermaid 代码块预览能计算思维导图内容尺寸，并继续支持预览模式的缩放、平移、错误恢复和源码切换。
  - 验收要点：公共导出补齐 Mindmap 相关模型、解析器、布局或 painter 的必要类型，外部通过 `wenz_richtext.dart` 使用 Mermaid 能力时不会缺少新增类型。
  - 验收要点：新增分发分支不改变既有 Mermaid 类型在 widget、插件和代码块预览中的行为。
