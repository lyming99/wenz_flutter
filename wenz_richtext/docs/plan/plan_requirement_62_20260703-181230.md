# 需求 #62 开发计划：媒体块工具栏能力收敛与非遮挡胶囊按钮

- 需求编号：#62
- 生成时间：2026-07-03 18:12:30
- 需求内容：图片块/视频块，不要复制块引用功能；工具按钮背景使用胶囊风格；各种块的工具栏按钮应该在元素右上角，不遮挡元素位置。

## 背景与现状

本项目是 Flutter 富文本编辑器组件。图片/视频块默认渲染入口在 `lib/src/widgets/wenz_rich_text_editor.dart`：`_defaultImageBlockRenderer` / `_defaultVideoBlockRenderer` 构造 `_ImageBlockContent` / `_VideoBlockContent`，再经 `_MediaBlockChrome`、`_BlockObjectSelectionSurface` 与 `_FloatingObjectBlockToolbar` 提供选中态、预览和对象块工具栏。

当前 `_ObjectBlockToolbar` 的 `mediaActions` 分支会同时显示“预览媒体”和“复制块引用”，这与“图片块/视频块不要复制块引用功能”冲突。对象动作分发 `_handleObjectBlockAction` 仍支持 `ObjectBlockAction.copyReference`，需要在媒体块路径上做 UI 与行为兜底，保留非媒体对象块既有能力。

当前 `_blockToolbarIconButtonStyle` 使用 32px 固定命中区、18px 图标、8px 圆角和透明背景，视觉不是胶囊按钮。对象块更多菜单、文件块工具栏、代码块复制按钮和表格工具栏按钮复用这组 token，适合集中调整。

当前 `_BlockFloatingToolbarSurface` 使用 `Stack` + `PositionedDirectional(top/end)` 将工具栏画在 child 内部右上角。它被媒体块、文件块、分割线等对象块复用，容易遮挡元素自身内容；对窄图、设置显示宽度的图片等场景，还可能按整行而不是实际元素 frame 对齐。

## 实施原则

- 本需求只调整对象块工具栏能力、视觉和定位，不改图片/视频数据模型、序列化、插入/删除命令、MediaResolver 接口、选区模型和复制选区语义。
- `ObjectBlockAction.copyReference` 保持兼容，非媒体对象块可继续使用；图片/视频块从默认 UI 中移除该入口，并在分发层防止媒体块复制块引用。
- 工具栏按钮样式优先通过共享 token/helper 落地，避免在单个按钮中散落硬编码；按钮命中尺寸保持稳定，不因胶囊背景改变布局。
- 非遮挡定位优先收敛到 `_BlockFloatingToolbarSurface` / `_MediaBlockChrome` 等公共承载层，使文件、分割线、图片、视频等对象块获得一致行为。
- 测试代码补充只覆盖本需求场景；最终运行测试与构建命令放入最后“完整验收”节点。

## 任务拆解

- [x] P001: 禁用图片和视频块复制块引用入口 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_ObjectBlockToolbar` 的 `mediaActions` 分支不再渲染“复制块引用”按钮；图片/视频块选中后默认只保留“预览媒体”和可编辑态下的“更多块操作”。
  - 验收要点：`_handleObjectBlockAction` 或等价分发层对 `ImageBlockNode`、`VideoBlockNode` 的 `ObjectBlockAction.copyReference` 做兜底忽略，避免自定义入口或旧路径继续复制媒体块引用。
  - 验收要点：非媒体对象块的复制块引用能力不回退；文件、分割线、嵌入类对象块原有复制引用、复制副本、移动、删除等动作语义保持不变。
  - 验收要点：只读模式下图片/视频块不出现 mutation 入口，且不会因为移除复制引用影响双击预览、点击选中和安全预览动作。

- [x] P002: 统一块工具栏按钮为胶囊背景风格 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_kBlockToolbarButtonRadius`、`_blockToolbarIconButtonStyle` 或等价 token 改为胶囊形态，圆角应按按钮高度半径或明确 capsule radius 计算，32x32 命中尺寸和 18px 图标尺寸保持稳定。
  - 验收要点：按钮默认、hover、focus、pressed、disabled 状态都有一致的中性背景/反馈；普通状态不再是完全透明背景，pressed/focus 不使用大面积主题主色填充。
  - 验收要点：`_ObjectActionButton`、`_ObjectMoreMenu`、`_FileBlockActionMenu`、代码块复制按钮、表格浮动工具栏按钮等复用 `_blockToolbarIconButtonStyle` 的入口同步获得胶囊背景，不新增分散样式。
  - 验收要点：light/dark 模式下按钮背景、图标、禁用态对比度可读，popup 菜单 chrome 与按钮胶囊风格视觉协调。

- [x] P003: 重构对象块工具栏为右上角非遮挡布局 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_BlockFloatingToolbarSurface` 不再把工具栏直接覆盖在 child 内容像素上；工具栏应占用独立的上方/外侧工具栏区域，或通过明确外置定位保证与元素主体矩形不相交。
  - 验收要点：工具栏仍定位在元素的右上角，支持 `Directionality`，并在窄宽度下按可用宽度收敛或换行，不发生 RenderFlex overflow。
  - 验收要点：工具栏 hit test 只覆盖自身矩形；点击元素主体仍能完成选中、预览或原有交互，不被透明工具栏层拦截。
  - 验收要点：表格浮动工具栏的 overlay 生命周期、测量和夹紧逻辑不被本任务破坏；如只复用按钮 token，则表格定位仍保持现有 overlay 行为。

- [x] P004: 让图片和视频工具栏对齐真实媒体 frame 右上角 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_MediaBlockChrome` 或等价媒体承载层按实际图片/视频 frame 对齐工具栏，而不是按整行内容宽度对齐；设置 `showWidth/showHeight` 的窄图、默认宽图和不同宽高比视频均正确。
  - 验收要点：图片工具栏不遮挡图片像素、caption、占位态或加载失败态；视频工具栏不遮挡视频 frame、播放按钮、封面占位、失败态或 resolver 提供的 child。
  - 验收要点：图片/视频选中描边仍由 `_MediaSelectionStroke` 绘制，圆角、线宽、颜色和无通用松散 overlay 的行为保持不变。
  - 验收要点：图片/视频双击预览、鼠标光标、读屏 label、MediaResolver 成功/失败回退不因工具栏定位调整而改变。

- [x] P005: 同步文件、分割线和嵌入类对象块工具栏非遮挡表现 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_FileBlockContent` 的工具栏不覆盖文件名、状态、大小或文件类型 badge；hover/focus 边框、阴影、更多菜单动作保持原有语义。
  - 验收要点：`_DividerBlockContent` 的工具栏不覆盖分割线和圆点主体，选中后仍能清晰识别分割线位置。
  - 验收要点：`BlockEmbedNode`、callout/formula 等复用对象块工具栏承载的块与新的右上角非遮挡布局一致；文本内容和主要交互区域不被工具按钮遮住。
  - 验收要点：窄屏或窄容器下工具栏最大宽度被约束，按钮可换行或收敛，但元素主体不被遮挡且无布局异常。
