## 背景与问题定位

项目已通过 \`MermaidDiagramPlugin\` 将 \`CodeBlockNode(language == 'mermaid')\` 接管为 Mermaid 图表块，入口位于 \`lib/src/plugins/mermaid\_diagram\_plugin.dart\`，实际 UI 在 \`lib/src/widgets/mermaid/mermaid\_code\_block\_widget.dart\`。

当前预览态 \`\_MermaidPreviewView\` 使用 \`InteractiveViewer(constrained: false)\` 包裹 \`DiagramSvgSurface.render()\`，高度由 SVG intrinsic aspect ratio 推导，默认渲染面为 \`VectorGraphicsDiagramSurface\` + \`SvgPicture.string\`。现有测试已覆盖源码/预览切换、渲染失败、空内容、无界高度不崩溃，但未覆盖桌面鼠标聚焦、滚轮缩放、初始 fit-to-view 和深色背景下的 SVG 可读性。

结合附件截图可见：深色 Mermaid 区块内节点和连线接近纯黑，文字对比度不足，图形局部被放大/裁切；反馈描述还指出预览区域鼠标呈可点击状态但无法直接滚轮调节，需进入“查看全图”类路径才能操作。根因优先按以下方向处理：

1. \`MermaidDiagramConfig.defaultTheme\` 已定义但渲染选项未真正参与 \`renderSvg\`，导致输出 SVG 主题与编辑器深色图表容器不匹配。

1. \`SvgPicture.string\` 只按 \`width: maxWidth\` 渲染，预览层未给 SVG 内容稳定的逻辑尺寸，\`InteractiveViewer\` 初始矩阵也没有按 viewport 和 SVG viewBox 做 fit-to-view。

1. 预览区域缺少明确的焦点节点和桌面滚轮/触控板 pointer signal 处理，事件容易被外层 editor/scroll view 吸收或表现为不可缩放。

1. 视口高度随 SVG 比例变化，复杂流程图容易出现过高、过窄或初始裁切；需求期望固定比例视口并把内容缩放进可见区域。

## 修复方案

以 \`\_MermaidPreviewView\` 为主改点，拆出一个可测试的预览 viewport：固定图表预览比例，解析 SVG \`viewBox\`/\`width\`/\`height\` 得到内容尺寸，用 \`TransformationController\` 在布局完成后计算初始 fit 矩阵，将整张图按 padding 缩放到视口内。预览区增加 \`FocusNode\`/\`FocusableActionDetector\`/\`MouseRegion\`，点击或 hover 后可聚焦，鼠标滚轮和触控板滚动在预览区内直接缩放，拖拽仍用于平移。

渲染质量方面，补齐 Mermaid render options 构造逻辑，让 \`MermaidDiagramConfig.defaultTheme\` 真正传入 \`merman\`；默认 surface 明确使用 \`BoxFit.contain\`、稳定尺寸和背景/主题策略，避免深色容器中出现黑色节点、黑色连线、文字不可读。必要时对缺失尺寸的 SVG 走保守 fallback，不把 unsupported SVG 问题扩散到普通 code block。

## 任务拆解

- [x] P001: 修复 Mermaid SVG 主题与默认绘制可读性 <!-- scope: lib/src/plugins/mermaid\_diagram\_plugin.dart,lib/src/widgets/mermaid/mermaid\_code\_block\_widget.dart -->

  验收要点：

  - \`MermaidDiagramConfig.defaultTheme\` 被实际用于 \`renderSvg\` 的 \`optionsJson\` 构造，保留现有 \`{"svg":{"pipeline":"resvg-safe"}}\` 安全管线，不破坏测试注入的 fake renderer。

  - 深色 Mermaid 区块中流程图节点、连线、文字具备可读对比度，附件截图所示黑色节点/黑色连线压在深色背景上的问题不再复现。

  - \`VectorGraphicsDiagramSurface\` 渲染 SVG 时具备明确的 \`fit: BoxFit.contain\`、对齐方式和尺寸约束， malformed/unsupported SVG 仍不崩溃并回退到现有错误 UI。

  - 普通非 mermaid code block 仍由原始 code renderer 渲染，\`MermaidDiagramPlugin.install()\` 的包装行为不扩大影响范围。

- [x] P002: 将 Mermaid 预览改为固定比例视口并初始完整适配 <!-- scope: lib/src/widgets/mermaid/mermaid\_code\_block\_widget.dart -->

  验收要点：

  - \`\_MermaidPreviewView\` 使用稳定的固定比例预览区域（建议 16:9 或项目内常量化比例），高度由可用宽度和 min/max 约束决定，不再直接随 SVG intrinsic ratio 大幅波动。

  - 解析 SVG \`viewBox\`、\`width\`、\`height\` 得到内容逻辑尺寸；缺失或非法尺寸时使用明确 fallback，避免 infinite/zero size。

  - 初次进入预览、SVG 更新、外层宽度变化时，\`TransformationController\` 自动计算 fit-to-view 矩阵，将整张流程图含边距缩放到视口内，默认不裁切节点、箭头或标签。

  - 用户手动缩放/平移后不被无意义重置；仅在 SVG 内容或 viewport 尺寸真正变化时重新 fit。

- [x] P003: 修复预览区聚焦、鼠标滚轮缩放和平移交互 <!-- scope: lib/src/widgets/mermaid/mermaid\_code\_block\_widget.dart -->

  验收要点：

  - 预览区域拥有独立 \`FocusNode\`，点击预览区即可获得焦点，并可通过 focus/hover 状态稳定接收桌面指针事件。

  - 鼠标滚轮或触控板滚动发生在预览区内时，可直接缩放 Mermaid 图表，不需要先进入“查看全图”；缩放中心应靠近指针位置或视口中心。

  - 拖拽平移、双指/触控板缩放与 \`InteractiveViewer\` 既有行为保持可用；父级编辑器滚动不应在图表缩放手势期间抢占事件。

  - 鼠标悬停在预览区时 cursor 与交互语义一致，不表现为文本编辑 I-beam；源码模式仍保持代码块横向滚动和文本展示行为。
