## 背景与影响范围

项目是 Flutter 富文本编辑器 package。根据当前源码，需求涉及的主要实现点如下：

- 左侧块操作按钮由 `lib/src/widgets/wenz_rich_text_editor.dart` 中的 `_BlockDragHandleOverlay`、`_BlockDragHandleButton` 渲染，公共尺寸与透明度规则在 `lib/src/widgets/block_renderer_registry.dart` 的 `BlockDragHandleSpec`。
- 正文标题折叠按钮由 `wenz_rich_text_editor.dart` 的 `_headingCollapseStateFor`、`_HeadingCollapseButton` 渲染；当前叶子标题仍会渲染 disabled 折叠按钮。
- 块拖拽落点由 `BlockGeometryRegistry.blockReorderDropTargetFromGlobalOffset` 返回 before/after 插入边界，再由 `_BlockMoveRange` 与 `_moveBlockRangeToInsertionBoundary` 执行；当前 `after` 标题行的落点语义是标题块之后，而不是该标题章节子内容尾部。
- `Ctrl/Cmd+A` 经 `EditorShortcutIntent.selectAll` 调用 `controller.selectAll()`，当前核心 `SelectAllCommand` 是文档级全选；代码块内全选应在编辑器快捷键层优先处理为当前代码块内部范围，避免改变文档级命令的既有语义。

## 实施策略

优先保持现有编辑器架构：不引入新的公共 API，样式与交互仍由编辑器行级 chrome 统一管理；拖拽逻辑复用现有 outline range，必要时只在编辑器层把 drop target 归一化；代码块全选在快捷键分发处做上下文判断，保留非代码块场景的文档级全选行为。
