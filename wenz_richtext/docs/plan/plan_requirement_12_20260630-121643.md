# 需求 #12 开发计划：空引用块回车退出引用样式

## 需求摘要

引用块处于最后一行且内容为空时，用户按回车应在当前行取消引用样式，不再创建新的空行或新的引用块。结合当前项目实现，引用样式可能来自 `BlockType.quote` 或 `BlockAttributes.quoted == true`，回车入口主要在 `EnterCommand`，编辑器键盘输入最终调用 `WenzRichTextController.enter()`。

## 代码分析结论

- 核心回车逻辑位于 `lib/src/core/commands/block_commands.dart` 的 `EnterCommand._splitTextBlock`。
- 当前空列表项已存在“回车退出列表”的特殊逻辑，但空引用块没有等价退出逻辑，因此会继续按普通文本块拆分并生成新块。
- 引用块识别在渲染层已同时兼容 `block.type == BlockType.quote` 与 `block.attributes.isQuoted`，命令层修复也应兼容这两种表示。
- 已有测试文件 `test/core/block_commands_test.dart` 覆盖 EnterCommand 的列表、代码块、表格等场景，适合补充命令级回归；`test/widgets/wenz_rich_text_editor_test.dart` 已有引用块与回车相关 widget 测试，适合补充键盘链路回归。
