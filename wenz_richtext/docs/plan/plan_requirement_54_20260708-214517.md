# 电脑端禁用手机选择器与选区悬浮工具栏

## 需求概要

需求 #54 要求 wenz_richtext 在电脑上不显示手机端选择器和悬浮工具栏。当前代码已实现 MobileSelectionHandlesOverlay 和 WenzMobileSelectionToolbar，并通过 WenzRichTextEditor.enableMobileSelectionHandles 与 EditorTokens.resolve(context).isMobile 挂载；但 EditorTokens.isMobile 仅由 MediaQuery.shortestSide < 600 推导，桌面端窄窗口也会被视为移动端，从而可能挂载手机选区手柄与选区悬浮工具栏。WenzEditorBootstrap.resolveEditorLayout 同样用该断点决定默认工具栏布局，存在桌面窄窗口被自动切到手机布局的风险。本次计划将“响应式尺寸/密度”与“手机触屏选择 UI”拆开：电脑平台（Windows/macOS/Linux 以及桌面 Web）即使窗口很窄也不自动显示手机选择器、选区悬浮工具栏或默认手机布局；Android/iOS 手机端保留现有选择手柄、长按选词和选区工具条行为，显式配置仍按现有契约可控。
