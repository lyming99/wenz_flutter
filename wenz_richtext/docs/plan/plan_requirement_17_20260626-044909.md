## 原始内容
提示类的块组件，删除内容要和代码块的逻辑一致，删除内容时只删除选中的内容

## 需求理解
- “提示类的块组件”对应现有文档模型中的 `CalloutBlockNode` / `BlockType.callout`，其正文内容存储在 `content: List<InlineNode>` 中，并使用 `PositionPath.blockText` 参与文本编辑。
- 当前删除命令已对普通文本块和代码块做选区内删除，但提示块正文需要与代码块一致：当选中提示块内部分内容并删除时，只移除选中范围，不删除整个提示块。
- 删除后提示块的 `id`、`variant`、`title`、`icon`、`attributes` 等块级元数据必须保持不变；仅正文 inline 内容按选区范围变化。
- 同块选区、跨块边界选区、退格/前删触发的非折叠选区删除、撤销/重做和序列化结果都应走现有命令体系，避免在 UI 层绕过模型逻辑。
- 空正文提示块仍是合法提示块；除非用户明确选中整个对象块或执行已有结构删除命令，否则不应因正文被删空而移除提示块本身。
