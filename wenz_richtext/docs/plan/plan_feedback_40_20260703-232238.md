# 反馈 #40 开发计划：视频组件工具栏改为悬浮 Overlay

- 反馈编号：40
- 生成时间：2026-07-03 23:22:38
- 反馈内容：视频组件，工具栏应该用overlay的形式，悬浮，而不是聚焦后导致组件偏移来显示工具栏

## 背景与现状

项目是 Flutter 富文本编辑器包。当前视频块由 `lib/src/widgets/wenz_rich_text_editor.dart` 中 `_defaultVideoBlockRenderer` 渲染，随后进入 `_withSelectableVideoBlock` 和 `_MediaBlockChrome`。`_MediaBlockChrome.build` 在媒体块被选中时把 `_FloatingObjectBlockToolbar` 放进一个 `Column`，并插入在媒体内容上方，再通过 `_kBlockFloatingToolbarInset` 留出间距；因此视频从未选中到选中时，渲染树高度会增加，后续 block 和当前视频视觉位置会发生偏移。这正是反馈中“聚焦后导致组件偏移来显示工具栏”的来源。

项目内已有可复用的浮层范式：表格工具栏在 `lib/src/widgets/table_floating_toolbar_overlay.dart` 中使用 `OverlayPortal`、`LayerLink`、锚点快照、视口顶部夹紧和命中测试拦截，编辑器 shell 通过 `TableFloatingToolbarOverlayHost` 统一承载 overlay。视频工具栏应采用同类编辑器级 overlay 承载，而不是在视频块自身布局中插入工具栏节点。

本次修复范围应聚焦媒体对象块工具栏，优先保证 `VideoBlockNode` 选中/聚焦时视频 block 和视频 frame 的布局尺寸、位置不因工具栏出现而变化；同时要兼顾 `_MediaBlockChrome` 当前同时服务图片和视频，避免图片媒体工具栏、预览按钮、更多菜单、对象块操作和既有测试回归。

## 目标

- 选中或聚焦视频块时，工具栏通过编辑器级 overlay 悬浮显示，不再作为视频 block 的布局子节点参与 `Column` 排版。
- 视频 block 的外接矩形、视频 frame 矩形和后续 block 位置在选中前后保持稳定，不因工具栏出现产生向下偏移。
- 工具栏仍锚定在视频 frame 上方并向 frame 末端对齐；靠近视口顶部、滚动、窗口尺寸变化和窄容器场景下位置稳定。
- 预览媒体、更多块操作、移动、删除等对象块动作保持原语义；工具栏点击不穿透到视频选区、编辑器手势层或底层内容。
- 图片等共享 `_MediaBlockChrome` 的媒体块不发生可见回归；如果实现选择同步迁移图片工具栏，也必须满足同样的无布局偏移约束。

## 任务拆解

- [x] P001: 抽象对象块工具栏 Overlay 承载结构 <!-- scope: lib/src/widgets/object_block_toolbar_overlay.dart,lib/src/widgets/block_renderer_registry.dart,lib/src/widgets/wenz_rich_text_editor.dart -->
  验收要点：
  - 新增对象块工具栏 overlay 的 request、controller、host、anchor 或等价结构，写法对齐现有 `TableFloatingToolbarOverlayHost` / `TableFloatingToolbarOverlayAnchor` 的编辑器级生命周期模式。
  - overlay request 能携带 owner、blockId、blockIndex、锚点 `LayerLink`、锚点 rect、visibleTop、toolbarBuilder、minWidth、gap、fallbackHeight 等定位和显示信息。
  - `BlockRenderContext` 能把对象块工具栏 overlay controller 传给内置图片/视频等对象块 renderer；自定义 renderer 不传入时应保持兼容。
  - overlay host 安装在编辑器 shell 内，与表格 toolbar overlay、外部图片拖拽 overlay、selection gesture overlay 互不抢占生命周期。
  - 选区取消、block 删除、renderer 销毁、controller 切换或编辑器 dispose 时能撤销对象块 toolbar request，不残留悬浮组件。

- [x] P002: 将视频媒体工具栏接入 Overlay 并移除布局占位 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/widgets/block_renderer_registry.dart,lib/src/widgets/object_block_toolbar_overlay.dart -->
  验收要点：
  - `_withSelectableVideoBlock` / `_MediaBlockChrome` 在 `VideoBlockNode` 选中时只发布 overlay request，视频内容本身仍返回稳定的 frame/content 布局，不再用 `Column` 把 `_FloatingObjectBlockToolbar` 插入到视频内容上方。
  - 视频工具栏继续使用现有 `_FloatingObjectBlockToolbar` / `_ObjectBlockToolbar` 视觉和按钮，不重写动作语义。
  - 工具栏默认位于视频 frame 上方，和 frame 末端对齐；当 frame 靠近视口顶部时按 visibleTop 夹紧，不遮挡到不可见区域。
  - 预览媒体、更多块操作、移动、删除等 action 仍通过 `ObjectBlockActionIntent` 和原 controller 路径触发，selection 和焦点不会因点击 overlay 丢失。
  - 视频 block 在窄宽度、resolver 自定义播放器、封面占位、加载失败占位等现有场景下仍保持 frame 内裁剪和圆角边界。

- [x] P003: 保持共享媒体和对象块工具栏兼容 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,test/widgets/editor_golden_test.dart -->
  验收要点：
  - 图片块若继续使用 `_MediaBlockChrome`，其工具栏行为与视频迁移后的实现兼容：选中态按钮、frame 对齐、预览、更多菜单和图片尺寸操作不回归。

  - overlay 命中测试只覆盖工具栏实际区域，不安装全屏阻断层；工具栏外的编辑、拖选、滚动和 block 选中行为保持可用。
