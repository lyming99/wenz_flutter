## 项目全景摘要

### 定位
自研 Flutter 富文本编辑器核心包，已完全移除 ydart/Yjs 依赖，拥有自研文档模型、命令体系、history、输入桥、渲染层、序列化层。

### 当前阶段：`0.1.0-alpha`，全部 30 项 ADV 进阶功能已完成

| 维度 | 状态 |
| --- | --- |
| **文档模型** | BlockNode 层次体系、TableModel、InlineNode、Comment/Revision 模型均已完成 |
| **命令层** | 文本/样式/块结构/表格/Selection/Revision 全系列命令已覆盖 |
| **输入系统** | IME 桥、剪贴板、快捷键管理、查找替换、Slash 菜单均完成 |
| **序列化** | Rich JSON、Legacy JSON、Markdown、HTML、Plain Text 均完成 |
| **渲染** | BlockRendererRegistry、InlineEmbedRenderer、虚拟化+增量 rebuild、LayoutCache 均完成 |
| **插件/协作** | WenzRichTextPlugin、CollaborationAdapter 接口已完成 |
| **质量** | 381 tests / 5 benchmarks / Golden 矩阵 / Flutter analyze clean |
| **可访问性** | 自动化语义节点完成，屏幕阅读器手验待补 |
