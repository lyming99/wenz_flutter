# 需求 #60 开发计划：公式 popup 更新内容后渲染消失

> 需求原文：公式 popup 更新内容后，渲染出现问题了，直接消失不见了。

## 背景与现状

- 触发路径：点击行内/块级公式 → 打开 `_FormulaEditPopup` → 修改内容 → 点“确认”
  → `_confirmFormulaEditor()`（`lib/src/widgets/wenz_rich_text_editor.dart`）
  → `controller.updateInlineFormula(...)` / `controller.updateBlockFormula(...)`
  → `UpdateInlineFormulaCommand` / `UpdateBlockFormulaCommand`。
- 数据层已被验证正确且单元测试覆盖（`test/core/inline_commands_test.dart`）：
  - `_updateInlineFormulaContent` 能定位目标 embed 并通过 `copyWithFormulaText` 重写
    `data['text' / 'latex' / 'value' / 'formula']`；块级命令同步更新 `fallbackText`。
  - 既有测试只断言 **数据字段**，未断言 **渲染输出**，因此渲染回归未被捕获。
- 问题本质是 **渲染回归**：确认更新后，渲染出的公式“直接消失不见”。
- 回归来源高度怀疑是最近的 `91ece57 富文本优化` 提交：该提交把行内公式渲染重构为
  `MeasuredWidgetSpan(placeholderSize: size)` + `_InlineFormulaView`（其内部
  `SizedBox.fromSize(key: _inlineFormulaKey, size: placeholderSize)` 固定到预计算的尺寸）。
  内容变更后，预计算的 `placeholderSize` 与实际子节点测量可能失配，导致占位尺寸归零/失效。

## 根因候选（供 P001 定位）

1. **行内公式（首要怀疑）**
   - `_formulaInlineSpanFor`（`wenz_rich_text_editor.dart` 约 12069）将
     `size = _inlineFormulaPlaceholderSize(formula, style)` 同时塞进 `MeasuredWidgetSpan.placeholderSize`
     与 `_InlineFormulaView.placeholderSize`（`SizedBox.fromSize`）。
   - `MeasuredWidgetSpan.build`（`lib/src/rendering/text_layout_service.dart`）中
     `dimensions ?? <PlaceholderDimensions>[ 单个 ]` 在 `dimensions` 为 null 或段落内存在多个占位符时，
     可能与 `placeholderCodeIndex` 失配，导致该 span 被错误测尺寸。
   - `TextLayoutService.layout` 按 `span` 引用相等缓存 painter；新 span 触发重建，但需确认
     `setPlaceholderDimensions` 拿到的是新尺寸而非陈旧值。
   - `_InlineFormulaView` 的 `SizedBox` 使用全局常量 `_inlineFormulaKey`，元素复用时尺寸/内容是否同步刷新待确认。
2. **块级公式（次要，需 P003 确认是否同源）**
   - `_FormulaBlockView`（约 10059）预览走 `_FormulaMathView(formula, displayMode: true)`，
     属于普通 widget 子树重建，理论上随 `block.data` 刷新；需确认 popup 更新后预览确实刷新而非消失。
