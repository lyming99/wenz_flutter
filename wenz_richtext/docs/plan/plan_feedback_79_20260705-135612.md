# 优化默认工具栏块样式显示与插入入口位置

## 需求概要

反馈 #79 要求默认工具栏不再以“块样式：正文”这类文案暴露块样式概念，而是直接显示“正文、H1、H2”等当前样式；默认状态为正文，当无法识别为具体标题或正文时仍以置灰的正文作为兜底提示；同时将“插入元素”入口移动到工具栏末尾。结合当前代码，影响主要集中在 WenzDefaultDesktopToolbar 的按钮顺序、_BlockStyleMenuButton 的展示/tooltip/禁用状态，以及依赖 tooltip 和顺序的默认工具栏 widget 测试。

## 任务拆解

- [x] P001: 调整默认工具栏控件顺序 <!-- scope: lib/src/widgets/default_desktop_toolbar.dart,test/widgets/default_desktop_toolbar_test.dart -->
  - 验收要点：默认工具栏中的“插入元素”按钮从当前文字格式组后方移动到主工具栏末尾。
  - 验收要点：块样式、引用、列表、对齐、表格上下文和插件/宿主扩展项的相对功能保持可用，不因插入按钮后移而丢失。
  - 验收要点：工具栏在窄宽度换行时仍不发生 Flutter overflow，末尾插入入口可见且可点击。

  - 验收要点：普通段落选区默认显示“正文”。
  - 验收要点：H1-H6 标题选区显示对应级别，点击下拉后仍能切换到正文或其他标题级别。

- [x] P003: 同步块样式状态与 tooltip 语义 <!-- scope: lib/src/widgets/default_desktop_toolbar.dart -->
  - 验收要点：块样式控件 tooltip 不再使用“块样式：正文”“块样式：H1”“块样式：混合”这类文案。

  - 验收要点：只读、评论权限或不可设置块类型时，块样式按钮仍按现有权限禁用，但兜底正文显示保持置灰可辨。
