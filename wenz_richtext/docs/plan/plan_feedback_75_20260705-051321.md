# 修复视频全屏圆角残留

## 需求概要

反馈指出视频进入全屏后仍携带内嵌媒体帧圆角，导致画面没有真正铺满全屏。项目中视频块内嵌状态由 `lib/src/widgets/wenz_rich_text_editor.dart` 的 `_VideoBlockContent` 使用 `_kMediaCornerRadius` 裁剪，媒体预览由 `_showVideoPreview` 通过 `Dialog` 和 `_VideoFrameChildBoundary` 渲染，示例播放器 `example/lib/example_video_player.dart` 根部也固定 `ClipRRect(8)`。修复计划需要保留编辑器内视频帧圆角和选择描边，同时让预览/全屏播放路径使用无圆角、无外层圆角裁剪的画面容器。
