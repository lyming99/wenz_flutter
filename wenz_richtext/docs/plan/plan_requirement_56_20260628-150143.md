## 原始内容
请在 example 中引入一个视频例子，并且真正支持视频播放，视频案例文件夹 `d:/video`。

## 需求理解
- “引入一个视频例子”指在 example 应用（`example/lib`）中提供一个真实可播放的视频块样例，而非仅渲染静态封面/播放图标卡片。
- 现状：`example/lib/main.dart` 中的 `_ExampleMediaResolver._resolveVideo` 对所有 `http` 源返回一个**静态预览卡片**（封面图 + 居中播放图标，不真正播放）；对非 `http` 源直接返回 `null` 走占位。`_sampleDocument()` 中的视频块 `playbackUrl` 指向 `https://example.com/videos/sample.mp4` 这类**并不存在**的地址。工具栏 `_insertVideo` 同样插入不可播放的 `example.com` 地址。
- “真正支持视频播放”要求 example 端接入一个真实播放库，能初始化播放器、播放/暂停、显示进度，并在加载失败时优雅降级；包核心（`wenz_richtext`）本身**不**新增播放依赖，仍通过 `MediaResolver` 扩展点把播放交给宿主（见 `lib/src/widgets/media_resolver.dart` 的设计约束）。
- “视频案例文件夹 `d:/video`”要求从该文件夹选取真实视频素材用于样例；为保持 example 自包含、可在多机器/CI 上播放，推荐把 `d:/video` 下一个小体积 mp4 拷贝进 `example/assets/videos/` 并在 `pubspec.yaml` 注册为 asset，同时让解析器支持 asset / 网络 / 本地文件 三类源。
- 模型侧已具备所需字段：`VideoBlockNode.file` / `playbackUrl` / `assetId`，且 `effectivePlaybackUrl` 会按 `playbackUrl → file → assetId` 回退，可直接用 `file: 'assets/videos/xxx.mp4'` 表达 asset 源，序列化/反序列化（JSON、HTML `data-*`）与现有行为一致，无需改动核心模型或编解码器。
- 需保护：现有静态预览卡片的“无可用源返回 null 走内置占位”语义、集成测试 `editor_richtext_test.dart` 中插入网络视频并 `pumpAndSettle` 的用例（真实播放器对不存在的网络地址可能报错或计时，必须降级而不阻塞测试），以及撤销/重做、序列化往返、文档统计等既有行为。

## 任务拆解
- [x] P001: 选型并接入视频播放依赖 <!-- scope: example/pubspec.yaml -->
  - 验收要点：评估 `media_kit`（`media_kit` + `media_kit_video` + `media_kit_libs_video`，基于 libmpv，Windows/桌面/Web/移动端原生可播 mp4/webm）与 `video_player`（+ `video_player_media_kit` 用于补齐桌面端）两条路线，依据 example 的目标平台（开发机为 Windows 桌面，且存在 web/）确定最终依赖；默认推荐 `media_kit` 以保证开发机上“真正可播”。
  - 验收要点：在 `example/pubspec.yaml` 的 `dependencies` 中加入所选播放库及其平台运行时库依赖（如 `media_kit_libs_video`），版本约束合理且与现有 SDK（`sdk: ^3.11.0`）兼容；不向包根 `pubspec.yaml` 引入任何播放相关依赖。
  - 验收要点：确认所选方案在 Windows 桌面、Web（若 example 以 web 为目标）上无需额外手改 native 目录配置即可工作；若需平台特定配置，在本任务内完成并记录。

  - 验收要点：从 `d:/video` 中选取一个小体积（建议 < 10MB，优先选 `d:/video/v1.0.10.beta更新视频/split/00_开场介绍.mp4` 这类短样例）的 mp4，拷贝为 `example/assets/videos/` 下的文件（命名建议全英文，如 `sample.mp4`），避免引入超大文件导致仓库体积膨胀；记录所选源文件路径。
  - 验收要点：在 `example/pubspec.yaml` 的 `flutter:` 下新增 `assets:`，注册 `assets/videos/`（或具体 mp4 路径），确保 `flutter pub get` 后资源可被 `rootBundle`/播放器 asset 方式加载。
  - 验收要点：所选素材为标准 mp4（H.264/AAC 等通用编码），能在所选播放库上直接解码播放；若素材为 `.webm` 等格式，确认所选播放库支持并在记录中说明。

- [x] P003: 实现真实视频播放组件 <!-- scope: example/lib/example_video_player.dart -->
  - 验收要点：在 `example/lib/` 下新增一个可复用的 `StatefulWidget`（如 `ExampleVideoPlayer`），基于所选播放库创建并持有播放控制器，`initState` 中异步初始化（asset/网络/本地文件三种来源）、`dispose` 中释放控制器，避免内存泄漏与重复初始化。
  - 验收要点：组件提供真实交互能力：播放/暂停切换、当前进度与总时长、进度条/拖动 seek、静音与音量控制（至少覆盖播放/暂停与进度展示），并在 `aspectRatio` 约束内正确裁剪/填充，遵循 `MediaResolver` 文档中“解析器组件需在有限帧内布局、不得假设无限宽高”的约束。
