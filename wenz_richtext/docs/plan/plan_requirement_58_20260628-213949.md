# 需求 #58 开发计划：视频/图片等媒体块选中边框匹配自身尺寸

- 需求编号：#58
- 生成时间：2026-06-28
- 需求内容：视频、图片之类的，选中边框要匹配自身尺寸，避免样式难看

## 背景与根因分析

媒体块（图片/视频，以及以媒体形式渲染的附件）的选中态描边由通用的对象块选中浮层
`_BlockObjectSelectionSurface` 统一绘制，而非像分割线、附件卡片那样在“自身帧”上绘制：

- `_BlockObjectSelectionSurface`（`lib/src/widgets/wenz_richtext_editor.dart:8427`）的 `build`
  中，选中态通过 `Positioned.fill` 叠加一层 `DecoratedBox`（`wenz_rich_text_editor.dart:8588-8620`）：
  ```dart
  border: Border.all(color: selectedColor, width: 2),
  borderRadius: BorderRadius.circular(6),
  ```
- 该浮层 `Positioned.fill` 覆盖的是整段 `child`（即 `_ImageBlockContent`/`_VideoBlockContent`
  整体），而媒体内容本身外层带有上下留白 `Padding(vertical: _kMediaBlockMarginVertical / 2)`
  （`wenz_richt_text_editor.dart:11215-11217` 图片、`10123-10126` 视频，其中
  `_kMediaBlockMarginVertical = _kRichTextBodyFontSize * 1.2`，`wenz_rich_text_editor.dart:220`）。

由此产生两处“样式难看”的根因：

1. **尺寸不匹配（主因）**：选中描边 `Positioned.fill` 贴满整段内容，**包含上下留白**，导致描边矩形
   比真正的媒体帧高出 `_kMediaBlockMarginVertical`，表现为一个“松散地浮在媒体外围”的大矩形，
   没有紧贴媒体自身尺寸（对应需求“选中边框要匹配自身尺寸”）。
2. **圆角不匹配**：选中描边固定用 `BorderRadius.circular(6)`，而媒体帧实际圆角为
   `_kMediaCornerRadius = 12.0`（`wenz_rich_text_editor.dart:221`，见
   `11233`/`11237` 图片、`10152`/`10156` 视频帧），两者圆角不一致，描边四角与媒体帧四角对不齐。

渲染链路（确认影响范围）：`_defaultImageBlockRenderer`/`_defaultVideoBlockRenderer`
（`wenz_rich_text_editor.dart:5700`/`5759`）→ `_withSelectableImageBlock`/`_withSelectableVideoBlock`
（`5976`/`6015`）→ `_MediaBlockChrome`（`11250`）+ `_BlockObjectSelectionSurface`（`8427`）
→ `_ImageBlockContent`（`11193`）/`_VideoBlockContent`（`10110`）。此外，解析后以媒体形式渲染的
附件块（`_defaultFileBlockRenderer` 中 `resolved != null` 分支，`5846-5847`，经
`_withSelectableObjectBlock`→`_BlockObjectSelectionSurface`）共用同一通用浮层，存在同样问题，
属于“视频、图片之类的”同类范畴，一并纳入。

对照之下，分割线 `_DividerBlockContent`（`10202`，选中态 `shellDecoration` 贴自身、圆角 8）、
附件卡片 `_EmbedBlockCard`（`10358`，`_DashedRRectBorderPainter` 圆角 `_kMediaCornerRadius`）
均在“自身帧”上绘制选中描边，视觉正确——图片/视频正是缺失了这一处理。

## 修复方案

把媒体块的选中描边从“通用浮层”改为“贴在媒体帧自身”，使边框尺寸与圆角都与媒体帧一致：

- 让选中描边绘制在真正的媒体帧矩形（`_ImageBlockContent`/`_VideoBlockContent` 中带
  `_kMediaCornerRadius` 圆角与 `_kSurfaceBoxShadow` 的 `DecoratedBox`，`11227`/`10146`）上，
  使描边**紧贴媒体帧**（不再延伸进上下 `_kMediaBlockMarginVertical` 留白），描边圆角使用
  `_kMediaCornerRadius`（12.0），不再用 `BorderRadius.circular(6)`。
- 通过 `_withSelectableImageBlock`/`_withSelectableVideoBlock`（及解析后附件媒体路径）把 `selected`
  透传到媒体帧绘制处；选中态描边用 `theme.colorScheme.primary`，与代码块/分割线/附件卡片选中色保持一致。
- 避免与 `_BlockObjectSelectionSurface` 的通用浮层叠加成“双重/松散矩形”：对媒体块（图片/视频/解析后
  附件媒体）关闭或替换该通用 overlay（命中/几何注册、双击预览 `onDoubleTap`、点击选择、浮动工具栏
  `_MediaBlockChrome`→`_FloatingObjectBlockToolbar` 等既有行为保持不变）。
- 不触碰文本块/代码块/分割线/callout/表格等其它块类型的选中高亮。
