# 增强表格工具栏能力并统一使用 Lucide SVG 图标

## 需求概要

当前 wenz_richtext 是 Flutter/Dart 包，项目已引入 flutter_svg、assets/lucide/ 和 WenzLucideToolbarIcon，默认桌面/移动工具栏已基本使用 Lucide SVG；但表格浮动工具栏仍在 lib/src/widgets/wenz_rich_text_editor.dart 中直接使用 Material Icons，动作入口也主要集中在少量快捷按钮和一个更多菜单。需求要求“表格工具栏功能多支持一些，图标都用 lucide svg 图标”，因此计划围绕现有 TableToolbarAction、TableFloatingToolbarOverlay 和表格命令族扩展表格浮动工具栏的动作模型、可见入口、菜单分组、可用态与测试覆盖，并将表格工具栏按钮和菜单图标统一迁移到本地 Lucide SVG 资产。
