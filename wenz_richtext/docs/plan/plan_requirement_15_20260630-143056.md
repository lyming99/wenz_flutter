# 需求 #15 开发计划：选择文件插入图片

## 来源
- 类型：需求
- 编号：15
- 生成时间：2026-06-30 14:30:56
- 原始需求：插入图片功能，要支持选择文件插入；

## 需求理解
- 当前项目已有 `ImageBlockNode`，支持 `assetId`、`file`、`width`、`height`、`showWidth`、`showHeight`、`caption`、`altText` 等字段；渲染层已有 `MediaResolver` 扩展点，可由宿主渲染真实图片。
- 当前缺口是块级图片插入没有与 `insertVideo` / `insertFile` 同级的 typed helper；`WenzRichTextController` 只有 `updateImageBlock` 和 `insertInlineImage`，example 的 `_insertImage` 仍插入固定 `picsum` 网络占位图。
- 默认 `/image` slash item 目前同步替换为图片占位块；`SlashMenuAction` 无 `BuildContext` 且同步执行，不适合直接承担系统文件选择弹窗。最优方案是：核心补齐稳定的块级图片插入 API，example/宿主 UI 通过文件选择器拿到本地图片后调用该 API 插入。
- 为保持核心 package 的轻依赖与跨平台边界，系统文件选择依赖优先只加在 `example` 端；核心包继续通过模型、controller、toolbar helper 和 `MediaResolver` 承接业务数据与渲染。
- 用户可见目标：点击 example 工具栏“插入图片”后打开系统文件选择器；选择 jpg/png/gif/webp/bmp 等图片后在当前光标位置插入并预览本地图片；取消选择不修改文档；插入后可撤销/重做。

## 影响范围
- 核心命令入口：`lib/src/controller/wenz_rich_text_controller.dart`、`lib/src/controller/toolbar_controller.dart`。
- 示例文件选择与预览：`example/lib/main.dart`、`example/pubspec.yaml`、`example/pubspec.lock`，必要时新增本地图片渲染条件导入 helper。
- 文档与测试：README、docs 下 API/命令/渲染说明、controller/toolbar/widget 或 example 测试。
