# 需求 #51 开发计划：公式点击编辑 popup

## 需求摘要
- 公式节点需要支持点击后弹出编辑 popup。
- 用户可在 popup 中修改公式内容，并将修改写回原公式节点。
- 编辑体验需覆盖行内公式与块级公式，保持现有选择、序列化、剪贴板、主题与只读行为不回归。

## 总体验收标准
- 计划中的所有 checkbox 任务完成，且每个任务的验收要点均有对应实现、测试或记录。
- 行内公式和块级公式在编辑模式下点击后均能弹出编辑 popup，并预填当前公式文本。
- 用户在 popup 中确认修改后，原公式节点内容更新，预览、纯文本、序列化、复制和统计等依赖公式文本的能力保持一致。
- 用户取消、关闭或点击外部收起 popup 时，文档内容不发生变化；空输入和非法目标不会导致崩溃或错误写入。
- 只读模式、主题切换、窄屏布局、滚动后点击、键盘弹出和现有 selection/toolbar 行为不回归。
- 最终验收命令范围：`flutter analyze`、`flutter test test/widgets/wenz_rich_text_editor_test.dart --name formula`、`flutter test test/core/inline_commands_test.dart`、`flutter test`；通过标准为命令成功退出，或仅存在已记录且与本需求无关的历史/环境失败。
