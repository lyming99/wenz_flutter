# 工具栏 Tooltip 中文化

## 需求概要

反馈要求将工具栏 tooltip 改成中文。结合当前代码，编辑器内表格、对象块、媒体、附件、代码块等浮动工具栏大多已经使用中文 tooltip，主要遗留在公开的 WenzDefaultDesktopToolbar：核心格式、块类型、对齐、缩进、插入、资源动作、表格动作以及颜色/链接/不可用/处理中等动态 tooltip 仍为英文。计划将这些内置 tooltip 统一中文化，并同步依赖 tooltip 查找的默认工具栏测试，保持按钮行为、启用禁用状态、选中态和宿主/插件自定义 toolbar item 文案不变。

  - 验收要点：标题、段落、引用、任务列表、有序列表、无序列表、左/中/右/两端对齐、清除对齐、增加缩进、减少缩进、插入代码块、插入标注、插入表格等结构按钮均显示中文 tooltip。
