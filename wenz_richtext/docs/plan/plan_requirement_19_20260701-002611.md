## 项目分析
- 项目是 Flutter package，主库位于 `lib/`，示例应用位于 `example/`。
- example 入口为 `example/lib/main.dart`，`WenzRichTextExampleApp` 通过 `_exampleTheme(Brightness.light/dark)` 创建 `MaterialApp` 的亮色和暗色主题。
- 当前 `_exampleTheme` 只设置 `colorScheme`、`scaffoldBackgroundColor` 和 `useMaterial3`，没有设置 `fontFamily`。
- example 编辑器通过 `_bootstrap.buildEditor(... textStyle: theme.textTheme.bodyLarge, defaultTextColor: theme.colorScheme.onSurface)` 使用当前主题文本样式，因此在 `ThemeData` 层设置默认字体可以覆盖 editor 正文、AppBar、工具栏和 Inspector 等 example 默认文本。
