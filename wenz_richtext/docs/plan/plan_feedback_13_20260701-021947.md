# Plan: 反馈 #13 — 表格单元格（cell）对齐方式无法设置

## 反馈原文

> 表格内容，cell 对齐方式，没办法设置

## 需求解读

用户希望在表格里给**单个或若干选中的单元格（cell）**单独设置文本对齐方式，但当前无法做到。

## 根因分析（基于项目实际代码）

表格对齐当前只支持**按列**粒度，没有单元格级别：

- `lib/src/core/model/table_model.dart:11` 中 `TableModel.columnAlignments`（`Map<int,String>`）按列存储对齐；`TableCellNode`（同文件 92 行起）只有 `id / blocks / rowSpan / columnSpan / isHeader / backgroundColor / covered`，**没有 alignment 字段**。
- 渲染层 `lib/src/widgets/wenz_rich_text_editor.dart:8029-8031` 直接用 `table.columnAlignments[cell.columnIndex]` 取对齐再交给 `_textAlign(...)`（13510 行），完全不看 cell 自身。
- 工具栏对齐按钮 `TableToolbarAction.alignLeft/alignCenter/alignRight/clearAlignment`（同文件 2693-2704）统一调用 `_setTableColumnAlignment`（2929 行），该方法**忽略 row 范围**，只对 `range.startColumn..endColumn` 写列对齐——因此即使用户只选中一个 cell，对齐也会落到整列上，表现为"cell 对齐设置不了"。
- 命令侧只有 `SetTableColumnAlignmentCommand`（`table_commands.dart:237`）与 controller typed helper `setTableColumnAlignment`（`wenz_rich_text_controller.dart:1674`），均按列操作。

## 设计方案（按最优工程方案）

引入**单元格级对齐**，并让 cell 对齐**优先于**列对齐（回退到列对齐），做到单 cell 可设、向后兼容：

1. `TableCellNode` 增加 `alignment`（可空 `String`，取值 `left/center/right/justify`，`null` 表示继承列对齐）。
2. 新增 `SetTableCellAlignmentCommand` + controller `setTableCellAlignment`，按 cell 写入，`null` 为清除。
3. 渲染时对齐优先级：`cell.alignment` → `columnAlignments[column]` → 默认 start。
4. 工具栏对齐按钮改为对选区内的**每个可见 cell** 设置 cell 对齐，单 cell 选区只改该 cell，不再无差别改整列。
5. codec round-trip 保留 cell 对齐：rich JSON（TableModel 自动）、legacy JSON、HTML（`text-align` 内联样式）。Markdown 表格语法仅支持列对齐，cell 对齐按列降级导出，导入沿用列对齐，属合理边界。

## 影响范围（scope 概览）

- 命令与门面：`table_commands.dart`、`wenz_rich_text_controller.dart`、`wenz_richtext.dart`

  - 验收要点：
    - `TableCellNode` 新增可空字段 `final String? alignment`，构造函数带默认值 `null`，保持现有构造调用点零破坏。
    - `toJson()` 在 `alignment != null` 时写入 `'alignment'`；`fromJson()` 读取 `json['alignment'] as String?`，缺失或为空时回退 `null`，旧文档可正常解析。
    - `TableBlockNode.copy()`、`copyCell()`（`table_cell_editing.dart`）、`block_commands.dart` 中重建表格的 cell 复制逻辑均显式复制 `alignment` 字段，避免拷贝丢失。
    - 富文本 JSON（走 `TableModel.toJson/fromJson` + `TableCellNode.toJson/fromJson`）对新字段自动 round-trip。

- [x] P002: 新增单元格对齐命令 SetTableCellAlignmentCommand 与 controller typed helper <!-- scope: lib/src/core/commands/table_commands.dart,lib/src/controller/wenz_rich_text_controller.dart,lib/wenz_richtext.dart -->
  - 验收要点：
    - 新增 `SetTableCellAlignmentCommand(blockIndex, rowIndex, columnIndex, alignment)`，复用 `updateTableCell`/`tableAt` 校验坐标，越界或 cell 不存在时返回 `CommandResult(recordHistory: false)`。
    - 通过 cell 拷贝重写 `alignment`（参照现有 `SetTableCellHeaderCommand` / `SetTableCellBackgroundCommand` 写法），保留其余字段不变。
    - 命令进入历史可被撤销/重做（`recordHistory` 默认 true）。
    - `WenzRichTextController` 新增 `ChangeSet setTableCellAlignment({required int blockIndex, required int rowIndex, required int columnIndex, required String? alignment})`，内部 `execute(SetTableCellAlignmentCommand(...))`。
    - 新命令与 helper 从 `lib/wenz_richtext.dart` public surface 导出（与 `SetTableColumnAlignmentCommand` 同层）。

- [x] P003: 渲染层应用单元格对齐（cell 优先，回退列对齐） <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：
    - 单元格文本渲染处（约 8029 行）对齐取值改为：`cell.cell.alignment ?? table.columnAlignments[cell.columnIndex]`，再交给既有 `_textAlign(...)`。
    - 仅设置列对齐的旧文档渲染行为不变（cell.alignment 为 null 时回退列对齐）。
    - 仅设置 cell 对齐的文档按 cell 对齐渲染，列对齐未被覆盖的其他 cell 仍按列对齐渲染。

- [x] P004: 工具栏对齐按钮作用于选中单元格范围 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：
    - `TableToolbarAction.alignLeft/alignCenter/alignRight/clearAlignment`（约 2693-2704 行）改为对 `range` 内每个**可见 cell** 调用 `widget.controller.setTableCellAlignment`，复用 `_forEachVisibleTableCell` 既有遍历模式（参照 `setBackgroundColor` 用法），`left/center/right` 传对应字符串，`clearAlignment` 传 `null`。
    - 选中单个 cell：只修改该 cell 的对齐，不影响同行/同列其他 cell。
    - 选中多 cell 矩形范围：范围内所有可见 cell 都被设置，范围外 cell 不受影响。
    - 跨行多选不再把对齐误扩散到整列；既有列对齐值保持不变。

- [x] P005: codec 保留单元格对齐 round-trip <!-- scope: lib/src/codecs/legacy_wen_json_codec.dart,lib/src/codecs/html_codec.dart -->
  - 验收要点：
    - legacy JSON：`_tableCell`（约 272 行）在 cell 上写入并读取 `alignment`，与 `_tableModel` 列对齐并存；旧数据缺失字段时回退 null。
    - HTML：编码表格 cell 时，当 cell.alignment 非空写入 `text-align` 内联样式（或 `align` 属性，与现有 HTML 输出风格一致）；解码 `_decodeTable`（约 985 行）读取 cell 的 `text-align`/`align` 回填 `TableCellNode.alignment`，无则回退列对齐。
    - Markdown：仅支持列对齐的语义不变，导出/导入不回归；cell 对齐在 Markdown 下按列降级（可接受）。
    - 富文本 JSON：通过 P001 的 `TableCellNode.toJson/fromJson` 自动 round-trip，验证 set→save→load 后 alignment 仍在。
