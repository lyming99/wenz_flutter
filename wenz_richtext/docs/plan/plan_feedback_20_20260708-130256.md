# 视频块尺寸与对齐能力补齐

## 需求概要

根据反馈“视频块也要像图片块一样调节尺寸、对齐方式”，在现有图片块能力基础上补齐视频块显示尺寸字段、命令/控制器入口、渲染尺寸约束、拖拽 resize、对象菜单/工具栏对齐联动，并补充模型、控制器和 widget 场景测试。

## 任务拆解

- [x] P001: 扩展视频块显示尺寸数据模型与命令 <!-- scope: lib/src/core/model/block_node.dart,lib/src/core/commands/block_commands.dart,lib/src/controller/wenz_rich_text_controller.dart,lib/src/controller/toolbar_controller.dart -->
  - 验收要点：VideoBlockNode 支持 showWidth/showHeight，与 ImageBlockNode 一样可 copy/copyWith、JSON 序列化和反序列化，并兼容旧数据缺省为 null。
  - 验收要点：InsertVideoBlockCommand、UpdateVideoBlockCommand、WenzRichTextController.insertVideo/updateVideoBlock 可写入、更新和清除视频显示尺寸。
  - 验收要点：视频尺寸变化参与 no-op 判断和 undo/redo 历史，且不影响 playbackUrl、coverUrl、title、description、aspectRatio、uploadStatus 等既有字段。
- [x] P002: 让视频块渲染支持显示尺寸和对齐 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：视频块 frame 使用 showWidth/showHeight 计算显示宽高，并按可用宽度、最小/最大视频尺寸和视频 aspectRatio 做安全约束。
  - 验收要点：视频块读取 block.attributes.alignment，支持 left、center、right 和无显式对齐，默认行为与图片块一致。
  - 验收要点：内置视频占位、封面层和 resolver 返回的自定义播放器都被约束在调整后的 frame 内，不出现溢出或无限尺寸。
- [x] P003: 为选中视频块接入拖拽调节尺寸 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：选中且可编辑的视频块显示左右 resize hit zone，交互方式、鼠标光标和 selection exclusion 与图片块保持一致。
  - 验收要点：拖拽视频块 resize 时保持视频宽高比，预览尺寸即时更新，拖拽结束后通过 updateVideoBlock 一次性提交 showWidth/showHeight。
  - 验收要点：非选中、只读或无编辑权限的视频块不显示 resize hit zone，拖拽过程不改变对象选择状态且不造成工具栏/正文布局跳动。
- [x] P004: 统一视频块对象菜单与对齐入口 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/controller/toolbar_controller.dart,lib/src/widgets/default_desktop_toolbar.dart,lib/src/widgets/default_mobile_toolbar.dart -->
  - 验收要点：视频块对象菜单提供左对齐、居中、右对齐、清除对齐，以及小/中/大尺寸预设和重置尺寸入口，行为与图片块对应能力一致。
  - 验收要点：选中视频块时桌面和移动工具栏可读取并设置视频块对齐状态，混合选择、清除对齐和只读权限表现正确。
  - 验收要点：对象菜单对齐/尺寸操作保留视频块既有元数据、选择状态和 undo/redo 行为。
- [x] P005: 补齐视频尺寸与对齐的模型和控制器测试 <!-- scope: test/core/model_test.dart,test/controller/video_block_controller_test.dart,test/controller/toolbar_controller_test.dart,test/codecs/rich_text_json_codec_test.dart -->
  - 验收要点：VideoBlockNode 的 showWidth/showHeight 能正确 round trip，旧 JSON 无尺寸字段时保持兼容。
  - 验收要点：insertVideo/updateVideoBlock 覆盖设置、清除、no-op、undo/redo 和非视频目标 no-op 场景。
  - 验收要点：ToolbarController 覆盖视频对象选择下的 alignment 读取、set/clear、混合对齐和无编辑权限 no-op 场景。
- [x] P006: 补齐视频块渲染和交互测试 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart,test/widgets/media_resolver_test.dart,test/widgets/editor_golden_test.dart -->
  - 验收要点：widget 测试覆盖视频块按 showWidth/showHeight 渲染、left/center/right 对齐定位、占位内容和自定义 resolver 内容不会越界。
  - 验收要点：widget 测试覆盖选中视频块 resize 手柄展示、拖拽提交尺寸、只读状态隐藏手柄，以及拖拽不破坏选择和工具栏 overlay 锚点。
  - 验收要点：对象菜单测试覆盖视频块尺寸预设、重置尺寸、对齐设置和清除对齐，并验证视频 metadata 不丢失。

  - 验收要点：最终验收命令为 flutter test
