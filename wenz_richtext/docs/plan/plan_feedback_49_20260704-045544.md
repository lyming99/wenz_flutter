# 开发计划：反馈 #49 — 块操作按钮位置固定、间距统一 8dp

## 需求分析

当前 `_BlockDragHandleOverlayState.build()` 中，块操作拖拽手柄（drag handle）的横向位置会根据当前块是否存在折叠按钮而改变：

- **有折叠按钮时**：handle 在 x=0，fold 在 x=36，content 在 x=68，间距 8dp。
- **无折叠按钮时**：handle 滑动到 x=32（即折叠按钮右边缘对齐的位置），content 仍在 x=68，handle 与 content 间距 40dp。

反馈要求：
1. 块操作按钮（拖拽手柄）位置固定，**不因折叠按钮缺失而改变** → handle 始终在左边缘 x=0。
2. 块操作按钮、折叠按钮、正文三者间距视觉一致，**一律 8dp 紧凑间距** → 无折叠时 content 应紧跟 handle 之后（28+8=36），而非保持不变 68dp。

### 影响范围

- `lib/src/widgets/wenz_rich_text_editor.dart` — `_BlockDragHandleOverlayState.build()` 布局计算逻辑
- `lib/src/widgets/block_renderer_registry.dart` — `BlockDragHandleSpec.railWidth` 可能需要新增辅助常量/方法
- `test/widgets/wenz_rich_text_editor_test.dart` — 布局断言需要与新间距对齐
- `test/widgets/editor_golden_test.dart` — 黄金图像测试的 railWidth 断言可能需要更新

### 当前布局常量

| 常量 | 值 | 说明 |
|---|---|---|
| `_kHeadingCollapseSlotWidth` | 24.0 | 折叠按钮槽宽 |
| `BlockDragHandleSpec.railWidth` | 68.0 | 预留轨宽 (28+8+24+8) |
| `BlockDragHandleSpec.chromeGap` | 8.0 | chrome 元素间距 |
| `BlockDragHandleSpec.gapToContent` | 8.0 | chrome 到内容间距 |
| `BlockDragHandleSpec.hitSize` | 28.0 | 拖拽手柄触控尺寸 |

### 目标布局

**有折叠按钮的块（如标题）**：
```
[handle:0-28] <8> [fold:36-60] <8> [content:68+]
```

**无折叠按钮的块（如正文、代码块）**：
```
[handle:0-28] <8> [content:36+]
```
