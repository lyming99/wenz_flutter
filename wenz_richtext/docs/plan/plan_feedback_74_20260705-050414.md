# 修复合并表格边界拖拽与展开后滚动回跳

## 需求概要

反馈 #74 包含两个编辑器交互问题：表格单元格合并后，合并区域内部已不可见的列边界仍会挂载列宽拖拽命中区；展开折叠内容后，编辑器在用户向上滚动时反复自动滚回当前光标位置。项目中表格渲染、列宽手柄、折叠投影和 caret 自动滚动逻辑主要集中在 lib/src/widgets/wenz_rich_text_editor.dart，计划在不改表格数据模型的前提下按可见边界段控制拖拽命中，并区分用户滚动、折叠展开重测量与程序化光标跳转，保留必要的自动滚动能力。

## 任务拆解

- [x] P001: 按可见表格边界限制合并单元格列宽拖拽 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：当 TableCellNode.columnSpan 或 rowSpan 覆盖某个内部列边界时，该合并区域内部不可见边界不挂载可拖拽命中区，也不显示 resize 语义。
  - 验收要点：拖拽合并单元格中间位置不会调用 onColumnResize，也不会写入或改变对应 TableModel.columnWidths。
  - 验收要点：未被合并覆盖、仍真实可见的相邻单元格列边界继续支持拖拽调整列宽，现有未合并表格的列宽调整行为保持不变。
- [x] P002: 补充合并表格列宽拖拽回归覆盖 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart -->
  - 验收要点：覆盖横向合并单元格内的中间列边界不可拖拽，拖动后 columnWidths 不发生变化。
  - 验收要点：覆盖混合合并与未合并行时，合并区域内部边界不可拖拽，但未合并行中真实可见的同一列边界仍可调整列宽。
  - 验收要点：覆盖普通未合并表格的现有 table-resize 手柄仍可拖动并保存显式列宽。
- [x] P003: 调整折叠展开后的 caret 自动滚动触发策略 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/controller/outline_controller.dart -->
  - 验收要点：用户主动展开或收起 heading 内容后，如果当前 caret 位置没有变化，编辑器不会无条件把视口滚回 caret。
  - 验收要点：展开内容引发的块高度重测量不会在用户继续向上滚动时反复安排 _scrollCaretIntoView，避免视口回跳循环。
  - 验收要点：当 selection 真的位于被折叠隐藏的内容中时，expandToRevealSelection 仍能展开相关 heading，并在需要时保持程序化 reveal 行为。
- [x] P004: 完善用户滚动识别并保留程序化光标跳转 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：鼠标滚轮、触控板、触摸拖动和滚动条拖动等用户滚动都能进入自动滚光标的抑制窗口。
  - 验收要点：连续用户滚动和展开后的布局重测量期间，caret 未变化时不会因为 extent 更新把滚动位置刷新回光标。
  - 验收要点：controller.setSelection、PageUp/PageDown、快捷键移动光标等程序化 caret 跳转仍能在 caret 移出视口时滚动到目标位置。
- [x] P005: 补充展开后向上滚动不回跳的回归覆盖 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart -->
  - 验收要点：构造含折叠 heading 和较长内容的文档，展开内容后用户向上滚动，后续 pump 和块高度更新不会把 scroll offset 拉回展开前的 caret 位置。
  - 验收要点：覆盖展开后多次连续向上滚动时 scroll offset 能持续向上变化，不出现反复回跳导致无法往上滚动。
  - 验收要点：覆盖程序化跳转到远处 caret 的既有自动滚动能力仍生效，避免为修复用户滚动回跳而破坏 reveal/caret jump 场景。
- [x] P006: 完整验收 <!-- scope: validation -->
  - 验收要点：最终验收命令为 flutter analyze
  - 验收要点：命令退出码为 0，没有新增 analyzer error 或 warning。
  - 验收要点：合并单元格内部不可见列边界不再支持拖拽调整列宽，未合并或真实可见的列边界仍可正常拖拽。
  - 验收要点：展开折叠内容后，用户向上滚动不会被重复刷新回当前光标位置，程序化光标跳转和隐藏 selection reveal 行为保持可用。
  - 验收要点：新增或调整的回归覆盖聚焦表格列宽拖拽、heading 展开、用户滚动抑制和程序化 caret 自动滚动，不引入无关业务改动。
