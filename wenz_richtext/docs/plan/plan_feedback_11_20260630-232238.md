# 反馈 #11 开发计划：Windows 选择文件插入图片卡死无反馈

## 来源
- 类型：反馈
- 编号：11
- 生成时间：2026-06-30 23:22:38
- 原始反馈：windows端：选择文件插入图片，过程中卡死界面，没有动静

## 需求理解
- 当前项目已完成块级图片插入基础能力：`WenzRichTextController.insertImage`、`ToolbarController.insertImage`、`ImageBlockNode.file` 和 example 端 `file_selector.openFile` 均已接入。
- Windows 端用户感知问题集中在 example 的 `_insertImage()` 交互链路：点击工具栏后直接等待系统文件选择器返回，期间没有忙碌状态；异常被静默吞掉；选择大图后 `Image.file` 直接按原图源进入预览，可能造成 UI 线程/渲染管线明显卡顿，用户看到“没有动静”。
- 核心 package 的职责边界仍应保持轻依赖：不把文件选择器或图片解码库加入根 `pubspec.yaml`；本次优先修复 example/宿主 UI 的 Windows 选择与本地预览体验，并补齐可测试状态。
- 目标体验：点击“插入图片”后按钮进入忙碌/禁用状态并有可见反馈；取消选择能恢复；选择失败/路径不可用有明确提示；选择大尺寸本地图片不会长时间冻结主界面，至少能快速插入 block 并显示加载/失败兜底。

## 影响范围
- 文件选择与工具栏状态：`example/lib/main.dart`。
- 本地图片预览：`example/lib/local_image_view_io.dart`、`example/lib/local_image_view_stub.dart`。
- 自动化测试：`example/test/widget_test.dart`，必要时补充根测试中与 media resolver 回归相关的断言。
- 文档：README 或 docs 中关于本地图片文件选择、Windows 大图预览和错误反馈的说明。

## 任务拆解
- [x] P001: 建立图片选择忙碌状态与错误反馈 <!-- scope: example/lib/main.dart -->
  - 验收要点：`_insertImage()` 进入文件选择前设置可观察的忙碌状态，并在 `finally` 中恢复，避免异常、取消或早退后工具栏永久不可用。
  - 验收要点：工具栏“插入图片”按钮在忙碌期间禁用或展示进度反馈，防止 Windows 上重复点击触发多个系统文件选择流程。
  - 验收要点：`openFile` 抛异常、返回空对象、路径为空或文件不可用时不再静默失败，应通过 `SnackBar`/状态文本等方式给出简短错误提示，同时不修改文档、不新增历史记录。
  - 验收要点：取消选择时只恢复 UI 状态，不提示错误、不插入图片、不影响撤销栈。
- [x] P002: 优化 Windows 本地图片预览解码路径 <!-- scope: example/lib/local_image_view_io.dart,example/lib/local_image_view_stub.dart,example/lib/main.dart -->
  - 验收要点：本地图片 helper 对空路径、非 file scheme、Windows 盘符路径、文件不存在或不可读路径有明确分支，失败时返回可回退的占位或错误 widget，不向 editor 抛异常。
  - 验收要点：IO 平台本地图片预览使用受控尺寸解码策略，例如 `cacheWidth`/`cacheHeight` 或等价的缩略预览上限，避免把超大原图完整解码到编辑器预览导致 Windows 界面长时间无响应。
  - 验收要点：图片加载中和加载失败状态可见，失败文案不阻塞编辑器布局；网络图片预览逻辑保持不回归。
  - 验收要点：Web/非 IO stub 继续不直接导入 `dart:io`，不破坏 example 的跨平台编译边界。
- [x] P003: 补充图片选择流程自动化测试 <!-- scope: example/test/widget_test.dart -->
  - 验收要点：测试覆盖文件选择成功路径：fake selector 返回 Windows 本地路径后，文档新增 `ImageBlockNode`，`file`、`caption`、`altText` 字段正确。
  - 验收要点：测试覆盖取消路径：fake selector 返回 `null` 时文档 block 数、图片数和撤销状态保持不变，忙碌状态能恢复。
  - 验收要点：测试覆盖异常路径：fake selector 抛错或返回空路径时不插入图片，并能观察到错误反馈或恢复后的按钮状态。
  - 验收要点：测试覆盖重复点击保护：图片选择进行中再次点击不会发起第二次文件选择调用。
- [x] P004: 更新 Windows 本地图片插入说明 <!-- scope: README.md,docs/rendering.md,docs/api_reference.md -->
  - 验收要点：文档说明核心包只保存 `ImageBlockNode.file` 并通过 `MediaResolver` 渲染，系统文件选择与错误提示由宿主/example UI 负责。
  - 验收要点：文档补充 Windows 本地图片选择的推荐交互：选择中禁用按钮、取消不报错、异常给出提示、大图预览应限制解码尺寸或使用缩略图。
  - 验收要点：文档示例与 example 实现保持一致，不引导业务方在根 package 中新增平台文件选择依赖。

## 总体验收标准
- 最终验收命令：在仓库根目录执行 `flutter pub get`，要求依赖解析成功且根 package 不新增运行时文件选择依赖。
- 最终验收命令：进入 `example` 目录执行 `flutter pub get`，要求 example 依赖解析成功。
- 最终验收命令：执行 `dart format example/lib/main.dart example/lib/local_image_view_io.dart example/lib/local_image_view_stub.dart example/test/widget_test.dart`，要求格式化完成且无非预期文件变更。
- 最终验收命令：在仓库根目录执行 `flutter analyze`，要求无新增 analyzer error；若存在既有问题，需在进度区记录并证明与本反馈无关。
- 最终验收命令：进入 `example` 目录执行 `flutter analyze` 与 `flutter test --reporter expanded`，范围覆盖 example 工具栏图片选择、fake 文件选择器成功/取消/异常路径和本地图片 helper，要求全部通过。
- 手工验收范围：在 Windows 桌面执行 `cd example && flutter run -d windows`，点击工具栏“插入图片”分别验证取消选择、选择普通 jpg/png、选择大尺寸图片、选择损坏或不可读图片、连续快速点击、插入后撤销/重做。
- 通过标准：文件选择期间有明确忙碌/禁用反馈；取消后界面恢复且文档不变；异常路径有提示且不崩溃；选择有效图片后能在当前插入位置生成图片 block 并预览或显示清晰加载/失败状态；大尺寸图片不会造成长时间无响应；所有自动化命令退出码为 0。
