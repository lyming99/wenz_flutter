# 参考 wenz_editor 实现手机工具栏

## 需求概要

需求 #59 要求参考 D:\project\GitHub\wenz_flutter\wenz_editor 的手机工具栏，在 wenz_richtext 中补齐可实际用于手机端的默认工具栏。当前项目已经有 WenzDefaultMobileToolbar、WenzMobileToolbarStyle、buildDefaultMobileToolbar 和对应测试，但实现更接近一个独立展开面板：example 仍始终渲染桌面工具栏，默认手机工具栏缺少参考项目的底部承载结构、左侧插入入口、右侧收起键盘入口、插入/格式底部面板切换、普通编辑与选区状态下的工具项优先级差异；部分参考操作如分割线和文字背景色/高亮也尚未通过 ToolbarController 暴露。计划在保持现有 ToolbarController、WenzToolbarItemRegistry、Bootstrap 生命周期归属不变的前提下，补齐手机工具栏的底部交互、命令能力、示例接入和测试覆盖，使手机端可通过默认入口完成常用插入、段落格式、列表、缩进、对齐、颜色、链接、媒体和扩展工具项操作，桌面默认工具栏行为保持不变。
