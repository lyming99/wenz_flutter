# 反馈 #43 开发计划：块工具栏按钮改为连体胶囊样式

- 反馈编号：43
- 生成时间：2026-07-04 02:17:14
- 反馈内容：各个块工具栏按钮样式较丑，应该是连体胶囊，图标按钮在背景上，而不是每个图标按钮都有个背景胶囊，只有hover状态，按钮才会显示背景高亮

## 背景与现状

当前所有块级悬浮工具栏（表格工具栏、媒体对象块工具栏、代码块复制按钮、文件块操作菜单、块更多菜单等）的图标按钮由 `lib/src/widgets/wenz_rich_text_editor.dart` 中的 `_blockToolbarIconButtonStyle()` 统一提供样式。

该函数通过 `IconButton.styleFrom()` 为每个按钮单独设置：

- `backgroundColor`: 每个按钮各自一个独立胶囊背景（浅色 `0xFFE9ECEF`，深色 `0xFF3A3B3F`），使每个按钮看起来像独立的药丸形状
- `disabledBackgroundColor`: 禁用态独立背景
- `shape: RoundedRectangleBorder(borderRadius: 16px)`：全圆角（按钮尺寸 32px 的一半），形成单独胶囊

这些按钮被放入 `_MinimalFloatingToolbarSurface`（已提供一个连体圆角背景容器）后，每个按钮各自又有独立背景胶囊叠加在上面，导致视觉上每个按钮都像一个独立胶囊，而非一个整体连体胶囊中嵌着的图标。

反馈要求改为：
1. 工具栏整体呈现连体胶囊（conjoined capsule），即一个共享的圆角背景承载所有按钮
2. 单个图标按钮默认无独立背景，直接坐在共享背景上
3. 仅 hover 时单个按钮才显示背景高亮

## 目标

- 所有块级工具栏（表格悬浮工具栏、媒体对象块工具栏、文件操作工具栏、代码块复���按钮、块更多菜单等）的图标按钮默认背景透明，不再显示独立胶囊
- `_MinimalFloatingToolbarSurface` 的共享背景作为连体胶囊的视觉效果，图标按钮透明地坐于其上
- 单个按钮在 hover/focus/pressed 状态下仍显示半透明叠加高亮，提供视觉反馈
- 工具栏整体外观、尺寸、间距、对齐和交互行为不变
- 移除因样式调整而不再使用的背景色常量和辅助函数
- 不改变任何编辑器 API、controller、浮层生命周期或定位逻辑
