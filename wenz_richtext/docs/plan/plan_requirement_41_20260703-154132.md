# 需求 #41 开发计划：收紧 todo 块左侧 checkbox 尺寸与间距

- 需求编号：#41
- 生成时间：2026-07-03 15:41:32
- 需求内容：todo 块左侧的 check 按钮宽度尺寸要小，间距要小，避免占用太多空白。

## 背景与影响范围

当前 todo 块由 `lib/src/widgets/wenz_rich_text_editor.dart` 的 `_TextBlockRenderer` 默认渲染：左侧使用 `_TodoCheckbox`，再通过 `_kTodoTextGap` 与正文分隔，并由 `_kTaskListPaddingLeft` 控制整行起始内边距。现有常量为 `_kTodoCheckboxWidth = 24.0`、`_kTodoCheckboxHeight = 28.0`、`_kTodoTextGap = 10.0`、`_kTaskListPaddingLeft = 8.0`，widget 回归测试已在 `test/widgets/wenz_rich_text_editor_test.dart` 中断言 checkbox 尺寸为 `Size(24, 28)`，并验证单行、多行 todo 的首行对齐和换行缩进。

本需求应只调整默认 todo 渲染层的视觉布局，不改变文档模型、`BlockAttributes.listType/checked`、checkbox 切换命令、Markdown/HTML/JSON 序列化语义，也不影响业务自定义 block renderer 的扩展入口。

## 实施策略

采用“小范围 token 调整 + 布局回归更新”的方案：先收紧 todo checkbox 外框宽度和左侧/正文间距，再确认 `_todoTextStyle` 的行高兜底仍能让 checkbox 与文字首行居中，最后更新既有 widget 测试中对尺寸、间距、对齐和交互的断言。对有序 todo（`listType == 'ordered'` 且 `checked != null`）需要保留编号列与 checkbox 的相对顺序，避免普通有序/无序列表被本次改动误影响。
