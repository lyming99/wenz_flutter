# 修复链接打开与中文文案

## 需求概要

反馈 #88 指出链接无法打开且需要显示中文。附件截图显示链接悬浮浮层仍展示英文 Edit/Open，且 Open 处于禁用态；结合代码可知链接打开依赖 WenzRichTextEditor.onOpenLink 回调，example 侧通过 url_launcher 执行实际打开。计划需要打通示例/集成层链接打开路径，并将链接相关默认 UI 文案中文化。

## 任务拆解

- [x] P001: 打通链接打开回调到实际浏览器打开 <!-- scope: example/lib/main.dart,lib/src/integration/wenz_editor_bootstrap.dart,lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：example 工作台中的正文链接在悬浮时“打开”按钮为可点击状态，而不是灰色禁用态。
  - 验收要点：点击“打开”或 Ctrl/Cmd+点击链接时，http/https 链接会通过宿主 onOpenLink 路径交给 url_launcher 打开。
  - 验收要点：空 URL、无法解析的 URL 或不支持的 scheme 不抛异常，并且不会改变当前文档内容或选择状态。
  - 验收要点：核心包仍保持回调优先的设计，不在 wenz_richtext 核心依赖中直接引入平台 URL launcher。
- [x] P002: 中文化链接悬浮浮层 <!-- scope: lib/src/widgets/link_hover_overlay.dart -->

- [x] P003: 中文化链接编辑弹窗 <!-- scope: lib/src/widgets/link_edit_dialog.dart,lib/src/widgets/default_desktop_toolbar.dart -->

  - 验收要点：从工具栏新增/编辑链接和从悬浮浮层编辑链接时，共用同一套中文链接编辑弹窗。
  - 验收要点：移除链接、取消编辑、提交修剪后的 URL 的返回值语义保持不变。
- [x] P004: 更新链接交互覆盖 <!-- scope: test/widgets/link_edit_dialog_test.dart,test/widgets/wenz_rich_text_editor_test.dart,example/test/widget_test.dart -->
