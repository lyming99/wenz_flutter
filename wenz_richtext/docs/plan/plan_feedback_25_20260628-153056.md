## 原始内容
连续的引用块，应该使用连续的背景，目前存在间距

## 需求理解
- “连续的引用块”指文档中前后相邻、均为 `BlockType.quote` 的文本块序列；当前每块各自渲染独立的 `_QuoteBlockSurface` 背景（`surfaceContainer` 填充 + 仅尾端圆角 + 4px `primary` 左侧强调条 + `EdgeInsetsDirectional.fromSTEB(22, 8, 18, 8)` 内边距），且块间通过 `_spacingBetweenBlocks` 产生 `_kDefaultBlockSpacing` 间距，导致相邻引用块的背景矩形之间出现可见间隙，而非连续成段。
- 块布局是虚拟化的绝对定位 `Stack`（`_MeasuredVirtualBlockList`）：每块由 `_MeasuredBlockExtent` 独立度量高度、按 `layoutFor`/`offsetFor` 计算的 `top` 绝对定位。因此不能把连续引用合并成单个容器渲染，否则会破坏按块度量、虚拟化回收与 keepAlive；正确做法是让相邻引用块的背景在视觉上拼合。
- 视觉拼合需要三处协同改动：①`_spacingBetweenBlocks` 对“引用↔引用”返回 0，消除背景间隙；②沿渲染上下文（仿既有 `listMarker` 由宿主按 `sourceBlocks` 预计算的先例）把“当前引用块在连续分组中的首/尾位置”贯通到 `_QuoteBlockSurface`；③`_QuoteBlockSurface` 依据该位置只保留外端圆角、重新分配上下内边距，并保持左侧强调条贯通，使多块拼成一段无缺口、无加倍留白的连续背景。
- 需求目标是纯渲染层修复（间距、圆角、强调条、内边距），不改变文档模型、`ToggleQuoteCommand`、Markdown/HTML 序列化、选区与光标命中、查找高亮、块度量与 keepAlive 行为；单个引用块、quote→非quote→quote 的多独立分组、引用与标题/列表/代码块/段落相邻等场景的外观与间距不得回归。

## 任务拆解
- [x] P001: 明确连续引用块背景连续的视觉语义与边界 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/widgets/block_renderer_registry.dart,docs/rendering.md -->
  - 验收要点：定义“背景连续”的视觉目标——相邻引用块之间无垂直间隙、圆角只在整段引用的首尾、左侧 4px `primary` 强调条贯通、合并后内部文本行距自然，不存在拼接缝隙或圆角缺口。
  - 验收要点：明确分组边界——只有前后相邻且均为 `BlockType.quote` 的文本块才属同一连续分组；quote→非quote→quote 形成两个独立分组，各自独立保留外端圆角。
  - 验收要点：确认本次仅改渲染层（间距、圆角、强调条、内边距），不改动文档模型、引用切换命令、序列化、选区/光标命中、虚拟列表度量与 keepAlive。
  - 验收要点：确认边界场景覆盖：单个引用、文档首/尾的引用、引用与标题/列表/代码块/段落相邻、3 个及以上连续引用、引用内含 todo/列表前缀的兼容情况。

- [x] P002: 消除连续引用块之间的垂直间距 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_spacingBetweenBlocks` 在 `previous` 与 `next` 均为 `BlockType.quote` 文本块时返回 0，使两块背景物理相接、无间隙。
  - 验收要点：保留自定义间距早退逻辑——当 fallback 与 `_kDefaultBlockSpacing` 差异超过阈值时仍按外部传入的 `blockSpacing` 返回，不把连续引用间距强制清零。
  - 验收要点：`layoutFor`/`offsetFor` 产出的连续引用块 offset 紧邻相接且 `totalExtent` 同步收缩；非引用相邻（列表项、嵌套列表、标题上下 margin、代码块、段落）间距完全不变。
  - 验收要点：`flutter analyze` 通过，列表项间距、嵌套列表间距、标题 margin 相关既有行为无回归。

- [x] P003: 为引用块渲染上下文增加连续分组位置信息 <!-- scope: lib/src/widgets/block_renderer_registry.dart,lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：在 `BlockRenderContext` 增加兄弟派生字段（仿 `listMarker`），表达当前引用块在其连续引用分组中的位置（如首块/尾块标志位），字段对自定义渲染器可见并附文档注释。
  - 验收要点：宿主在构建块上下文处（与 `_listMarkersFor` 同侧）按 `sourceBlocks` 预计算每个引用块的首/尾分组位置，非引用块取空值，且随文档变更刷新。
  - 验收要点：将该字段沿 `_KeepAliveBlock` → 行级块上下文 → `_defaultTextBlockRenderer` → `_TextBlockRenderer` → quote 分支 → `_QuoteBlockSurface` 贯通传递，不破坏既有构造参数顺序与相等性判断。
  - 验收要点：字段缺省（如自定义渲染器手建上下文）时回退为“独立引用块”，渲染结果与改造前单引用一致。

- [x] P004: 调整 _QuoteBlockSurface 圆角与内边距以合并背景 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`_QuoteBlockSurface` 依据分组位置调整圆角——首块只保留上端圆角、尾块只保留下端圆角、中间块不圆角，使连续引用拼成无缺口的连续矩形。
  - 验收要点：垂直内边距按分组位置重新分配（首块保留上边距、尾块保留下边距、中间块去除/收窄上下边距），消除拼接处加倍的留白，合并后文本行距均匀自然。
  - 验收要点：左侧 4px `primary` 强调条在连续引用分组内贯通、无断点无错位；背景 `surfaceContainer` 颜色与宽度在拼接处一致。
  - 验收要点：单个引用块（独立分组）仍保持原有圆角与上下内边距外观不变；quote 与非 quote 相邻处各分组独立圆角，互不影响。

## 总体验收标准
- 计划中所有 checkbox 任务完成，且每个任务的验收要点均有对应实现、测试或记录说明。
