# 修复视频块首次点击无法播放

## 需求概要

反馈 #25 指出视频块需要点击 2 次才开始播放。结合项目代码，视频块由 `lib/src/widgets/wenz_rich_text_editor.dart` 中 `_withSelectableVideoBlock`、`_BlockObjectSelectionSurface`、`_VideoBlockContent` 与 resolver 输出共同组成，示例真实播放器在 `example/lib/example_video_player.dart` 内通过 `GestureDetector` 单击切换播放；编辑器外层 `SelectionGestureOverlay` 会在同一次点击里执行对象块选择并触发重建，存在首击先选中/重建、子播放器 onTap 未能稳定生效的风险。计划应修复视频 resolver 子组件的首击事件路由，使第一次点击即可进入播放，同时保持视频块选中、对象工具栏、双击预览、占位渲染和拖选行为不回退。

  - 验收要点：当 VideoBlockNode 通过 MediaResolver 渲染真实播放器时，用户在播放器画面或播放按钮区域单击一次即可触发 resolver 子组件的播放切换回调，不需要先点击一次选中视频块。
  - 验收要点：编辑器级对象块选择逻辑不得在同一次 pointer 序列中提前重建或替换视频 resolver 子树，导致子组件 GestureDetector/InkWell 的 onTap 丢失。
  - 验收要点：修复应限定在视频块交互路由或对象块选择命中处理，不改变图片、文件、divider、block embed 和普通文本块的点击/拖选语义。
