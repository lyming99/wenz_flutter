# 修复粘贴图片比例识别问题

## 需求概要

反馈 #28 指出粘贴图片的比例识别仍然不正确。当前项目的外部图片粘贴链路会从剪贴板或拖拽输入读取图片字节/文件，再通过 `ExternalImageBlockDescription.width/height` 写入 `ImageBlockNode`，编辑器渲染时按 `showWidth/showHeight`、原始 `width/height`、已测量 frame 或占位比例依次推导显示比例。计划需要收敛图片尺寸识别、粘贴尺寸透传和渲染比例优先级，重点覆盖 JPEG EXIF 方向、文件 URI 与内存剪贴板双 flavor、无尺寸或异常元数据回退等场景，确保粘贴后的图片块按真实展示方向保持正确宽高比。

## 任务拆解

- [x] P001: 修正外部图片像素尺寸识别 <!-- scope: lib/src/input/external_image_input.dart,lib/src/input/external_image_store_io.dart -->
  - 验收要点：PNG、GIF、WebP、BMP 与普通 JPEG 的 `ExternalImagePixelSize` 仍能从可信图片字节中读取正数宽高。
  - 验收要点：带 EXIF Orientation 的 JPEG 粘贴图片按最终展示方向产出宽高，Orientation 5、6、7、8 等旋转场景会交换宽高，避免竖图被当成横图。
  - 验收要点：文件路径和 file:// URI 输入通过读取实际文件字节得到与内存图片一致的尺寸结果，不能只依赖扩展名或剪贴板文件名。
  - 验收要点：损坏、不完整、无尺寸或不支持的图片元数据返回 null 并保留现有降级路径，不阻断图片粘贴或拖拽插入。
- [x] P002: 统一粘贴图片尺寸透传与比例优先级 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/input/clipboard_service.dart,lib/src/controller/wenz_rich_text_controller.dart,lib/src/widgets/media_resolver.dart -->
  - 验收要点：外部图片粘贴或拖拽生成的 `ImageBlockNode.width/height` 使用修正后的真实展示尺寸，`showWidth/showHeight` 默认保持为空，避免把错误展示尺寸固化为手动 resize 状态。
  - 验收要点：剪贴板同时提供文件 URI/path 与内存图片 flavor 时，尺寸选择能使用更可靠的候选结果，不因先读取到文件候选而保留错误或缺失比例。
  - 验收要点：编辑器图片 frame 的 `_imageAspectRatio` 优先采用有效 `showWidth/showHeight`，其次采用修正后的原始 `width/height`，再使用测量 frame 和占位比例回退；已手动 resize 的图片继续按手动尺寸显示。
  - 验收要点：MediaResolver 自定义图片内容继续在有限 frame 内布局，接收到的 `ImageBlockNode` 元数据与粘贴后的宽高保持一致，不破坏既有 resolver 成功、返回 null 或抛错的回退行为。
- [x] P003: 补充外部图片尺寸解析用例覆盖 <!-- scope: test/input/external_image_input_test.dart -->
  - 验收要点：新增或更新测试覆盖带 EXIF Orientation 的 JPEG 字节，断言旋转后的宽高与最终展示方向一致。
  - 验收要点：新增文件路径和 file:// URI 准备流程的尺寸断言，确保 `ExternalImageIoStore.prepare` 对内存图片和磁盘图片都返回正确 `ExternalImageBlockDescription.width/height`。
  - 验收要点：保留并扩展 PNG、GIF、WebP、BMP、普通 JPEG、损坏字节和空文件等既有场景，确认尺寸解析失败时仍按现有 rejection 或 graceful degradation 行为处理。
- [x] P004: 补充粘贴与渲染比例用例覆盖 <!-- scope: test/input/clipboard_service_test.dart,test/widgets/wenz_rich_text_editor_test.dart,test/widgets/media_resolver_test.dart -->
  - 验收要点：ClipboardService 将外部图片描述转换为 `ImageBlockNode` 时保留修正后的 width/height，且不写入 showWidth/showHeight。
  - 验收要点：快捷键粘贴外部图片后，controller 文档中的图片块宽高与 store 返回值一致，多图粘贴顺序、caption/altText、undo 和焦点行为不回归。
  - 验收要点：固定宽度编辑器中，新粘贴图片按修正后的比例计算 frame 高度；竖图、横图、极宽/极高图和无尺寸图片分别覆盖正确比例、边界 clamp 与占位回退。
  - 验收要点：MediaResolver 成功渲染、返回 null、抛错以及手动 resize 后的图片 frame 均保持可预期宽高比，选择描边、resize hit zone、对齐和预览入口不因比例修正错位。
