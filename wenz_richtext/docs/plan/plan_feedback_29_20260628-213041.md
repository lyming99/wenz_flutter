# 反馈 #29 开发计划：视频组件鼠标样式改为非编辑状态

- 反馈编号：#29
- 生成时间：2026-06-28
- 反馈内容：视频组件，应该像附件组件一样，鼠标样式应该是非编辑状态鼠标模式

## 背景与根因分析

编辑器通过 `SelectionGestureOverlay`
（`lib/src/widgets/selection_gesture_overlay.dart`）在整个可编辑内容外层包了一个
`MouseRegion`，其 `cursor` 在编辑态下为 `SystemMouseCursors.text`（文本 I-beam 光标），只读态为
`SystemMouseCursors.basic`（箭头）：

- `selection_gesture_overlay.dart:56-57` —— `cursor` 定义。
- `selection_gesture_overlay.dart:117-151` —— `MouseRegion` 与 `_resolvedCursor()`，仅区分滚动条 gutter（click）与其余区域（编辑态 text）。

附件组件（`FileBlockNode`）通过在 `_FileBlockContent` 外层用
`FocusableActionDetector(mouseCursor: SystemMouseCursors.click, ...)` 覆盖了该光标
（`wenz_rich_text_editor.dart:10922-10923`），因此鼠标悬停在附件卡片上显示的是非编辑态的
click 光标，而不是 I-beam 文本光标。

视频组件（`VideoBlockNode`）的渲染链路为：
`_defaultVideoBlockRenderer`（`wenz_rich_text_editor.dart:5759`）
→ `_withSelectableVideoBlock`（`wenz_rich_text_editor.dart:6015`）
→ `_MediaBlockChrome`（`wenz_rich_text_editor.dart:11248`）
→ `_BlockObjectSelectionSurface`（`wenz_rich_text_editor.dart:8424`）
→ `_VideoBlockContent`（`wenz_rich_text_editor.dart:10107`）。

上述链路中没有任何一层设置 `MouseRegion`/`cursor`，因此视频块继承了 overlay 的文本 I-beam
光标，表现为“编辑态鼠标样式”。视频预览对话框 `_showVideoPreview`
（`wenz_rich_text_editor.dart:5917`）在独立的 `Dialog` 中渲染，不经过 overlay，不在本次范围。

结论：需要为视频块设置非编辑态鼠标光标，方式与附件组件一致。

## 修复方案

在视频块渲染路径中增加一个 `MouseRegion`，显式设置非编辑态光标，使其覆盖外层 overlay 的文本
I-beam 光标（Flutter 中最近祖先 `MouseRegion` 的 `cursor` 对命中区域生效，附件组件正是用同样
机制工作，方案已被验证可行）。

- 推荐改动点：`_withSelectableVideoBlock`（视频块专用包装器，视频独有，不影响图片/附件块），
  在其返回的 `_MediaBlockChrome` 外层包一层 `MouseRegion`；等价替代位置为 `_VideoBlockContent`
  顶部。
- 光标取值：与附件组件保持一致，使用 `SystemMouseCursors.click`（反馈明确要求“像附件组件一样”）。
  若更希望严格等于只读/非编辑态的箭头，可改用 `SystemMouseCursors.basic`，二者都能达到“非编辑态”
  目的；硬性要求是**不能是文本 I-beam（`SystemMouseCursors.text`）**。
- 保持视频块既有的选择高亮、双击预览（`onDoubleTap`）与点击选择语义不变。
