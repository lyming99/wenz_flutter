# 需求开发计划：Block 左侧拖拽调节行位置

## 来源
- 类型：需求

## 原始内容
增加block拖拽调节行功能，在block左侧增加拖拽按钮，这个按钮支持打开菜单，如果是拖拽，则调节block行位置

## 需求理解
- 在每个顶层 block 左侧增加统一的拖拽按钮/把手，作为 block 行级操作入口。
- 按钮点击或轻触时打开 block 操作菜单；拖拽时不打开菜单，而是根据拖拽落点调整 block 在文档中的行位置。
- 拖拽调节应覆盖普通文本块、标题、列表、引用、代码、callout、表格和对象块等顶层 block，并避免影响行内编辑、选区拖拽、表格列宽拖拽、图片尺寸调节等已有交互。
- 行位置调整应进入编辑器命令/历史体系，保证选区、撤销/重做、只读模式和自定义 block renderer 扩展点行为一致。

## 总体验收标准
