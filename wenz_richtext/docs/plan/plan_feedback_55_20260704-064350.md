# 反馈 #55 开发计划：表格 cell 选择、居中光标与文本高亮修复

## 需求描述

反馈指出表格 cell 选择算法存在两个问题：

1. 居中对齐 cell 的选择状态与光标渲染位置不正确。
2. 未选中的 cell 被渲染成选择高亮，需要区分 cell 高亮和文本高亮；这里强调的是文本高亮错误，cell 高亮本身是正确的。

## 项目分析

当前表格默认渲染集中在 `lib/src/widgets/wenz_rich_text_editor.dart`：

- `_TableBlockRenderer` 计算 `_TableGridMetrics`，并为每个可见 cell 渲染 `_TableCellSurface`。
- `_TableCellSurface` 外层负责 cell 背景、整格 selection 高亮与语义 selected 状态；内部通过 `_TextSelectionSurface` 绘制文本、文本 selection 高亮和 caret。
- `_shouldHighlightTableCell()` 负责整格高亮，现有实现会根据 `tableCellRange` 与 caret 端点矩形判断 cell 是否整格高亮。
- `_selectionRangeForPath()` 是通用文本高亮算法，按 `PositionPath.compare()` 在同一 block 内推导跨 path 的本地文本范围。表格矩形选区直接复用该算法时，容易把矩形内但文本未实际覆盖的 cell 当作文本 range 来绘制。
- 居中/右对齐文本依赖 `TextPainter`、`TextLayoutService`、`_TextSelectionSurface` 的 `maxWidth`、`textAlign`、`hitTestKey` 映射和 `_caretRectForTableSelectionEndpoint()` 的端点坐标计算，必须保证绘制、命中、IME caret 与 selection endpoint 使用同一套 inner-width 坐标。

主要影响范围：

- `lib/src/widgets/wenz_rich_text_editor.dart`
- `lib/src/rendering/text_layout_service.dart`
- `test/widgets/wenz_rich_text_editor_test.dart`
- `test/widgets/block_geometry_registry_test.dart`
- `docs/selection_engine.md`
- `docs/rendering.md`

## 任务拆解

- [x] P001: 修正表格 cell 文本高亮范围判定 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：表格矩形 cell 选区不再直接让 `_selectionRangeForPath()` 为每个跨过的 cell 生成文本高亮范围。
  - 验收要点：单个 cell 内部拖选文本时仍只绘制该 cell 内真实文本范围的 `_SelectionHighlightPainter`。
  - 验收要点：跨多个 cell 的矩形选区由整格高亮表达 cell 选中状态，未实际选中文本的 cell 不出现文本 selection 高亮 key 或非透明文本高亮 painter。
  - 验收要点：普通段落、代码块、callout 等非表格文本继续使用原有跨 block 文本高亮行为，不发生回归。

- [x] P002: 校准居中对齐 cell 的 caret 与 selection 端点几何 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/rendering/text_layout_service.dart -->
  - 验收要点：居中、右对齐和默认 start 对齐 cell 中，caret 绘制位置与 `TextPainter.getOffsetForCaret()` 的实际文本位置一致。
  - 验收要点：`_caretRectForTableSelectionEndpoint()` 与 `_TextSelectionSurface` 使用相同的 text span、offset mapper、textAlign、textDirection 和 cell innerWidth，避免 padding 或对齐偏移被重复计算或遗漏。
  - 验收要点：点击居中对齐 cell 的文本、左右 padding、上下居中留白时，命中仍解析到当前 cell 的 `tableCellText` path，并得到合理 offset。
  - 验收要点：IME/composition caret anchoring、上下方向键的 remembered caretX 不因修复发生明显偏移。

- [x] P003: 拆分 cell 高亮、文本高亮与 selected 语义状态 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：`highlightWholeCell` 只表示整格 cell 选中背景，不再隐式代表文本 range 高亮。
  - 验收要点：`_TableCellSurface` 的 `selected` 语义可表达当前 cell 属于表格选区，但不会导致内部 `_TextSelectionSurface` 绘制未选中文本高亮。
  - 验收要点：覆盖单元格 `covered == true` 仍不渲染、不参与 hit-test、不产生 selection highlight。
  - 验收要点：跨 block selection 覆盖整张表时，整格高亮仍正确覆盖可见 cell；表格内部纯文本选区只覆盖真实文本。

- [x] P004: 补充表格选择渲染与命中测试代码 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart,test/widgets/block_geometry_registry_test.dart -->
  - 验收要点：新增居中对齐 cell 的 collapsed caret 位置断言，caret x 坐标应落在居中文本对应的视觉位置，而不是 cell 左侧 padding 或整格起点。
  - 验收要点：新增居中对齐 cell 内部局部文本选择断言，只出现该 cell 的文本 selection 高亮。
  - 验收要点：新增多 cell 矩形选择断言，整格 cell 高亮正确，未实际选中文本的 cell 不出现文本高亮。
  - 验收要点：新增或扩展命中测试，覆盖居中 cell 文本左右 padding、短文本垂直居中留白、空 cell 的 offset 解析。

- [x] P005: 同步表格选择渲染契约文档 <!-- scope: docs/selection_engine.md,docs/rendering.md -->
  - 验收要点：文档明确区分表格 cell 高亮、文本 selection 高亮、语义 selected 三类状态。
  - 验收要点：文档说明居中/右对齐 cell 的 caret、hit-test 和 selection box 均以 cell padding 内的 text layout 坐标为准。
  - 验收要点：文档列出矩形 cell 选区与单 cell 文本选区的预期视觉差异，便于后续回归判断。

- [x] P006: 完整验收 <!-- scope: validation -->

1. `dart analyze`
2. `flutter test test/widgets/wenz_rich_text_editor_test.dart`
3. `flutter test test/widgets/block_geometry_registry_test.dart`

验收范围：

- 表格 cell 内文本 selection 高亮与整格 cell 高亮的职责边界。
- 居中、右对齐、默认 start 对齐 cell 的 caret 绘制位置、selection endpoint 计算与点击命中。
- 多 cell 矩形选区、单 cell 文本选区、跨 block 选区覆盖表格的渲染差异。
- 普通文本块、代码块、callout 等非表格文本 selection 的既有行为。

通过标准：

- 分析和测试命令全部通过，退出码为 0。
- 未选中的 cell 不再出现文本 selection 高亮；需要整格选中时仍保留正确 cell 高亮。
- 居中对齐 cell 的 caret 和 selection 高亮与文本视觉位置一致。
- 既有表格命中、空 cell、merged/covered cell、跨 block selection 行为无回归。
