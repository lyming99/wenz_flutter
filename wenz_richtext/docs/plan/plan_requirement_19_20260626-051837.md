## 原始内容
代码内容要支持行号显示

## 需求理解
- “代码内容”对应编辑器中的 `CodeBlockNode` / `BlockType.code`，当前代码块正文由 `_CodeBlockRenderer` 使用 `_TextSelectionSurface` 渲染，并支持语法高亮、横向滚动、选区、输入法组合态、查找高亮、语言切换和复制代码。
- 本需求目标是在代码块 UI 中展示 1-based 行号，帮助用户阅读多行代码；行号属于展示层能力，不应写入 `CodeBlockNode.code`、导出/导入 codec、剪贴板复制结果或命令历史内容。
- 行号数量应由代码文本的实际行数决定：单行代码显示 `1`，包含空行时空行也有行号，末尾换行产生的最后空行需要按编辑器现有代码文本语义稳定处理。
- 行号需要与代码正文逐行垂直对齐，且不影响现有代码文本 offset 映射、拖拽选区、光标、组合输入下划线、查找匹配高亮、Tab 缩进、语言标签和复制按钮。
- 如果后续产品希望支持开关，可在本次实现中预留样式/构建函数边界；但默认验收以代码块显示行号为准，不引入模型字段作为必要条件。
