# 新增可配置的快速添加文本块快捷键

## 需求概要

根据反馈 #21，为编辑器补齐快速添加空文本块的键盘入口：Ctrl+Enter 在当前块下方新增文本块，Ctrl+Shift+Enter 在当前块上方新增文本块，并复用现有 EditorShortcutConfiguration 体系，使宿主可以像其它快捷键一样覆盖、禁用或透传该快捷键。现有代码中快捷键解析集中在 lib/src/input/shortcut_manager.dart，执行分发集中在 lib/src/widgets/wenz_rich_text_editor.dart，块插入能力已有 InsertBlocksCommand 和 WenzRichTextController.insertBlocks，可在此基础上增加定向插入文本块的命令/控制器入口与回归测试。

## 任务拆解

- [x] P001: 扩展快捷键意图与默认 Ctrl+Enter 映射 <!-- scope: lib/src/input/shortcut_manager.dart -->
  - 验收要点：EditorShortcutIntent 新增用于在当前块上方和下方快速添加文本块的两个独立意图，命名能清晰表达插入方向。
  - 验收要点：默认快捷键将 Ctrl+Enter 解析为下方添加文本块，将 Ctrl+Shift+Enter 解析为上方添加文本块，并与现有 Ctrl 数字、Ctrl+Shift+T/L 等富文本快捷键写法保持一致。
  - 验收要点：主键盘 Enter 与小键盘 Enter 在该快捷键场景下行为一致，避免普通 Enter 现有拆分文本块语义被误改。
  - 验收要点：两个新增意图纳入写操作只读守卫，readOnly 下返回 ignored，不产生文档变更。
  - 验收要点：现有 EditorShortcutConfiguration 仍优先于内置 keymap，宿主可以通过 handled 覆盖、ignored 禁用、passThrough 交给外层处理，也可以通过 disabledIntents 禁用新增意图。
- [x] P002: 新增按当前选择上方或下方插入空文本块的控制器入口 <!-- scope: lib/src/core/commands/block_commands.dart,lib/src/controller/wenz_rich_text_controller.dart -->
  - 验收要点：新增空文本块时生成 BlockType.paragraph 的 TextBlockNode，不复制当前块的标题、列表、引用、代码或媒体类型。
  - 验收要点：当前选择位于普通文本块、代码块、媒体/对象块或表格单元格内时，都能按所在顶层块计算上方或下方插入位置。
  - 验收要点：选择跨多个顶层块时，上方插入到 selection.start 所在块之前，下方插入到 selection.end 所在块之后。
  - 验收要点：插入后选区折叠到新文本块开头，方便用户立即输入内容，并且该变更进入 undo/redo 历史。
  - 验收要点：无有效选择、空文档、越界 blockIndex 或只读权限受限时不抛异常，按现有命令风格返回 no-op 或 permission blocked。
- [x] P003: 将新增快捷键接入编辑器执行分发 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：_performShortcut 能处理新增的上方/下方添加文本块意图，并通过控制器入口提交变更。
  - 验收要点：快捷键执行前后保留现有隐藏内容展开、焦点、输入法同步、selection changed 回调和 lastChangedBlockIds 通知语义。
  - 验收要点：Ctrl+Enter 不再落入普通 Enter 拆分文本块路径，Ctrl+Shift+Enter 不触发选择扩展或段落拆分。
  - 验收要点：斜杠菜单、mention 搜索、公式编辑弹窗、代码块 Tab 和表格 Tab 等已有键盘拦截优先级不受影响。
  - 验收要点：宿主通过 shortcutConfiguration 覆盖或 passThrough 新增组合时，编辑器不会再执行内置添加文本块动作。
