# 反馈 #25 开发计划：连续引用块使用连续背景

- 反馈编号：#25
- 反馈内容：连续的引用块，应该使用连续的背景，目前存在间距
- 计划类型：bugfix / 视觉渲染优化
- 影响层：块垂直布局（间距/偏移层）+ 引用块渲染（widget 树层）

## 背景

当前每个引用块（`BlockType.quote`）都由 `_QuoteBlockSurface` 独立绘制：自带背景色（`scheme.surfaceContainer`）、右侧上下圆角（`BorderRadiusDirectional.only(topEnd:8, bottomEnd:8)`）、左侧 4px 强调条（`scheme.primary`）以及内部 padding（`EdgeInsetsDirectional.fromSTEB(22, 8, 18, 8)`）。

当多个引用块连续出现时：

1. **存在间距**：块之间的垂直间距由 `_spacingBetweenBlocks` 计算。该函数对「列表项↔列表项」有特判（返回更小的 `_kListItemSpacing`），但对「引用块↔引用块」没有特判，于是直接返回默认间距 `_kDefaultBlockSpacing`（≈ 正文字号 × 0.55），在两个引用背景之间产生一段空白。
2. **即便消除间距仍有缝隙**：每个引用块的右下角（`bottomEnd`）与下一个引用块的右上角（`topEnd`）都各自向内圆角，紧贴时右侧会出现内凹缺口；强调条虽为同色但被逐块绘制。
3. **缺少相邻上下文**：`BlockRenderContext`（`block_renderer_registry.dart:214`）与 `_TextBlockRenderer`（`wenz_rich_text_editor.dart:5907`）当前只携带 `block / blockIndex / blockCount`，不携带兄弟块信息，因此渲染器无法判断当前引用块是否处于连续连排之中（首段 / 中段 / 尾段 / 独立）。

## 目标

- 连续、缩进级别相同的引用块，背景连成一片（无可见缝隙），强调条贯通。
- 连排中仅最顶部保留上右圆角、仅最底部保留下右圆角，中段与拼接处不圆角，避免内凹缺口。
- 缩进级别不同（左右起始位置不同）的相邻引用块保持原有间距与各自圆角，不强行合并。
- 不影响其他块类型（段落、标题、列表、代码块等）的既有间距与渲染表现。

## 任务拆解

- [x] P001: 折叠连续引用块之间的垂直间距 <!-- scope: lib/src/widgets/wenz_richtext_editor.dart -->

  验收要点：
  - 新增 `_isQuoteBlock(BlockNode)` 辅助函数，判断 `TextBlockNode` 且 `type == BlockType.quote`（与既有 `_isListItemBlock` 风格一致）。
  - 在 `_spacingBetweenBlocks` 中新增特判：当 `previous` 与 `next` 均为引用块，且二者 `_blockIndentLevel` 相同时，返回折叠后的间距（0 或极小值，使背景首尾相接）；缩进级别不同时回落到默认间距，保持各自独立。
  - 该间距同时被 `offsetFor` / `layoutFor` 使用，修改后命中测试与光标几何（基于 `topFor`/`bottomFor`）需与视觉位置保持一致，不得引入光标错位。
  - 不得破坏「fallback 与默认间距不同时直接返回 fallback」以及「列表项特判」的既有分支。

- [x] P002: 引用块连排渲染为连续背景（圆角与强调条自适应） <!-- scope: lib/src/widgets/wenz_richtext_editor.dart,lib/src/widgets/block_renderer_registry.dart -->

  依赖 P001（二者改写同一文件的相邻关注点，建议在 P001 之后串行执行，避免并发冲突）。

  验收要点：
  - 在 `BlockRenderContext` 增加相邻引用块上下文（例如 `previousBlockType` / `nextBlockType`，或语义化的「是否处于同缩进引用连排及连排位置」标志），默认值保持向后兼容，不影响自定义渲染器。
  - 在编辑器构建 `BlockRenderContext` 处（`wenz_rich_text_editor.dart:4534` 一带）依据兄弟块填充上述上下文；并将其沿 `_TextBlockRenderer` 透传到 `_QuoteBlockSurface`。
  - 改造 `_QuoteBlockSurface`：依据连排位置决定圆角——独立引用块保持原有上下右圆角；连排首段仅保留下侧不圆角、顶部保留 `topEnd`；尾段仅顶部不圆角、底部保留 `bottomEnd`；中段上下拼接处均不圆角，消除右侧内凹缺口。
  - 强调条（左侧 4px `scheme.primary`）与背景色在连排内保持同色贯通，视觉上连为一片；连排内部建议收紧或保持合理纵向 padding，使相邻段落文字行距协调（不出现过大空白）。
  - 仅同缩进级别的相邻引用块视为连排；不同缩进（如现有 golden 用例中 indent:1 的引用块）按独立引用块处理，保留各自圆角与间距。
