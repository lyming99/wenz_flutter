# 反馈 #58 开发计划：表格 cell 居中显示时选择高亮渲染修复

## 需求描述

反馈指出：表格 cell 居中显示的情况下，选择高亮渲染存在问题。结合当前项目代码，最合理解释是表格单元格设置 `alignment: 'center'` 或继承 `TableModel.columnAlignments` 为 `center` 后，用户进行 cell 内文字选择或跨 cell 选择时，高亮区域与实际居中文本位置、cell 边界或相邻 cell 的选中状态不一致。

本计划只生成修复方案，不修改业务代码。

## 项目分析

当前表格渲染和选择高亮主要集中在 `lib/src/widgets/wenz_rich_text_editor.dart`：

- `_TableBlockRenderer` 负责计算 `_TableGridMetrics`，并把每个可见 cell 渲染为 `_TableCellSurface`。
- `_TableCellSurface` 同时承载整格高亮、语义 selected 状态和内部 `_TextSelectionSurface` 文本高亮。
- `_SelectionHighlightPainter` 通过 `TextLayoutService.selectionBoxes()` 绘制文字选择高亮，依赖 `textAlign`、`maxWidth` 和 `_InlineOffsetMapper` 与 `RichText` 使用同一套布局参数。
- `_selectionRectForTableCells()` 与 `_caretRectForTableSelectionEndpoint()` 用于跨 cell 选择的可视矩形约束，居中/右对齐 cell 必须与 `_TextSelectionSurface` 的实际文本坐标保持一致。
- `_shouldHighlightTableCell()`、`_shouldPaintTableCellTextSelection()` 和 `_isTableCellSemanticallySelected()` 已经区分整格高亮、文本高亮和语义选中，但 #58 表明居中场景仍需补齐渲染几何和回归覆盖。

现有测试基础：

- `test/widgets/wenz_rich_text_editor_test.dart` 已有 `table cell alignment selection` 分组，覆盖居中 caret、单 cell 文本选择、右对齐局部选择、跨 cell 选择和 merged/covered cell。
- `test/widgets/editor_golden_test.dart` 已有 `golden: table cell alignment per column`，但尚需针对“居中 cell + 选择高亮”补充更直接的视觉锁定。
- `lib/src/rendering/text_layout_service.dart` 封装 `TextPainter` 的 caret、hit-test 和 selection boxes，如果问题根因在 `getBoxesForSelection` 输入参数或缓存布局参数不一致，需要同步校准。

## 任务拆解

- [x] P001: 校准居中 cell 文本选择高亮的绘制坐标基准 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/rendering/text_layout_service.dart -->
  - 验收要点：`_SelectionHighlightPainter`、`_TextSelectionSurface`、`RichText` 与 `TextLayoutService.layout()` 对同一个居中 cell 使用一致的 `textAlign`、`textDirection`、`maxWidth` 和逻辑到渲染 offset 映射。
  - 验收要点：居中 cell 内的局部文字选择高亮绘制在实际文字所在区域，而不是从 cell 左侧 padding、整格宽度起点或相邻 cell 区域开始。
  - 验收要点：修复不能破坏左对齐、右对齐、justify、空 cell、inline embed 和 composition/caret 的既有布局逻辑。

- [x] P002: 修正表格 cell 文本高亮与整格高亮的分流逻辑 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：单个居中 cell 内部选中文字时，只绘制该 cell 的文本选择高亮，不额外绘制整格选择背景。
  - 验收要点：跨多个 cell 的表格选择仍由整格高亮表达，未实际选中文字的 cell 不出现文本 selection highlight key 或非预期文本高亮 painter。
  - 验收要点：merged/covered cell、跨 block selection 覆盖整张表、反向拖选和空 cell 的整格高亮判定保持正确。

- [x] P003: 校准表格选择端点和命中几何 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/widgets/block_geometry_registry.dart -->
  - 验收要点：`_caretRectForTableSelectionEndpoint()` 计算跨 cell 选择端点时，与 `_TextSelectionSurface` 的 text-local 坐标一致，不重复计算 padding 或遗漏居中偏移。
  - 验收要点：点击居中 cell 的文字、左右留白和空白区域时，仍能解析到正确的 `PositionPath.tableCellText`，offset 合理且不会落入相邻 cell。
  - 验收要点：拖选起点/终点在居中 cell 中时，跨 cell selection rect 只覆盖视觉上经过的可见 cell，不因逻辑矩形过宽导致额外 cell 被高亮。

- [x] P004: 补充居中 cell 选择高亮回归测试 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart,test/helpers/selection_test_helpers.dart -->
  - 验收要点：新增或扩展 widget 测试覆盖居中 cell 内局部文字选择，断言高亮 rect 位于居中文本附近、未覆盖 cell 左侧 padding 和相邻 cell。
  - 验收要点：覆盖居中 cell 的反向选择、多行文本选择、空 cell 邻接选择、跨 cell 拖选，确保文本高亮与整格高亮互斥场景稳定。
  - 验收要点：测试代码复用现有 `_tableCellFinder`、`_textRangeGlobalRect`、`_textSelectionHighlightedTableCells` 等 helper；若 helper 不足，仅补充通用辅助，不引入新的测试体系。

- [x] P005: 补充居中 cell 选择高亮 golden 覆盖 <!-- scope: test/widgets/editor_golden_test.dart,test/widgets/goldens/editor_table_selection_centered.png,test/widgets/goldens/editor_table_alignment.png -->
  - 验收要点：新增或更新 golden 场景，包含至少一个居中对齐 cell 的局部文字选择高亮，并保留相邻未选中 cell 用于识别高亮外溢。
  - 验收要点：golden 中同时覆盖列级居中对齐和 cell 级 `alignment: 'center'`，避免只验证其中一种数据路径。
  - 验收要点：golden 只锁定选择高亮视觉结果，不把运行 golden 更新命令作为本任务内容。

## 总体验收标准

最终验收命令：

1. `dart analyze`
2. `flutter test test/widgets/wenz_rich_text_editor_test.dart`
3. `flutter test test/widgets/editor_golden_test.dart`
4. `flutter test`

通过标准：

- 居中显示的表格 cell 内部选择高亮与实际文字位置一致，不向左侧 padding、整格背景或相邻 cell 外溢。
- 单 cell 文本选择、跨 cell 整格选择、跨 block selection 三类高亮职责清晰且互不污染。
- 左对齐、右对齐、justify、merged/covered cell、空 cell、普通文本块 selection 没有回归。
- 分析、定向测试、golden 测试和全量测试均通过；如更新 golden，更新内容仅限本次居中 cell 选择高亮修复带来的预期视觉变化。
