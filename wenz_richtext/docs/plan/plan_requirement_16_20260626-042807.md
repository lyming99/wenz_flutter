## 原始内容
要支持配置字体颜色

## 需求理解
- 需要让调用方或用户能够配置富文本字体颜色，覆盖“默认文字颜色配置”和“选中文本字体颜色格式化”两类常见诉求。
- 文档模型中已有 `TextAttributes.color` 字段，后续实现应优先复用现有内联属性、命令、渲染、表格单元格编辑和编解码链路。
- 字体颜色应与现有链接色、批注/修订色、背景色、字号、字体族、加粗/斜体等内联样式明确优先级，避免渲染和状态回显冲突。
- 颜色配置需要支持设置、清除、状态读取、撤销/重做、复制粘贴、导入导出以及只读态/无效选区保护。
- API 应保持 Flutter 使用习惯，公共输入可面向 `Color`，底层序列化继续使用稳定的 ARGB 整数表示。
