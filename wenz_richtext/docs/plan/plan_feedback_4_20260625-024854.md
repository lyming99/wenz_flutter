# 反馈开发计划：公式、todo 与表格工具栏细节优化

## 来源
- 类型：反馈
- 编号：4

## 原始内容
1. 公式渲染要垂直居中文字，渲染内容要考虑公式内容进行优化，例如调整行高。
2. todo 的 checkbox 要对齐文字，要根据 checkbox 和文字，调整文字行高。
3. 表格工具栏优化一下位置，目前离表格顶部较远。

## 需求理解
- 本次反馈聚焦编辑器默认渲染的视觉对齐与间距优化，不改变富文本文档模型、命令语义和导入导出协议。
- 公式属于内联 embed 渲染问题，需要以文字基线、公式实际高度和段落行高为依据，让公式与同一行文字视觉垂直居中，并避免高公式被裁剪或挤压。
- todo 属于列表项默认渲染问题，需要让 checkbox 与文字首行垂直对齐，同时根据 checkbox 尺寸与文本字号/行高统一整行高度。
- 表格工具栏属于浮层定位问题，需要缩短工具栏与表格顶部的距离，并继续兼容滚动、选区和顶部边界贴合场景。

## 总体验收标准
- 所有任务 checkbox 均完成，且每个任务的验收要点都有明确结论。
- 公式在正文中与周围文字视觉垂直居中，高公式可安全撑开行高，普通公式不会造成异常大行距。
- todo checkbox 与文字首行对齐，单行和多行 todo 的行高、缩进、点击区域和完成态样式稳定。
- 表格浮动工具栏更贴近表格顶部，滚动、视口贴边和选区变化时位置稳定，原有表格操作不回归。
- 本次改动不改变文档模型、命令协议、导入导出数据结构和业务自定义渲染扩展方式。
- 相关自动化测试、静态检查和必要手工验证通过；若存在非本次变更导致的失败，需在进度区记录失败命令、原因和处理建议。
