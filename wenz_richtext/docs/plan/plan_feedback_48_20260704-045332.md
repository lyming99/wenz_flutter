# 开发计划：支持 Tab 缩进和 Shift+Tab 缩退

## 需求概述

为编辑器增加 Tab 键缩进（indent）和 Shift+Tab 缩退（outdent）的键盘快捷操作支持。当前 Tab 键在非表格、非代码块上下文中被映射为表格单元格导航（且无实际效果），需要改为触发块级缩进/缩退。

## 现状分析

- **`EditorShortcutIntent` 枚举** (`lib/src/input/shortcut_manager.dart:9-49`)：目前不含 `indent` / `outdent` 意图。
- **默认 Tab 键行为** (`shortcut_manager.dart:354-359`)：`resolve()` 中 Tab 硬编码映射为 `moveTableCellForward` / `moveTableCellBackward`。
- **代码块 Tab 拦截** (`wenz_rich_text_editor.dart:4430-4456`)：`_handleCodeBlockTabKeyEvent` 在 shortcut manager 之前拦截 Tab 键，当光标位于代码块内时调用 `controller.indentCodeBlock()`。
- **缩进命令** (`block_structure_commands.dart:286-342`)：`IndentCommand` 已完整实现，通过修改 `BlockAttributes.indent`（0~8 钳位）对 `TextBlockNode` 生效，`controller.indent()` / `controller.outdent()` 已暴露。
- **`_performShortcut`** (`wenz_rich_text_editor.dart:4685-4857`)：switch 分发所有 `EditorShortcutIntent` 到具体 controller 方法，不含 indent/outdent 分支。

## 总体架构

```
_handleKeyEvent
 ├─ _handleCodeBlockTabKeyEvent     → 代码块内: indentCodeBlock (保持)
 ├─ _handleTableTabKeyEvent (NEW)   → 表格内: moveTableCell (保持旧行为)
 └─ shortcutManager.resolve()       → 默认: Tab→indent, Shift+Tab→outdent
      └─ _performShortcut           → indent/outdent dispatch
```

**关键设计决策**：
- Tab 键在 shortcut manager 的默认映射改为 `indent` / `outdent`，使其成为一个通用的块级缩进快捷键。
- 特殊上下文（代码块、表格单元格）在 `_handleKeyEvent` 中优先拦截，确保原有行为不受影响。
- `indent` / `outdent` 作为正式 `EditorShortcutIntent` 枚举值，可被用户通过 `EditorShortcutConfiguration.disabledIntents` 禁用。

## 总体验收标准

1. 在普通段落/标题/列表/引用块中按 **Tab**：块缩进级别 +1（最多 8），视觉上产生缩进效果。
2. 在普通段落/标题/列表/引用块中按 **Shift+Tab**：块缩进级别 -1（最少 0），视觉上缩退。
3. 在**代码块**中按 Tab / Shift+Tab：保持原有代码缩进行为（`indentCodeBlock`），不受此变更影响。
4. 在**表格单元格**中按 Tab / Shift+Tab：保持原有单元格间导航行为，不受此变更影响。
5. 只读模式下 Tab / Shift+Tab 不触发缩进/缩退（被 shortcut manager 的 readOnly 守卫拦截）。
6. 可通过 `EditorShortcutConfiguration(disabledIntents: {EditorShortcutIntent.indent, EditorShortcutIntent.outdent})` 禁用该快捷键。
7. 缩进/缩退操作正确记录 undo/redo 历史。

