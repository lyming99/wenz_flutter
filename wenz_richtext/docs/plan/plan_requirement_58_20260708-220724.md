# 桌面端笔记大纲视图优化

## 需求概要

优化现有 WenzOutlineTree / WenzOutlinePanel 的桌面端笔记大纲展示：标题项没有可折叠子内容时不显示折叠按钮且不预留按钮空间；大纲面板 header 不再显示类似“7 headings”的总数文案；大纲项左右水平内边距统一为 8dp，并保留现有按标题层级递增的缩进语义。实现应保持树内折叠状态仍为本地 UI 状态，不影响 WenzOutlineController 管理的编辑器正文折叠投影。

## 任务拆解

- [x] P001: 调整大纲树 header 与标题项行布局 <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 验收要点：桌面端 WenzOutlineTree / WenzOutlinePanel 的 header 只保留大纲标题和必要操作入口，不再渲染“0 headings”“1 heading”“7 headings”等标题总数文案
  - 验收要点：没有可折叠子内容的 OutlineItem 不显示行内折叠按钮，也不为折叠按钮保留水平占位；有子内容且 canCollapse=true 的标题仍显示展开/折叠按钮
  - 验收要点：大纲项内容区的基础水平内边距为 8dp：起始侧为 8dp 加层级缩进，结束侧为 8dp；层级缩进、选中态左侧强调线、H1-H6 badge 和标题文本省略行为保持一致
  - 验收要点：展开/折叠单行、全部展开、全部折叠、点击选择、键盘导航和空状态展示不因布局调整产生行为回归
- [x] P002: 补充大纲面板 widget 回归覆盖 <!-- scope: test/widgets/outline_tree_test.dart,test/widgets/outline_panel_test.dart -->

  - 验收要点：WenzOutlinePanel 测试覆盖由 controller 提供多条 heading 时不再显示“2 headings”等计数文案
  - 验收要点：叶子标题测试覆盖不出现折叠图标、不触发折叠回调、点击标题仍能正常 select
  - 验收要点：行布局测试覆盖基础水平内边距为 8dp，并确认多级 heading 的层级缩进仍向右递增
