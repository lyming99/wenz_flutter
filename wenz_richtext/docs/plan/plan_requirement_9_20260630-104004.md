# 需求 #9 开发计划：连续引用块背景无断层

## 需求摘要

当前富文本编辑器中连续 `BlockType.quote` 引用块的背景色存在“断层”或“间距”，导致多段连续引用无法视觉上形成一个完整背景区域。目标是在连续引用块之间消除可见缝隙，或统一背景绘制策略，让同一组连续引用块呈现为完整、连续的引用背景，同时保持引用块与非引用块之间的正常段落间距。

## 代码现状分析

- 引用块渲染集中在 `lib/src/widgets/wenz_rich_text_editor.dart`，其中 `_QuoteBlockSurface` 负责引用背景、左侧强调条、圆角和内边距。
- 连续块间距由 `_spacingBetweenBlocks` 计算，当前已有 `quote -> quote` 返回 `_kAdjacentQuoteSpacing = 0.0` 的逻辑，但用户反馈仍存在视觉断层，说明断层可能来自引用块自身内边距、圆角、虚拟列表测量/布局偏差，或相邻背景分别绘制导致的亚像素缝隙。
- 连续引用分组由 `_quoteGroupPositionFor` 计算，并通过 `BlockRenderContext.quoteGroupPosition` 传递到内置渲染器；`QuoteGroupPosition` 定义在 `lib/src/widgets/block_renderer_registry.dart`。
- 已有 widget 测试覆盖连续两段引用背景贴合和圆角变化，但需要补充三段及以上、空引用、不同缩进、虚拟列表布局下无缝连续等回归场景。
- `docs/rendering.md` 已被代码注释引用，应同步明确连续引用背景的渲染契约，避免后续改动破坏该行为。

## 总体验收标准

- 功能标准：任意相邻的连续引用块在视觉上呈现为一个连续背景区域，不出现“断层”“间距”或背景色缺失；引用块与非引用块之间仍保留正常段落分隔。
- 兼容标准：选择、光标、点击、空块高度、inline embed、不同缩进引用块、自定义渲染上下文均不出现行为回归。
- 测试标准：至少执行 `flutter test test/widgets/wenz_rich_text_editor_test.dart` 并通过；条件允许时执行 `flutter test` 并通过。
- 文档标准：连续引用背景的渲染规则在 `docs/rendering.md` 中可追溯，代码注释、测试断言和文档描述一致。
