# 开发计划 #27: AI 对话模块与多配置管理

## 需求概述

为 wenz_richtext 项目新增 AI 对话模块，支持：
1. 创建并管理多个对话
2. 创建并管理多个 AI 服务配置（含 OpenAI 和 DeepSeek）
3. OpenAI 配置支持「思考深度」（reasoning_effort）参数
4. DeepSeek 配置支持独立的「思考深度」参数
5. 使用成熟的 Dart 专属依赖库（`dart_openai`）接入 OpenAI / DeepSeek API
6. 对话过程中实时显示「思考中…」「回复中…」状态

## 关键约束

- AI 基础设施层（模型、服务抽象、管理器）放入 `lib/src/ai/`，作为库的 tier-3 实验性模块
- AI 对话 UI 页面放入 `example/lib/ai/`，通过 example app 演示完整流程
- 使用 `dart_openai`（pub.dev 上最成熟的 Dart OpenAI 客户端）作为 API 接入层，OpenAI 直连、DeepSeek 通过自定义 base URL 适配（DeepSeek API 与 OpenAI 兼容）
- 对话和配置数据使用本地持久化（JSON 文件 / shared_preferences），不在 rich text document 模型中引入 AI 字段
- 流式响应通过 `dart_openai` 内置的 Stream 支持实现，UI 层展示逐 token 输出 + 状态标记
- 思考深度配置：OpenAI 使用 `reasoning_effort` 参数（`low`/`medium`/`high`），DeepSeek 使用 `thinking` 参数（DeepSeek-R1 的 `thinking` 字段，类型为 `{type: "enabled"}` 或 `{type: "disabled"}`）；两种配置各自独立

1. `flutter pub get` 成功，新增依赖无版本冲突
2. `flutter analyze` 无新增 error/warning（仅允许既有 warning）
3. `flutter test` 全部通过（现有测试 + `test/ai/` 下新增测试）
4. example app 在桌面端可运行：进入 AI 对话页 → 创建/切换多个对话 → 发送消息后状态显示「思考中…」→ 开始收到回复后显示「回复中…」→ 完整回复渲染完毕
5. AI 配置页可创建多个 OpenAI/DeepSeek 配置，各自独立设置思考深度
6. 库 barrel 文件 `lib/wenz_richtext.dart` 正确导出 `lib/src/ai/` 下的公开 API

- [x] P005: 创建 AI 服务抽象层与 OpenAI/DeepSeek 实现 `lib/src/ai/services/ai_service.dart` <!-- scope: lib/src/ai/services/ai_service.dart,lib/src/ai/services/openai_service.dart,lib/src/ai/services/deepseek_service.dart -->
  - 验收要点：
    - 定义抽象接口 `abstract class AIService`：
      - `Stream<String> chatStream({required List<ChatMessage> history, required AIConfig config, String? systemPrompt})`：流式对话，逐 token 产出
      - `Future<String> chat({required List<ChatMessage> history, required AIConfig config, String? systemPrompt})`：非流式对话
      - `Future<void> validateConfig(AIConfig config)`：验证 API key 有效性
      - `String get providerName`
    - 创建工厂 `class AIServiceFactory`：`static AIService create(AIProvider provider)` 返回对应实现
    - 实现 `class OpenAIService extends AIService`：
      - 使用 `dart_openai` 的 `OpenAI.instance.chat.createStream()` 实现流式对话
      - `chatStream` 中将 `OpenAIConfig.thinkingDepth` 映射为 `reasoning_effort` 参数（`low`/`medium`/`high`）
      - 支持通过 `config.model` 指定模型
      - 解析流式 chunk 的 `choices[0].delta.content` 逐 token 产出
    - 实现 `class DeepSeekService extends AIService`：
      - 使用 `dart_openai` + 自定义 `baseUrl`（默认 `https://api.deepseek.com/v1`）
      - `chatStream` 中根据 `DeepSeekConfig.thinkingMode` 设置 `thinking` 字段（`{type: "enabled"}` / `{type: "disabled"}`）
      - 支持通过 `config.model` 指定模型（默认 `deepseek-chat`）
      - 解析流式 chunk 产出内容
    - 错误处理：网络异常、API 错误、鉴权失败等均通过 `AIServiceException` 包装抛出

- [x] P006: 创建对话管理器 `lib/src/ai/conversation_manager.dart` <!-- scope: lib/src/ai/conversation_manager.dart -->
  - 验收要点：
    - 定义 `class ConversationManager extends ChangeNotifier`：管理对话列表的 CRUD + 消息发送
    - `Future<void> initialize(AIConfigManager configManager)`：从本地 JSON 加载已有对话
    - `List<Conversation> get conversations`：获取所有对话列表（按 `updatedAt` 降序）
    - `Future<Conversation> createConversation({required String title, required String aiConfigId, String? systemPrompt})`：创建新对话 → 持久化 → `notifyListeners()`
    - `Future<void> deleteConversation(String id)`：删除对话 → 持久化 → `notifyListeners()`
    - `Conversation? getConversation(String id)`：按 ID 查找
    - `Stream<String> sendMessage(String conversationId, String content)`：核心方法
      - 创建 `ChatMessage(role: user, content: content)` 追加到对话
      - 设置 `conversation.status = ConversationStatus.thinking` → `notifyListeners()`
      - 调用 `AIService.chatStream()` 获取流
      - 创建空的 assistant `ChatMessage`
      - 首个 token 到达时 `status = ConversationStatus.replying` → `notifyListeners()`
      - 拼接 token 内容到 assistant message 的 `content`
      - 流结束时 finalize message → 持久化 → `status = ConversationStatus.idle` → `notifyListeners()`
      - 流异常时 `status = ConversationStatus.error` → 在 assistant message 上记录 `error` → `notifyListeners()`
      - 返回 Stream 供 UI 层使用
    - 内部持久化：JSON 序列化到 `{appDocDir}/wenz_ai_conversations.json`
    - `dispose()` 时释放资源
