# 需求 #61 开发计划：移除代码块顶部头部的边框盒子

- 需求编号：#61
- 创建日期：2026-06-28
- 状态：待评审

## 需求概述

代码块顶部的头部（header）当前被一个带边框的盒子包裹，视觉上呈现
`【dart | 留白 | 复制按钮】`（语言标签 → spacer → 复制按钮 外层有一圈描边/背景圆角盒）。
期望改为 `dart | 留白 | 复制按钮`：语言标签、中间留白、复制按钮直接作为一行落在代码块背景上，
**不显示任何边框/外框盒子**。

即：移除代码块头部 `_CodeBlockToolbar` 的外层 `DecoratedBox` 边框（及其配套背景填充与圆角），
仅保留语言标签、`Expanded` 留白、复制按钮这一行布局。代码块**整体外框**保持不变。

## 现状分析（勘察结论）

- 头部渲染集中在 `lib/src/widgets/wenz_rich_text_editor.dart` 的 `_CodeBlockToolbar.build`（约 7094–7192 行）：
  - 外层为 `Material`（透明）→ `DecoratedBox`，其 `BoxDecoration` 同时设置了：
    - `color: _codeBlockHeaderBackgroundColor(theme)`（头部背景填充，亮色 `Colors.white.withAlpha(18)`、暗色 `surface.withAlpha(120)`）；
    - `border: Border.all(color: _codeBlockHeaderBorderColor(theme))`（**问题来源**：亮色 `white.withAlpha(24)`、暗色 `outlineVariant.withAlpha(120)` 的描边，正是用户看到的 `【…】` 边框）；
    - `borderRadius: BorderRadius.circular(_kCodeBlockHeaderRadius)`（`9.0`）。
  - 内部为 `SizedBox(height: _kCodeBlockHeaderHeight)`（`36.0`）→ `Padding` → `Row`：
    `Expanded(LayoutBuilder(语言标签 / PopupMenuButton 切换语言))` + `IconButton(复制按钮)`。
  - 头部行结构（语言标签 → `Expanded` 留白 → 复制按钮）本身正确，问题仅在于外层 `DecoratedBox` 的边框/背景/圆角盒子。
- 头部由 `_CodeBlockRenderer`（约 6789–6799 行）在代码块 `Container`（外框 `_codeBlockBorderColor` + `_kCodeBlockRadius`）内、代码正文上方渲染，`_CodeBlockHeaderGap`（`14.0`）分隔。
- 头部配色/边框**未纳入设计基线 token**（`WenzRichTextDesignBaseline` 仅含 `codeBackground` / `codeText` / `languageTagFontSize` 等；`_codeBlockHeaderBackgroundColor` / `_codeBlockHeaderBorderColor` 为 theme 派生的私有辅助函数，定义在约 11632–11642 行）。
- 既有测试对代码块的覆盖：
  - `test/widgets/editor_golden_test.dart` 中 4 张**图像 golden** 渲染了代码块头部，会随本次视觉改动而变化：
    `goldens/editor_blocks.png`、`goldens/editor_advanced_blocks.png`、`goldens/editor_theme_light.png`、`goldens/editor_theme_dark.png`。
  - 其余用例为结构性断言（`find.byKey` / `findsOneWidget` 等），不断言头部边框；无直接针对代码块头部边框的结构化断言。
- 未发现其他渲染器或测试文件引用代码块头部边框逻辑。

## 方案与关键决策

1. **改动收窄到 `_CodeBlockToolbar.build`**：去掉 `DecoratedBox` 的 `border`、`color` 与 `borderRadius`（即整个头部盒子），使头部成为透明行，语言标签与复制按钮直接落在代码块背景上，精确匹配期望观感 `dart | 留白 | 复制按钮`。
   - 保留外层 `Material`（透明，`IconButton` 的 ripple / tooltip 与 `PopupMenuButton` 弹层依赖其层级）。
   - 保留 `SizedBox(height: _kCodeBlockHeaderHeight)` + `Padding` + `Row` 的尺寸与排布，仅去除装饰盒子。
2. **不动代码块整体外框**：`_CodeBlockRenderer` 外层 `Container` 的 `_codeBlockBorderColor` + `_kCodeBlockRadius` 边框保持不变——本需求只移除“头部”的边框。
3. **死代码清理**：移除头部盒子后，`_codeBlockHeaderBorderColor` / `_codeBlockHeaderBackgroundColor` / `_kCodeBlockHeaderRadius` 若不再有其他引用则一并删除，避免 `flutter analyze` 死代码；若仍被引用则保留。改动前以全局检索确认引用情况。
4. **golden 重新生成**：本次为纯视觉改动，4 张受影响 golden 图像需在验收阶段重新生成（`flutter test --update-goldens`）并核对差异仅限于代码块头部区域，不作为独立开发任务，归入“完整验收”节点统一处理。
5. **范围边界**：仅改代码块头部的外观（去边框盒子），不触碰语言切换、复制、只读、明暗主题等行为逻辑，也不改菜单/工具栏等其他 chrome。
