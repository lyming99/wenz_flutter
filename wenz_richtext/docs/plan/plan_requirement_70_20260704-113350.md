## 背景与影响范围

本需求要求在 `WenzRichTextEditor` 中增加桌面右键操作菜单，并允许外部注入自定义操作按钮。基于当前代码分析，编辑器主体、选择手势、剪贴板和 bootstrap 组装路径分别位于：

- `lib/src/widgets/wenz_rich_text_editor.dart`：编辑器主体、默认块菜单、快捷键分发、复制/剪切/粘贴/删除/插入等现有动作。
- `lib/src/widgets/selection_gesture_overlay.dart`：编辑区域鼠标/触控选择手势，适合作为右键事件入口，但不应承载剪贴板业务逻辑。
- `lib/src/controller/wenz_rich_text_controller.dart` 与 `lib/src/input/clipboard_service.dart`：已有 copy/cut/paste/delete/insert 命令能力，应复用而不是重写。
- `lib/src/integration/wenz_editor_configuration.dart` 与 `lib/src/integration/wenz_editor_bootstrap.dart`：标准外部接入路径，需要透传自定义菜单配置。
- `test/widgets/wenz_rich_text_editor_test.dart` 与 `test/integration/wenz_editor_bootstrap_test.dart`：适合补充右键菜单交互和配置透传回归覆盖。

## 实施策略

新增右键菜单应作为编辑器 widget 层能力实现，复用当前 `showMenu`、`_PopupMenuItemContent`、剪贴板处理和命令分发逻辑。右键事件由 `SelectionGestureOverlay` 上报给 `WenzRichTextEditor`，编辑器负责解析命中位置、维护选择、关闭互斥 overlay，并根据当前 selection/readOnly/permission 构建默认菜单和外部自定义项。公开 API 应保持类型化，避免把私有 `_ObjectMenuSelection`、私有快捷键处理器或内部 widget 状态泄漏给业务层。
