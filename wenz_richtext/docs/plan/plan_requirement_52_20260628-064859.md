# 需求开发计划：@ 提及支持点击打开

## 来源

## 原始需求
提及“@”要支持点击打开，这个可以通过点击事件进行打开

## 需求理解
- 当前 `@` 提及已通过 `InlineEmbed(embedType: 'mention')` 和 `WenzRichTextController.insertMention` 写入文档，默认渲染为 `@label` 的 inline embed。
- 需求目标是在用户点击编辑器内的提及文本时，对外触发打开动作；核心包不应内置具体业务页面，而应暴露稳定点击事件，由业务方决定打开用户资料、成员卡片或其他目标。
- 点击提及应与现有文本选择、光标定位、拖拽选择、只读模式、公式/emoji/image inline embed 和自定义 `InlineEmbedRenderer` 保持兼容。
- 提及点击事件应携带足够上下文，例如 mention 的 `id`、`label`、原始 `InlineEmbed.data`、所在 block/path 或 selection 信息，便于业务打开正确目标。
