# 优化桌面端深色主题编辑器背景色

## 需求概要

当前 WenzRichTextEditor 的深色主题编辑器背景在核心组件、example 工作台和集成测试 helper 中均直接使用 Colors.black，桌面端黑色主题下视觉过深。实施时应将深色编辑器画布调整为更柔和的深色中性背景，同时保持浅色主题白色背景、正文颜色、选区/光标/块渲染和现有主题切换行为不回归。重点范围包括 lib/src/widgets/wenz_rich_text_editor.dart 的默认背景解析、example/lib/main.dart 的桌面编辑器外层背景、example/integration_test/helpers/test_app.dart 的测试工作台背景，以及现有深色主题 golden/集成断言同步。

- [x] P001: 调整编辑器默认深色背景 token <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->

  - 验收要点：Brightness.light 下编辑器默认背景仍保持白色，不改变浅色主题既有视觉基准
  - 验收要点：背景色调整仅影响编辑器根画布，不改写文档模型、正文默认颜色、光标、选区、代码块、表格、媒体块或浮层色彩语义
  - 验收要点：实现保留 ThemeData/ColorScheme 派生边界，不新增业务侧必填配置，也不破坏现有 WenzRichTextEditor 构造参数兼容性
