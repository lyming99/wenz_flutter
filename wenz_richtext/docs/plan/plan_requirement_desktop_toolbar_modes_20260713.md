# 需求开发计划：桌面工具栏固定与选区悬浮双模式

## 需求

桌面端工具栏支持两种模式：保留当前固定工具栏，并新增选中文本后跟随选区显示的悬浮工具栏。

## 实现边界

- 新增公开模式枚举，默认值保持固定模式，现有集成无需修改。
- 悬浮模式复用 `ToolbarController`、`WenzDefaultDesktopToolbar`、插件工具栏项和宿主资源 action。
- 悬浮工具栏只在桌面端可编辑的非折叠文本选区显示；折叠光标、清空选区、移动端和只读状态隐藏。
- 定位复用编辑器的 `BlockGeometryRegistry`，监听选区与滚动，在视口边缘自动翻转和夹紧。
