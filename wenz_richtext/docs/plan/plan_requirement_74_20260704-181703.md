## 背景与影响范围

本项目是 Flutter 富文本编辑器组件。分割线是 `DividerBlockNode` 原子对象块，默认渲染入口位于 `lib/src/widgets/wenz_rich_text_editor.dart` 的 `_defaultDividerBlockRenderer`，实际 UI 由 `_DividerBlockContent` 绘制。

当前实现中，选中分割线时存在三层明显 chrome：`_BlockObjectSelectionSurface` 的通用选区 overlay、`_DividerBlockContent` 自己的选中 shell 背景加边框，以及 `_FloatingObjectBlockToolbar` 的复制/更多工具栏。需求要求“选择状态只有一个边框，不需要工具栏”，因此本次应收敛为分割线选中后仅显示一个轻量边框，保留分割线本体的线和圆点，不显示对象块浮动工具栏。

范围限定：
- 只调整分割线的默认 widget 渲染、选中态和对应测试/golden。
- 不修改 `DividerBlockNode` 数据模型、schema、codec、Markdown/HTML 导入导出和命令语义。
- 不影响图片、视频、文件、embed 等其他对象块的工具栏、预览、复制引用、移动、删除能力。
- 分割线仍应通过左侧块操作菜单获得复制/副本/移动/删除等块级操作；本需求只移除“选中分割线后贴着分割线显示的对象块工具栏”。

## 实施策略

优先在 `wenz_rich_text_editor.dart` 内做局部收敛：让 divider 继续通过 `_BlockObjectSelectionSurface` 注册原子块几何和命中测试，但关闭通用选区 overlay，避免出现双边框；由 `_DividerBlockContent` 独立绘制唯一选中边框，并移除 `_FloatingObjectBlockToolbar` 作为其选中子内容。

测试侧应把现有“分割线选中后显示复制/更多工具栏”的断言改为“没有工具栏、没有通用选区 overlay、只有 shell 边框”。若静态 golden 受影响，只更新分割线区域对应基线并记录差异边界。
