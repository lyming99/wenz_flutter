# 开发计划：大纲视图优化

> 反馈原文：大纲视图优化一下
>
> 目标：对现有的大纲树组件（WenzOutlineTree）和示例面板（ExampleOutlinePanel）进行体验优化，包括：提供可直接消费 `WenzOutlineController` 的便捷包装组件、添加 heading 级别徽标、标题头增加「全部折叠/全部展开」操作、以及大纲树内键盘导航。

## 背景与现状

大纲视图已在需求 #64 中落地，当前状态：

- `lib/src/widgets/outline_tree.dart`：纯展示型 `WenzOutlineTree`，接收 `List<OutlineItem>`、`activeBlockId`、`onSelect`、`onToggleCollapse` 等入参，不持有 controller、不做订阅。
- `example/lib/outline_panel.dart`：`ExampleOutlinePanel` 手动接线——订阅 `WenzOutlineController`、计算 `activeBlockId`、转发 `select`/`toggle` 回调。该封装在 example 内，业务方无法直接复用。
- 标题行无级别视觉区分（H1/H2/…/H6 仅靠缩进距离分辨，缺少文字标签加速辨识）。
- 标题头仅有标题+数量，缺少「全部展开/全部折叠」快捷操作。
- 大纲树内不支持键盘上下键导航。

## 设计决策

1. **新增 `WenzOutlinePanel`（智能包装组件）**：在 `lib/src/widgets/` 下新增，内持 `WenzOutlineController` 引用并 `addListener`，自动计算 `activeBlockId`（基于选区反查）、自动转发 `onSelect`→`controller.select`、`onToggleCollapse`→`controller.toggle`。对外仅暴露 `controller` 和可选的 `width`/`emptyBuilder` 参数。例程改为消费该包装组件，减少样板代码。
2. **Heading 级别徽标**：在 `_OutlineItemRow` 中标题文本左侧插入小号填充型 label（如 "H1"），同一 level 使用同色、不同 level 使用渐淡的 `onSurfaceVariant` 色阶区分。
3. **标题头折叠操作**：`_OutlineHeader` 右侧新增图标按钮组：全部折叠（`unfold_less`）→ 折叠所有可折叠项；全部展开（`unfold_more`）→ `controller.expandAll()`。仅在有可折叠项时显示。
4. **键盘导航**：`ListView.builder` 包裹 `KeyboardListener` 或使用 `Focus` + `Actions`，监听 ArrowUp/ArrowDown 移动高亮索引、Enter 执行选中跳转。高亮索引溢出时循环或 clamp。
5. **向后兼容**：`WenzOutlineTree` 保持原有纯展示 API 不变（不向后破坏），新增功能作为可选 props 或通过 `WenzOutlinePanel` 提供。

## 任务拆解

- [x] P001: 新增 WenzOutlinePanel 便捷包装组件 <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 在 `lib/src/widgets/outline_tree.dart` 中新增 `WenzOutlinePanel extends StatefulWidget`。
  - 入参：`required WenzOutlineController controller`、`double? width`、`WidgetBuilder? emptyBuilder`。
  - 内部自动订阅 `controller`（`addListener` → `setState`），dispose 时移除监听。
  - 自动计算 `activeBlockId`：依据 `controller.editor.selection.extent.blockIndex` 反查所属/最近的上级标题（同 `ExampleOutlinePanel.activeBlockId` 逻辑）。
  - 接线：`onSelect` → `controller.select(item)`；`onToggleCollapse` → `controller.toggle(item)`；将 `items`、`activeBlockId`、回调解耦传递给内部 `WenzOutlineTree`。
  - `WenzOutlineTree` 保持纯展示不变；`WenzOutlinePanel` 仅做智能包装。

- [x] P002: 新增 WenzOutlinePanel 的导出与 example 接线 <!-- scope: lib/wenz_richtext.dart, example/lib/main.dart, example/lib/outline_panel.dart -->
  - 在 `lib/wenz_richtext.dart` 中导出 `WenzOutlinePanel`。
  - 修改 `example/lib/main.dart` 或 `example/lib/outline_panel.dart`，将原先手动接线的 `ExampleOutlinePanel` 调换为 `WenzOutlinePanel`（或保持 `ExampleOutlinePanel` 不变、内部改为委托 `WenzOutlinePanel`），使 example 预览到新组件的效果。
  - 移除或简化 `ExampleOutlinePanel` 中重复的主动订阅/activeBlockId 计算逻辑。

- [x] P003: 标题项添加 heading 级别徽标 <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 在 `_OutlineItemRow` 的 `Row` 中、折叠按钮与标题文本之间插入级别徽标：小号 `Container` + `Text("H{level}")`，水平 padding 4、圆角 4、字号 `labelSmall`、背景 `onSurface.withAlpha(20)`、文字色 `onSurfaceVariant`。
  - 不同 level 使用不同透明度/色阶差异：H1 最深（alpha 32）、H6 最浅（alpha 8），帮助快速扫视分辨层级。
  - 徽标不响应点击、不影响行高。

- [x] P004: 标题头增加「全部折叠/全部展开」操作 <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 在 `_OutlineHeader` 右侧现有数量文本旁/后添加操作按钮：全部展开（`Icons.unfold_more`）、全部折叠（`Icons.unfold_less`）。
  - 按钮仅在整个大纲存在可折叠项时显示（`items.any((i) => i.canCollapse)`）。
  - 全部展开：调用 `onExpandAll`（新增可选入参）。全部折叠：遍历可折叠且未折叠的项调用 `onCollapseAll`（新增可选入参）。
  - `WenzOutlineTree` 新增可选回调 `VoidCallback? onExpandAll`、`VoidCallback? onCollapseAll`；`WenzOutlinePanel` 自动接线到 `controller.expandAll()` 和「逐个 collapse 所有可折叠项」。
  - tooltip 文案：「展开全部」「折叠全部」。

- [x] P005: 增加大纲树键盘导航 <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 在 `_OutlineItemRow` 外层或 `ListView.builder` 外层引入 `Focus` 与键盘事件，使大纲树可通过 ArrowUp/ArrowDown 移动焦点高亮。
  - 维护一个 `_focusedIndex` 状态（与 `activeBlockId` 独立），ArrowUp 减一、ArrowDown 加一，边界 clamp 到 `[0, items.length-1]`。
  - Enter/Space 在当前聚焦项上执行 `onSelect`；`activeBlockId` 高亮仍保持跟随编辑器选区，焦点高亮通过额外视觉效果（如聚焦环或背景色加深）区分。
  - `WenzOutlinePanel` 默认启用键盘导航；`WenzOutlineTree` 的新增可选开关（`bool enableKeyboardNavigation = false`）保持向后兼容。

- [x] P006: 补充/更新测试 <!-- scope: test/widgets/outline_tree_test.dart, test/widgets/outline_panel_test.dart -->
  - 在 `test/widgets/outline_tree_test.dart` 中新增用例覆盖：
    - heading 级别徽标渲染与文本正确性；
    - 标题头「全部展开/全部折叠」按钮可见性（有/无可折叠项）；
    - 点击全部折叠后再点全部展开触发对应回调。
  - 新增 `test/widgets/outline_panel_test.dart`，覆盖 `WenzOutlinePanel`：
    - 挂载后自动显示 controller.items；
    - 选区变化时 activeBlockId 相应变化；
    - 点击项触发 controller.select；
    - 空 controller 显示空状态。
  - 本任务只描述应覆盖场景，**不要求在本任务内运行测试**（统一交由最终验收节点运行）。
