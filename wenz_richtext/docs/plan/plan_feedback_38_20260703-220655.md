# 反馈 #38 开发计划：短文字右侧点击应定位到当前行尾

- 反馈编号：38
- 生成时间：2026-07-03 22:06:55
- 反馈内容：文字较短的情况下，点击右侧没有定位到行尾，反而定位到其它行

## 背景与现状

当前项目是 Flutter 富文本编辑器。点击定位链路为 `SelectionGestureOverlay` 接收 pointer 事件，通过 `BlockGeometryRegistry.positionFromGlobalOffset` 把全局坐标解析为 `DocumentPosition`，命中具体文本 surface 后再调用 `_TextSelectionSurface._offsetForLocalPosition` 和 `TextLayoutService.offsetAt` 将本地坐标转换为文本 offset。

现有代码已经为包裹换行的长文本补过“右侧空白点击定位到该视觉行行尾”的测试，相关测试位于 `test/widgets/wenz_rich_text_editor_test.dart`，底层行命中测试位于 `test/widgets/block_geometry_registry_test.dart`。但普通非空文本块的 `_TextSelectionSurface` 只有在 `textLength == 0` 时才把可点击宽度扩到整行；短文字时 `RichText`/`Stack` 的命中区域可能接近文字自身宽度，点击右侧空白会 miss 当前行 surface，转而走 registry 的 nearest clamp，进而落到其它行或其它块。表格、代码块、callout 已有独立 `hitTestKey` 或可见范围 clamp，修复时需要保留这些特殊路径。

## 目标

- 普通段落、标题、引用、列表文本较短时，点击同一视觉行右侧空白应把光标定位到该行行尾，而不是其它视觉行或相邻块。
- 多行文本中任意视觉行右侧空白点击应定位到对应视觉行的 end offset，包括自动换行和显式换行。
- 保持表格单元格、水平滚动代码块、callout 卡片、空文本块、列表 marker/todo checkbox、折叠按钮、block handle 等现有命中排除和特殊命中语义不变。
- 增加针对“短文字右侧空白”的回归测试，覆盖 widget 层和底层行命中层。

## 任务拆解

- [x] P001: 修正普通文本块右侧空白命中区域 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  验收要点：
  - 普通非空 `_TextSelectionSurface` 在父级提供有限宽度时，文本 hit-test 区域覆盖当前文本行可编辑宽度，不再只覆盖短文字本身宽度。
  - 空文本块当前撑满文本区宽度的行为保留；列表/任务列表的 marker、checkbox、标题折叠按钮、block chrome 不被纳入文本命中区域。
  - 表格 cell、水平滚动代码块、callout 使用既有 `hitTestKey` 的路径不被改窄或改坏，点击 padding/gutter 仍按原有语义解析。
  - 修复后点击短段落右侧空白能命中该段落对应的 `blockId`/`path`，不会因 miss surface 落入 `BlockGeometryRegistry._clampToNearest` 后跳到其它行。

- [x] P002: 强化视觉行右侧空白到行尾的 offset 映射 <!-- scope: lib/src/rendering/text_layout_service.dart -->
  验收要点：
  - `TextLayoutService.offsetAt` 对 `computeLineMetrics()` 选中的视觉行显式处理 x 边界：点击行左侧空白返回该行 start，点击行右侧空白返回该行 end。
  - 自动换行、显式 `\n` 换行、短行和最后一行均按当前视觉行计算 offset，不让 `TextPainter.getPositionForOffset` 在远右侧坐标下漂移到下一行或其它行。
  - 文本长度为 0、无 line metrics、inline embed/placeholder 参与布局时仍返回合法 offset，不抛异常且不越界。
  - 保持现有 caret、selection box、word boundary、vertical move API 行为不变。

- [x] P003: 补充短文字右侧空白点击回归测试代码 <!-- scope: test/widgets/wenz_rich_text_editor_test.dart,test/widgets/block_geometry_registry_test.dart -->
  验收要点：
  - Widget 测试覆盖短段落右侧大面积空白点击，断言 selection 仍在当前 `blockId`，offset 为文本长度。
  - Widget 测试覆盖多行短文本或显式换行文本的每一行右侧空白点击，断言落点为对应视觉行 end offset，不跳到上一行、下一行或相邻块。
  - 底层 `TextLayoutService` 测试覆盖短行右侧远端 x、左侧 x、显式换行、自动换行、最后一行等场景。
  - 测试复用现有 `_richTextRightBlankTarget`、`_visualLineRange`、`_lineHitFixture` 等辅助模式，避免引入与反馈无关的测试基建重构。
