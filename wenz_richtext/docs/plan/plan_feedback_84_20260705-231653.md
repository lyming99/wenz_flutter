# 固定工具栏右侧三个按钮显示位置

## 需求概要

根据反馈 #84，当前默认桌面工具栏使用 Wrap 顺序排布，按钮组会随可用宽度、表格上下文按钮和插件扩展项变化而换行或移动，导致最右侧动作区存在被遮挡或位置不稳定的风险。计划将工具栏拆分为左侧可流式排布的主工具区与右侧固定显示的尾部按钮区，确保最右边 3 个按钮始终靠右、尺寸稳定且不覆盖其他工具项。

## 任务拆解

- [x] P001: 拆分默认桌面工具栏主工具区与固定右侧按钮区 <!-- scope: lib/src/widgets/default_desktop_toolbar.dart -->
  - 验收要点：WenzDefaultDesktopToolbar 不再把所有工具项放入单个 Wrap 中直接顺序渲染，而是形成左侧主工具区和右侧固定尾部按钮区两个布局区域。
  - 验收要点：右侧尾部区域承载当前工具栏末尾的 3 个按钮，并通过 Row、Expanded、Align 或等效约束始终贴靠工具栏右侧显示。
  - 验收要点：左侧主工具区在宽度不足时可以换行或横向受限，但不能占用右侧尾部按钮区的空间，也不能遮挡右侧按钮。
- [x] P002: 保持右侧按钮组尺寸与交互稳定 <!-- scope: lib/src/widgets/default_desktop_toolbar.dart -->
  - 验收要点：右侧 3 个按钮使用稳定的按钮尺寸、间距和分隔规则，启用、禁用、选中或菜单展开状态变化时不引发区域宽度跳变。
  - 验收要点：插入元素菜单、对齐或其他被拆入右侧区域的菜单按钮仍能正常打开、关闭并执行原有动作。
  - 验收要点：工具栏在表格上下文按钮出现或消失时，右侧 3 个按钮仍保持靠右显示且不与表格按钮重叠。
- [x] P003: 兼容插件扩展项和资源插入动作的动态变化 <!-- scope: lib/src/widgets/default_desktop_toolbar.dart,lib/src/controller/toolbar_controller.dart -->
  - 验收要点：WenzToolbarItemRegistry 和 toolbarItems 注入的扩展按钮仍按现有优先级排序渲染，动态增减时不会挤压或遮挡固定右侧按钮区。
  - 验收要点：图片、视频、文件、业务嵌入等资源插入动作的隐藏、禁用、pending 状态仍只影响插入菜单内容，不改变右侧固定区域的外部尺寸。
  - 验收要点：只读、评论、无选择等权限或状态变化下，右侧按钮仅改变可用性或视觉状态，不改变固定靠右布局。
- [x] P004: 补充默认桌面工具栏右侧固定布局测试 <!-- scope: test/widgets/default_desktop_toolbar_test.dart -->
  - 验收要点：测试覆盖默认宽度下右侧 3 个按钮位于固定尾部区域，并且尾部区域贴靠工具栏右边界。
  - 验收要点：测试覆盖窄宽度下左侧工具项换行或受限时，右侧 3 个按钮仍可见、可点击且没有 Flutter overflow。
  - 验收要点：测试覆盖表格上下文按钮出现、插件扩展项增多、资源插入动作隐藏或禁用时，右侧固定按钮区的位置和尺寸保持稳定。
- [x] P005: 同步示例宿主的顶部工具栏右侧动作布局 <!-- scope: example/lib/main.dart -->
  - 验收要点：示例应用顶部栏中的右侧快捷动作保持固定靠右，不因标题、窗口宽度或编辑器区域尺寸变化而遮挡。
  - 验收要点：撤销、重做、AI 对话、主题切换等现有入口的 tooltip、启用状态和点击行为保持不变。
  - 验收要点：示例宿主与默认桌面工具栏的右侧固定策略一致，方便人工验证反馈场景。
