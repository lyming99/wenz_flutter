# 隐藏图片块可见文字描述

## 需求概要

反馈 #27 要求图片不需要显示文字描述。结合当前实现，图片块会在 `_ImageBlockContent` 中把 `ImageBlockNode.caption` 渲染为图片下方可见 figcaption，同时 `_ImageBlockPlaceholder` 在空态、上传中和加载失败状态中显示标题与提示文案；这些都会让图片块出现额外文字。计划应收敛为图片块默认只显示图片 frame、图标/进度/状态视觉和选中交互，不再显示 caption 或占位提示文案；但保留 `caption` 与 `altText` 的数据、编辑、导入导出和无障碍朗读能力，避免破坏既有内容模型与业务集成。
