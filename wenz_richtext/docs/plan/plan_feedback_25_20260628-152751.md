# 反馈 #25 开发计划：连续引用块使用连续背景

- 反馈编号：#25
- 反馈内容：连续的引用块，应该使用连续的背景，目前存在间距
- 计划类型：bugfix / 视觉渲染优化
- 影响层：块垂直间距层 + 引用块 widget 渲染层

## 背景

引用块（`BlockType.quote`）由 `_QuoteBlockSurface`（`lib/src/widgets/wenz_rich_text_editor.dart:6378`）独立绘制：背景色 `scheme.surfaceContainer`、右侧上下圆角 `BorderRadiusDirectional.only(topEnd: 8, bottomEnd: 8)`、左侧 4px 强调条 `scheme.primary`、内部 padding `EdgeInsetsDirectional.fromSTEB(22, 8, 18, 8)`。引用块在 `_TextBlockRenderer.build`（`wenz_rich_text_editor.dart:6010`）被包裹为 `_QuoteBlockSurface(child: text)`。

连续出现多个引用块时存在三个相互叠加的问题：

1. **存在垂直间距**：块间垂直间距由 `_spacingBetweenBlocks`（`wenz_rich_text_editor.dart:5374`）计算。该函数对「列表项↔列表项」有特判（`_kListItemSpacing = 16 * 0.25 = 4.0`、`_kNestedListItemSpacing = 16 * 0.15 = 2.4`，`wenz_rich_text_editor.dart:124-125`），但对「引用块↔引用块」没有特判，于是回落到 `_blockMarginAfter` / `_blockMarginBefore` 的最大值（≈默认间距 `_kDefaultBlockSpacing`），在两个引用背景之间产生一段空白，背景无法连成一片。
2. **即便消除间距仍有右侧内凹缺口**：每个引用块的右下角（`bottomEnd`）与下一个引用块的右上角（`topEnd`）都各自向内圆角，背景首尾相贴时右侧会出现内凹缺口；强调条虽同色但被逐块独立绘制。
3. **渲染层缺少相邻上下文**：`BlockRenderContext`（`lib/src/widgets/block_renderer_registry.dart:214`）与 `_TextBlockRenderer`（`wenz_rich_text_editor.dart:5907`）当前只携带 `block / blockIndex / blockCount`，不携带兄弟块信息，渲染器无法判断当前引用块是否处于连续连排之中（首段 / 中段 / 尾段 / 独立）。

现有测试 `quote blocks fill the editable row width`（`test/widgets/editor_golden_test.dart:164`，构造 short-quote + empty-quote 同缩进连续 + indented-quote 缩进 1）与 `renders quote blocks with themed background`（`test/widgets/wenz_rich_text_editor_test.dart:1678`，构造 quote1 + quote2 连续）目前只断言背景矩形的 left/right 一致，**未断言相邻背景垂直首尾相接（前块.bottom == 后块.top）**，因此该间距缺陷未被回归保护。

## 目标

- 连续、缩进级别相同的引用块，背景连成一片（无可见缝隙），强调条贯通。
- 连排中仅最顶部保留上右圆角、仅最底部保留下右圆角，中段与拼接处不圆角，消除右侧内凹缺口。
- 缩进级别不同（左右起始位置不同）的相邻引用块保持原有间距与各自圆角，不强行合并。
- 连排内部段间仍保留合理纵向间距（来自 `_QuoteBlockSurface` 内部 padding 8/8），文字行距协调。
- 不影响其他块类型（段落、标题、列表、代码块等）的既有间距与渲染表现。
- 命中测试、光标几何（基于 `offsetFor`/`layoutFor` 的 `topFor`/`bottomFor`）与键盘上下导航在连续引用块间保持正确。

## 任务拆解

- [x] P001: 折叠连续同缩进引用块之间的垂直间距 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->

  验收要点：
  - 新增 `_isQuoteBlock(BlockNode)` 辅助函数（位于 `wenz_rich_text_editor.dart:5409` 一带的 `_isListItemBlock` 旁），判断 `block is TextBlockNode && block.type == BlockType.quote`，风格与 `_isListItemBlock` 一致。
  - 在 `_spacingBetweenBlocks`（`wenz_rich_text_editor.dart:5374`）中新增特判：当 `previous` 与 `next` 均为引用块且 `_blockIndentLevel` 相同时，返回折叠间距（`0` 或新增常量如 `_kAdjacentQuoteSpacing = 0`，使相邻背景矩形首尾相接）；缩进级别不同时回落到默认分支，保持各自独立。
  - 该间距同时被 `offsetFor`（`wenz_rich_text_editor.dart:3922`）与 `layoutFor`（`wenz_rich_text_editor.dart:3934`）使用，修改后命中测试与光标几何（基于 `topFor`/`bottomFor`）需与视觉位置一致，不得引入光标错位或方向键跨块跳跃异常。
  - 不得破坏既有分支：「fallback 与默认间距不同时直接返回 fallback」（`wenz_rich_text_editor.dart:5379`）与「列表项特判」（`wenz_rich_text_editor.dart:5382-5388`）行为不变。

- [x] P002: 引用块连排渲染为连续背景（圆角与强调条自适应） <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/widgets/block_renderer_registry.dart -->

  依赖 P001：背景连成一片需要 P001 折叠间距 + 本任务圆角自适应共同作用；二者改写同一文件相邻关注点，须在 P001 之后串行执行，避免并发冲突。

  验收要点：
  - 在 `BlockRenderContext`（`lib/src/widgets/block_renderer_registry.dart:214`）增加相邻引用块上下文（例如 `previousQuoteIndent` / `nextQuoteIndent`，或语义化的「是否处于同缩进引用连排及连排位置」标志如 `quoteGroupPosition`），默认值保持向后兼容，不影响未设置的现有自定义渲染器与手工构建的 context。
  - 在编辑器构建 `BlockRenderContext` 处（`lib/src/widgets/wenz_rich_text_editor.dart:4534`）依据兄弟块（前一个/后一个 block 的类型与缩进级别）填充上述上下文；连排判定规则须与 P001 的 `_spacingBetweenBlocks` 引用块特判一致（同类型 + 同缩进才算连排）。
  - 将该上下文沿 `_TextBlockRenderer`（`wenz_rich_text_editor.dart:5907`）透传到 `_QuoteBlockSurface`（`wenz_rich_text_editor.dart:6378`）。
  - 改造 `_QuoteBlockSurface` 依据连排位置决定圆角：独立引用块（前后均非同缩进引用）保留原有 `topEnd + bottomEnd` 圆角；连排首段仅保留 `topEnd`、去掉 `bottomEnd`；连排尾段仅保留 `bottomEnd`、去掉 `topEnd`；连排中段上下拼接处均不圆角，消除右侧内凹缺口。
  - 强调条（左侧 4px `scheme.primary`）与背景色在连排内保持同色贯通，视觉上连为一片；连排内部 padding 保持合理（顶部/底部 8），使相邻段落文字行距协调、不出现过大空白。
  - 仅同缩进级别的相邻引用块视为连排；不同缩进（如现有 golden 用例中 `indent: 1` 的 indented-quote）按独立引用块处理，保留各自圆角与间距。

## 总体验收标准

- 最终验收命令：
  1. `flutter analyze lib test`（无新增告警/错误）
  2. `flutter test test/widgets/editor_golden_test.dart`（引用块几何/金标准通过）
  3. `flutter test test/widgets/wenz_rich_text_editor_test.dart`（引用块渲染与交互通过）
  4. `flutter test`（全量测试通过，含 `block_structure_commands_test.dart`、`core/markdown_shortcut_commands_test.dart` 等）
- 验收范围：
  - 连续、同缩进引用块背景连续无缝隙、强调条贯通、圆角仅出现在连排顶部（`topEnd`）与底部（`bottomEnd`）。
  - 不同缩进相邻引用块、独立引用块、段落/标题/列表/代码块等其他块类型行为与外观保持不变。
  - 命中测试、光标几何（`topFor`/`bottomFor`）、键盘上下导航（方向键在连续引用块间移动）行为正确，无错位。
- 通过标准：上述命令全部通过；`flutter analyze` 无新增问题；视觉上连续引用块为一整片背景，缝隙与内凹缺口消失。
- 任务依赖：P002 依赖 P001；P003 依赖 P001、P002 的实现（描述场景即可，不要求本任务内运行）。
