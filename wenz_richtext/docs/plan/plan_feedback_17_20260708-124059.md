# Fix adjacent inline formula edit targeting

## 需求概要

Feedback #17 reports that after inserting two formulas on the same line, editing the second formula has no effect. In the current code, inline formulas are atomic one-character inline nodes. `_InlineFormulaView` carries a `DocumentPosition`, and `_confirmFormulaEditor` calls `WenzRichTextController.updateInlineFormula`, which resolves the target in `UpdateInlineFormulaCommand._updateInlineFormulaContent`. That resolver currently treats a formula node range as including its end boundary. When two formula embeds are adjacent, the first formula end offset equals the second formula start offset, so the second formula's start offset can be claimed by the first formula before the loop reaches the intended node. The implementation should clarify the inline formula range boundary semantics, keep paragraph and table-cell behavior aligned, and add regression coverage for consecutive formulas on one visual line.
