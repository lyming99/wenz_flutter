# 反馈开发计划：块菜单工具栏与代码块选中态视觉优化

## 来源
- 类型：反馈
- 编号：8
- 生成时间：2026-06-26 02:53:28

## 原始内容
1. 所有块的菜单工具栏，放到右上角显示，尽可能简约，不需要占用全行。
2. 优化一下菜单 popup 的样式。
3. 优化一下工具栏的图标样式。
4. 优化一下代码块的选中底色，目前在深色背景下显示不明显。

## 需求理解
- 本次反馈聚焦块级元素的悬浮操作区、菜单弹层、图标视觉和代码块选中态对比度，属于编辑器渲染与交互层优化。
- “所有块的菜单工具栏”应覆盖代码块、表格、图片、视频、文件、引用块等块级元素；工具栏应贴近块右上角，以轻量浮层形式出现，不再占用整行布局空间。
- 菜单 popup 与工具栏图标需要统一视觉语言，包括尺寸、圆角、阴影、间距、hover/pressed/disabled 状态和深浅主题可读性。
- 代码块选中底色需要在深色代码背景下具备足够对比度，同时不破坏语法高亮、查找高亮、光标、拖选和复制行为。
