# 反馈开发计划：斜杆智能 Popup 不出现

## 来源
- 类型：反馈

## 原始反馈
编辑器中输入斜杆，还是没有出现popup，类似代码编辑器的智能popup

## 问题理解
- 用户期望在编辑器获得焦点后输入 `/` 时，立即出现类似代码编辑器智能提示的斜杆命令 popup，并可继续输入关键词筛选命令。
- 当前项目已有 `SlashMenuController`、默认命令注册表、编辑器浮层常量和相关测试，问题更可能出在输入事件触发、控制器刷新时机、popup 锚点计算或浮层渲染条件，而不是完全缺失功能。
- 修复需要覆盖键盘文本输入、IME 提交、空段落/段落开头/行内输入等常见触发路径，并确保只读、组合输入中、无匹配项、手动关闭等已有边界不被破坏。
- 目标是让 `/` 输入后菜单稳定打开、位置贴近光标、筛选与键盘导航可用，行为接近代码编辑器的命令补全体验。
