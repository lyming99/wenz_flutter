# 开发计划 #25: Mermaid 图表支持

## 需求概述

在 wenz_richtext 富文本编辑器中支持 Mermaid 图表（流程图、甘特图、思维导图、时序图等）。复用现有 `CodeBlockNode`（`language == 'mermaid'` 即视为图表块），通过 `merman` pub 包（FFI 绑定）渲染 SVG，参考 Notion 的「预览/源码」切换交互。

## 关键约束

- 数据模型零改动：复用 `CodeBlockNode`，不新建 BlockType、不改 BlockNode、不改 codec
- `merman` 依赖懒加载+容错：FFI 失败时回退纯文本
- SVG 渲染面可插拔：定义 `DiagramSvgSurface` 抽象，通过 `WenzEditorConfiguration` 注入
- `BlockAttributes.toJson/fromJson` 不透传未知键，预览/源码切换状态使用 widget 内部 `setState`（非持久化）

1. `flutter analyze` 无新增 error/warning（仅允许既有 warning）

4. example app 在 Windows 桌面可运行：插入 mermaid 代码块 → 切预览见图 → 改源码后预览更新 → 切回源码可编辑 → 普通 code 块行为完全不变
5. 发布依赖 `merman: ^0.8.0-alpha.2` 和 `flutter_svg: ^2.0.10+1` 正确添加到 pubspec.yaml
6. 库 barrel 文件 `lib/wenz_richtext.dart` 正确导出所有新增公开 API

- [x] P002: 创建 Mermaid 插件文件 `lib/src/plugins/mermaid_diagram_plugin.dart` <!-- scope: lib/src/plugins/mermaid_diagram_plugin.dart -->
  - 验收要点：
    - 定义 `abstract class DiagramSvgSurface`：方法 `Widget render(BuildContext context, String svg, {double? maxWidth})`
    - 定义 `class VectorGraphicsDiagramSurface extends DiagramSvgSurface`：用 `flutter_svg` 的 `SvgPicture.string` 做 best-effort 渲染
    - 定义 `class MermaidDiagramConfig`（携带 `DiagramSvgSurface? svgSurface`、`Duration debounce` 默认 300ms、`String defaultTheme` 默认 `'default'`）
    - 定义 `class MermaidRenderer` 可替换抽象（默认实现 `NativeMermaidRenderer` 调用 `Merman.open()`，用于支持测试注入 fake）
    - 定义 `class MermaidDiagramPlugin extends WenzRichTextPlugin`：
      - `id` = `'wenz.richtext.mermaid'`
      - `install(context)` 时：`context.blockRenderers?.resolve(BlockType.code)` 拿到原 builder，然后用 `context.blockRenderers?.register(BlockType.code, ...)` 注册包装 builder；包装 builder 在 `block is CodeBlockNode && block.language == 'mermaid'` 时返回图表 widget，否则委托原 builder

- [x] P003: 创建 Mermaid 图表渲染 widget `lib/src/widgets/mermaid/mermaid_code_block_widget.dart` <!-- scope: lib/src/widgets/mermaid/mermaid_code_block_widget.dart -->
  - 验收要点：
    - 用 `StatefulWidget`，内部维护 `_showSource`（默认 `true`/源码态）、`_svg`、`_error`、`_rendering` 状态
    - 视觉语言对齐现有 `_CodeBlockRenderer`：深色圆角容器 `0xFF1E1E2E`、等宽字体、复用 `_kCodeBlockRadius` 常量
    - 源码态：显示带行号的只读源码（用 `CodeSyntaxHighlighter` 高亮，或纯文本等宽展示），并在文档中注明编辑能力后续接入

    - 错误态：显示 `_error` 文案 + 「查看源码」回退按钮

    - 渲染在后台 isolate 中执行（`Isolate.run` 内调 `Merman.open()` + `renderSvg(source, optionsJson: '{"svg":{"pipeline":"resvg-safe"}}')`），避免卡 UI 线程
    - 切换按钮放在工具栏区域（类似 `_CodeBlockToolbar` 布局），使用 `Icons.visibility_outlined`（预览）和 `Icons.code`（源码）图标
