## 背景与现状

项目是 Flutter 富文本编辑器 package。分割线块由 `lib/src/widgets/wenz_rich_text_editor.dart` 中 `_defaultDividerBlockRenderer` 渲染，实际 UI 在 `_DividerBlockContent` 内完成。当前分割线内容使用只有高度、没有稳定宽度的 `SizedBox` 包裹 `Stack`，非定位子是中心圆点，横线用 `PositionedDirectional(start: 0, end: 0)` 绘制。在某些父约束下 `Stack` 会按圆点尺寸收缩，最终横线被压成圆点宽度，用户看到的效果就是“只显示一个点”。

图片块同样集中在 `wenz_rich_text_editor.dart`。斜杆菜单的“图片”项位于 `lib/src/controller/slash_menu_controller.dart`，它会插入一个没有原始宽高、没有 `showWidth/showHeight` 的 `ImageBlockNode`，并把 selection 放到对象块上。默认图片渲染器随后进入 `_SelectableImageBlock`、`_ImageBlockContent` 和 `_ImageBlockPlaceholder`。当前 `_ImageDisplayMetrics.resolve` 在缺少显式尺寸时可能只给出 `maxWidth` 而不生成有限 `displaySize`，选中态 `_MediaSelectionStroke` 与 `StackFit.passthrough` 再叠加无界高度约束，容易触发 `BoxConstraints forces an infinite height`。修复应优先放在图片块渲染约束层，而不是改变斜杆菜单插入语义。

## 目标

- 分割线块在普通、选中、窄宽度和深浅主题下都显示为完整水平线加居中圆点，不再收缩为单点。
- 斜杆菜单插入图片后，默认图片占位块获得有限宽高，编辑器不再因为无界高度约束崩溃。
- 图片块已有能力保持兼容：resolver 自定义图片、空占位、失败占位、caption、对齐、选中态工具条和拖拽调整尺寸不回归。
- 新增回归测试覆盖分割线宽度和斜杆插入图片的真实 widget 路径。
