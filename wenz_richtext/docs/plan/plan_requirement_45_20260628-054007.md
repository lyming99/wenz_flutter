# 需求 #45 开发计划：斜杆弹出 popup 实现

## 需求理解

> 原始需求：斜杆弹出 popup 实现一下

在编辑器中输入 `/`（斜杠）后，在光标处弹出浮动命令菜单（类似 Notion / Tiptap 的 slash menu），支持：

- 通过关键字过滤命令项；
- 键盘上下键移动高亮、回车确认插入对应块、Esc 关闭；
- 鼠标/触摸点击命令项直接插入；
- 点击菜单外、失焦、只读、文档结构变化时自动关闭；
- 菜单跟随光标定位、避开键盘与视口边界。

## 现状说明（实现前必读）

经代码勘察，本仓库**已存在**相当完整的斜杆菜单实现，且已通过 `lib/wenz_richtext.dart` 对外导出：

- 控制器：`lib/src/controller/slash_menu_controller.dart`（`SlashMenuController` / `SlashMenuRegistry` / `SlashMenuItem` / `SlashMenuTrigger`，含触发检测 `_detectTrigger`、过滤、高亮、激活、IME 组合态屏蔽）。
- 浮层 UI：`lib/src/widgets/slash_menu_overlay.dart`（`WenzSlashMenuOverlay`，列表项 / 图标 / 标题 / 描述 / 选中态 / 语义）。
- 编辑器集成：`lib/src/widgets/wenz_rich_text_editor.dart`（在 `Stack` 内按光标定位 `Positioned` 浮层、视口与键盘 inset 边界裁剪、向上展开判定、滚动跟随、键盘路由、点击外部/失焦/只读关闭）。
- 已有测试：`test/controller/slash_menu_controller_test.dart`、`test/widgets/slash_menu_overlay_test.dart`。

**确认的真实缺口**：示例应用 `example/lib/main.dart` 未接入 `slashMenuController`，演示中无法触发该浮层。

因此本计划的执行目标不是推倒重建，而是：**逐项核对/补全斜杆弹出 popup 的端到端能力**，确保在真实运行中稳定可用、测试覆盖到位、并在示例中可演示。执行时若某项能力已存在且符合验收要点，则视为该任务已完成并记录结论，不要重复造轮子。

## 任务拆解

- [x] P001: 实现斜杆触发检测、查询过滤与高亮激活的控制层 <!-- scope: lib/src/controller/slash_menu_controller.dart -->
  - 验收要点：
    - 在文本块的起始或中间输入 `/` 后，光标在该块内时能检测出 `SlashMenuTrigger`（含 blockId/blockIndex/path/start/end/query）；`/` 之前若有内容也应在行首或空白后正确触发（按现有 `_slashStartBeforeCaret` 规则一致）。
    - 输入 `/xxx` 时，`query` 为 `xxx`，并通过 `SlashMenuRegistry.filter` 按 id/title/description/keywords 过滤；过滤后无结果则不展示浮层。
    - `highlightedIndex` 默认 0，`moveHighlight` 支持上下键并循环回绕，`selectIndex` 做边界 clamp。
    - `activate(item)` / `activateHighlighted()` 在插入目标块前删除触发区文本，插入后清空 trigger 并关闭菜单。
    - 触发检测在「不可编辑 / 选区未折叠 / 光标不在块文本 / 文档结构变化」时不触发或自动关闭。

- [x] P002: 实现斜杆浮层 UI（WenzSlashMenuOverlay） <!-- scope: lib/src/widgets/slash_menu_overlay.dart -->
  - 验收要点：
    - `controller.isOpen` 为 false 时渲染 `SizedBox.shrink()`，不占位。
    - 列表渲染 `controller.items`，每项含图标 + 标题 + 描述，并带 `wenz-slash-menu-overlay` 与 `wenz-slash-item-<id>` 的 ValueKey。
    - 高亮项（`highlightedIndex`）有选中态样式（背景 / 字重 / 图标色），并提供正确的语义标签（标题，描述）。
    - 尺寸受 minWidth/maxWidth/maxHeight 约束（maxWidth < minWidth 时以 maxWidth 为准做收敛）。
    - 点击某项调用 `selectIndex` + `activate`。

- [x] P003: 编辑器内按光标定位的悬浮浮层与边界裁剪 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：
    - 仅在非只读且 `slashMenuController.isOpen` 时，于编辑器 `Stack` 内构建 `_buildSlashMenuOverlay`。
    - 以光标 caret 矩形为锚点定位（`caretRectForPosition`），水平方向 clamp 不溢出右边界。
    - 下方空间不足且上方更宽裕时改为向上展开（opensAbove）。
    - 计入键盘 `viewInsets.bottom` 与视口高度，浮层不超出可见区域，留 `_kPopupViewportInset` 安全边距。
    - 滚动（`_handleScrollChanged`）时浮层随光标重新定位（触发 setState）。

- [x] P004: 斜杆浮层的键盘路由与生命周期关闭 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart,lib/src/controller/slash_menu_controller.dart -->
  - 验收要点：
    - 菜单打开时 ArrowUp/ArrowDown 路由到 `moveHighlight`（并阻止默认滚动），Enter/回车激活高亮项，Escape 关闭菜单。
    - 点击浮层外部（`TapRegion` `onTapOutside`）关闭菜单；点击浮层内部不穿透到编辑器。
    - 编辑器失焦（`_hadEditorFocus` 变为 false）关闭菜单；切换为只读时关闭菜单。
    - 文档结构变化（增删块）时关闭菜单，避免与后续插入冲突。

- [x] P005: 内置斜杆命令项与触发区块替换动作 <!-- scope: lib/src/controller/slash_menu_controller.dart -->
  - 验收要点：
    - `defaultSlashMenuItems()` 提供 heading / bulleted list / todo / quote / code block / table(3×3) / image / video 等命令项，含中文/英文 keywords。
    - 各项 action 将 `/...` 触发文本替换为对应类型块：heading(list level=1)、listItem(bullet)、listItem(task)、quote、code、table、image、video，并定位到合理的新光标位置。
    - 触发块前后若还有内容，应正确拆分为前/插入/后三块，不丢字。

- [x] P006: 斜杆菜单与 IME 输入法（中文等组合输入）兼容 <!-- scope: lib/src/controller/slash_menu_controller.dart -->
  - 验收要点：
    - 处于输入法组合态（`isApplyingComposingTextInput` 或 `compositionState != null`）时不触发/不刷新浮层，避免拼音过程误弹。
    - 组合态结束、提交文本为 `/` 时才正常弹出；纯组合变化不关闭已打开的菜单（除非结构变化）。
    - 中文/拼音场景下输入 `/xxx` 过滤正确，不被组合事件打断。

- [x] P007: 示例应用接入斜杆菜单，使其可演示 <!-- scope: example/lib/main.dart -->
  - 验收要点：
    - `example/lib/main.dart` 中创建并持有 `SlashMenuController`（生命周期随页面销毁 dispose），传入 `WenzRichTextEditor.slashMenuController`。
    - 真机/示例运行时，聚焦编辑器输入 `/` 能在光标处看到浮层；输入关键字可过滤；回车/点击插入块。
    - 不影响只读模式与既有示例功能。

  - 验收要点（仅描述应覆盖场景，不在本任务内运行）：

    - 高亮：默认 0、上下键循环回绕、空结果时不报错。
    - 激活：heading/list/todo/quote/code/table/image/video 各插入正确块类型且删除触发文本，光标落在合理位置。
    - 浮层 UI：关闭态不渲染、列表项 key、选中态样式、语义标签、尺寸约束收敛。
    - 编辑器集成：Enter 激活、上下键路由、Esc/失焦/点击外部/只读关闭、视口与键盘 inset 边界裁剪不溢出、滚动时重新定位。
    - IME 组合态：组合过程中不弹/不刷新，提交后正常弹出。
