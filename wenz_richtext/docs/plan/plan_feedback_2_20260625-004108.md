# 开发计划：反馈 #2 富文本渲染与选择体验优化

## 来源
- 类型：用户反馈
- 编号：#2
- 生成时间：2026-06-25 00:41:08
- 原始反馈：
  1. @提及后面的文字无法被选择
  2. 引言内容渲染方式优化一下，用背景块颜色背景的方式渲染引言内容
  3. todo内容优化一下，用checkbox切换todo完成状态
  4. info卡片目前无法被选择
  5. 表格工具栏应该在表格上方，而不是在表格下方，占用内容
  6. 表格边框除了最边缘，内部的边框存在重复绘制，显示2条线
  7. 公式渲染要用特殊组件渲染，目前只是显示了文字，参考gpt_markdown项目优化

## 问题理解
- 本次反馈覆盖选择模型、块级渲染、交互控件、表格浮层、表格绘制和公式渲染多个方向，需要按模块拆分并逐项验证。
- `@mention` 后续文字和 `info` 卡片无法选择，说明当前选择命中测试、块级/内联节点 offset 映射或不可选组件包裹策略仍存在遗漏。
- 引言、todo、info、公式属于富文本语义节点，需要在保持文档模型稳定的前提下优化视觉与交互，不应只做纯样式遮罩。
- 表格工具栏和边框问题属于布局与绘制体验缺陷，需要避免工具栏占用正文流空间，并统一边框绘制责任以消除内部双线。
