# wenz_richtext 手机端（移动端）适配：桌面/移动双 UI 并存，按配置与响应式断点选择

## 需求概要

为 wenz_richtext 增加移动端适配能力。核心层（model/command/codec/controller/history）已是平台无关纯 Dart，无需改动；适配工作集中在 widget 层与 input 层。目标：桌面端现有行为完全保持不变，移动端通过新增 token 化、响应式布局、移动工具栏、选择手柄、移动化侧边面板获得可用体验，桌面/移动两套 UI 并存并由 WenzEditorConfiguration.layout（auto/desktop/mobile）+ 运行时 MediaQuery.shortestSide<600 共同决定渲染哪一套。按 阶段0（token 化 + 响应式布局 + SafeArea + 触屏降级）→ 阶段2（移动工具栏 + 软键盘协同）→ 阶段1（选择与手势）→ 阶段3（侧边面板移动化）推进。所有新增配置字段均带默认值并沿用 _unset sentinel 的 copyWith 模式，不破坏 tier1/tier2 稳定 API。
