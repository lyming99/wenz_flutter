# Plan Feedback #44 — 修复键盘导航选中文字问题

## 需求概述

反馈内容：Home / End / Ctrl+Left / Ctrl+Right 等键盘操作，在没有按住 Shift 时不应该选中文字，只应跳动光标；只有 Shift 按下时才应扩展选区。

## 问题根因分析

经过代码审查，`shortcut_manager.dart` 的快捷键解析层和 `_performShortcut` 的执行分发层逻辑均**正确**——`expandSelection` 仅在 `shiftPressed` 为 `true` 时才设为 `true`，且该标志正确传递到 controller 层。

问题出在 `selection_commands.dart` 中两个命令的 `execute()` 方法：

1. **`MoveCaretByWordCommand`**（Ctrl+Left / Ctrl+Right）——当 `expandSelection=false` 且当前存在非折叠选区时：
   - `anchor = _collapseTo(selection, direction)` 正确折叠到选区一端
   - 但 `next = _moveWordFrom(session.document, selection.extent, direction)` **仍然从原始 extent 计算**目标位置
   - 导致 `DocumentSelection(base: anchor, extent: next)` 中 `anchor` 和 `next` 不在同一位置，产生非预期的选区

2. **`MoveCaretToBlockBoundaryCommand`**（Home / End）——同类型缺陷：
   - `anchor` 从折叠位置计算，`next` 从原始 extent 计算
   - 导致 Home/End 在有选区时产生非折叠结果

对比 `MoveCaretCommand`（普通左右箭头），它已正确处理此场景：
```dart
if (!selection.isCollapsed) {
    // 先折叠选区，不移动光标
    final position = switch (direction) {
        CaretMovementDirection.backward => selection.start,
        CaretMovementDirection.forward => selection.end,
    };
    return CommandResult(
        selection: DocumentSelection(base: position, extent: position),
    );
}
```

3. **`MoveCaretToDocumentBoundaryCommand`**（Ctrl+Home / Ctrl+End）—已正确处理（`!expandSelection` 分支返回 collapsed selection），但代码中有冗余的 `anchor` 计算可清理。

  - `MoveCaretByWordCommand.execute()` — 需要修复
  - `MoveCaretToBlockBoundaryCommand.execute()` — 需要修复
  - `MoveCaretToDocumentBoundaryCommand.execute()` — 代码梳理（逻辑正确，简化冗余计算）

- `test/core/selection_commands_test.dart` — 补充以下场景的测试用例：

  - 存在非折叠选区时，按 Home/End（不带 Shift）→ 光标跳到块首/尾且不选中
  - 存在非折叠选区时，按 Ctrl+Home/Ctrl+End（不带 Shift）→ 光标跳到文档首/尾且不选中

## 任务拆解

- [x] P001: 修复 MoveCaretByWordCommand 的非折叠选区处理逻辑 <!-- scope: lib/src/core/commands/selection_commands.dart -->
  - **问题**：当 `expandSelection=false` 且存在非折叠选区时，anchor 从折叠位置取、next 从原始 extent 计算，两者不一致导致产生非预期选区
  - **修复方案**：当 `expandSelection=false` 时，先统一从折叠位置出发计算 `origin`，再从 `origin` 做 word 跳转，保证 base==extent（折叠）
  - **验收要点**：
    1. 有选区时按 Ctrl+Left（不带 Shift），光标从选区 start 向左侧跳一个单词，无选区产生
    2. 有选区时按 Ctrl+Right（不带 Shift），光标从选区 end 向右侧跳一个单词，无选区产生
    3. 无选区时按 Ctrl+Left/Ctrl+Right（不带 Shift），行为不变（正常单词跳转）
    4. 有选区时按 Ctrl+Left/Ctrl+Right **带 Shift**，行为不变（扩展选区到单词边界）
    5. 光标已在文档首/尾时 Ctrl+Left/Ctrl+Right 不报错

- [x] P002: 修复 MoveCaretToBlockBoundaryCommand 的非折叠选区处理逻辑 <!-- scope: lib/src/core/commands/selection_commands.dart -->
  - **问题**：同 P001，anchor 和 next 来源不一致
  - **修复方案**：`expandSelection=false` 时使用折叠后的位置作为 extent 来源计算偏移目标
  - **验收要点**：
    1. 有选区时按 Home（不带 Shift），光标跳到当前块首（offset=0），无选区产生
    2. 有选区时按 End（不带 Shift），光标跳到当前块尾，无选区产生
    3. 无选区时 Home/End（不带 Shift），行为不变
    4. 有选区时 Home/End 带 Shift，行为不变（扩展到块首/尾）
    5. 光标在表格单元格内时 Home/End 行为正确
