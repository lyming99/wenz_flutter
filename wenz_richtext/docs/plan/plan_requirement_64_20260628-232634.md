# 需求 #64 开发计划：example 右侧显示大纲树

> 需求原文：example，要在右侧显示大纲树。
>
> 目标：在 example 应用右侧新增一个「大纲树」面板，按标题层级展示当前文档的标题结构，支持点击跳转到对应标题、跟随编辑实时更新、高亮当前所在标题。

## 背景与现状（基于现有代码）

- 大纲数据已就绪：`lib/src/controller/outline_controller.dart` 中的 `WenzOutlineController` 已从标题块派生 `List<OutlineItem>`，并通过 `lib/wenz_richtext.dart` 导出 `WenzOutlineController`、`OutlineItem`。
  - `OutlineItem` 字段：`blockId`、`blockIndex`、`level`(1-6)、`title`、`anchor`、`isCollapsed`、`canCollapse` 等。
  - 导航：`select(item)` / `selectByBlockId(id)` / `selectByAnchor(anchor)` 会把宿主选区移到标题起点；文档注释明确「挂载的 `WenzRichTextEditor` 会通过既有选区处理把光标滚动进入视野」，因此**跳转滚动无需额外接线**。
  - 控制器是 `ChangeNotifier`，组件可用 `addListener` 订阅、`setState` 重建。
- 缺失：目前**没有**与 `WenzOutlineController` 配套的「大纲树」展示组件（不像评论侧已有 `WenzCommentSidebar`）。
- 现成参照：`lib/src/widgets/comment_sidebar.dart` 的 `WenzCommentSidebar`（`SizedBox` + `Material` + `Column`：头部 + 列表 + 空状态），对应测试 `test/widgets/comment_sidebar_test.dart`。
- example 现状：`example/lib/main.dart` 的 `EditorWorkbench.body` 为 `Row`：左侧宽 280 的 `_InspectorPanel` + `Expanded` 的编辑器列（工具栏 + 编辑器）。`WenzEditorBootstrap.create` 当前 `enableOutline: false`，`bootstrap.outlineController` 为 `null`。

## 设计决策（关键取舍）

1. **将大纲树实现为可复用的库组件** `WenzOutlineTree`（而非仅写在 example 内）。理由：`WenzCommentSidebar` 已是该仓库的既定模式（库提供侧栏组件、example 负责接线），而 `WenzOutlineController` 已导出却无配套组件，补齐组件是自然完成项，且可被其它业务消费。
2. **导航/滚动沿用既有机制**：点击项 → 调用 `WenzOutlineController.select(item)`，编辑器自动滚动并聚焦到标题，无需新增滚动 API。
3. **激活项高亮**由 example 根据当前 `selection.extent.blockIndex` 反查所属标题、把 `activeBlockId` 传给组件（组件保持纯展示，不自行读取选区）。
4. example 右侧面板较薄，可在 `example/lib/main.dart` 内直接渲染 `WenzOutlineTree`；若 main.dart 过长，允许抽出到 `example/lib/outline_panel.dart`（任务 scope 已包含该可选文件）。

## 任务拆解

- [x] P001: 新增大纲树组件 WenzOutlineTree <!-- scope: lib/src/widgets/outline_tree.dart -->
  - 在 `lib/src/widgets/outline_tree.dart` 新建展示型组件，结构对齐 `WenzCommentSidebar`（`SizedBox` + `Material` + `Column`：头部「大纲」标题 + 列表 + 空状态）。
  - 入参：`List<OutlineItem> items`（必填）、`String? activeBlockId`（当前/激活标题）、可选 `double width`（默认约 260）、可选 `ValueChanged<OutlineItem>? onSelect`、可选 `emptyBuilder`。
  - 列表项按 `OutlineItem.level`(1-6) 做层级缩进渲染标题文本，文本溢出省略；使用 `Theme.of(context)` 适配明/暗主题。
  - 点击项触发 `onSelect(item)`（由 example 调用 controller 的 `select` 完成跳转）；当前激活项（`item.blockId == activeBlockId`）渲染高亮态。
  - 空状态：`items` 为空时显示空提示文案（参照 `_EmptyComments`）。
  - 暴露稳定可测 Key：组件根 `'wenz-outline-tree'`、列表项 `'wenz-outline-item-{blockId}'`，便于测试与集成测试定位。
