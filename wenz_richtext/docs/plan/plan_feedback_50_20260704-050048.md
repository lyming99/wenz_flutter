# 开发计划：块操作拖拽悬浮内容渲染（反馈 #50）

## 需求概述

块操作拖拽排序时，需要显示一个跟随鼠标/指针位置的悬浮内容渲染（拖拽预览/幽灵块）。当前拖拽只显示一条插入位置指示线，缺少对被拖拽块内容的视觉反馈。

## 现状分析

块拖拽排序的现有实现位于 `lib/src/widgets/wenz_rich_text_editor.dart` 中的私有类：

| 类 | 职责 |
|---|---|
| `_BlockDragHandleOverlayState` | 块级 chrome rail 布局，包含拖拽手柄 |
| `_BlockDragHandleButtonState` | 拖拽交互核心：pointer down/move/up、drop indicator overlay、菜单 |
| `_BlockReorderRowGeometry` | 用 `RepaintBoundary` 包裹块行，注册到 `BlockGeometryRegistry` |
| `_BlockMoveRange` | 拖拽移动范围（单块或多块选区） |

当前拖拽流程：
1. `_handlePointerDown` 记录 `_pressOrigin`
2. `_handlePointerMove` 超过 `dragStartSlop` 后设置 `_dragging = true`
3. `_updateDropTarget` + `_syncDropIndicator` 在 Overlay 中绘制插入指示线
4. `_handlePointerUp` 提交重排 → `_submitBlockReorder`

**缺失**：没有悬浮内容预览。

---

## 技术方案

### 方案选择：`RepaintBoundary.toImage()` 快照 + OverlayEntry 跟随

块行已有 `RepaintBoundary`（`_BlockReorderRowGeometry.build`），可在拖拽启动时从中捕获 `ui.Image`，再通过 `RawImage` 渲染为半透明浮动层。

### 核心修改范围

- `lib/src/widgets/wenz_rich_text_editor.dart` — 主要修改文件
  - `_BlockDragHandleButtonState`：新增浮动预览 OverlayEntry 管理、快照捕获、位置更新
  - `_BlockDragHandleOverlayState` / `_BlockReorderRowGeometry`：向拖拽手柄暴露 `RepaintBoundary` 的 GlobalKey 用于快照

## 任务拆解

- [x] P001: 向拖拽手柄传递 RepaintBoundary 引用以支持快照捕获 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - `_BlockReorderRowGeometry` 已有 `_rowKey`（GlobalKey），确认该 key 可用于 `RenderRepaintBoundary.toImage()`
  - 若当前 key 层级无法访问 RepaintBoundary，新增专门的 `_dragSnapshotKey`（GlobalKey）并放置在正确的 `RepaintBoundary` widget 上
  - 将该 key 通过 `_BlockDragHandleOverlay` → `_BlockDragHandleButton` 的构造参数链传递下去
  - 验收要点：`_BlockDragHandleButton` 在拖拽启动时能通过传入的 GlobalKey 获取 `RenderRepaintBoundary` 引用

- [x] P002: 实现拖拽启动时的块内容快照捕获逻辑 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 在 `_BlockDragHandleButtonState` 中新增字段：`ui.Image? _dragSnapshot`、`OverlayEntry? _dragPreviewEntry`、`Offset _dragPointerPosition = Offset.zero`
  - 在 `_handlePointerMove` 首次越过 `dragStartSlop` 且 `_dragging` 变为 true 时，异步调用 `_captureDragSnapshot()` 捕获块快照
  - `_captureDragSnapshot()`：通过 `RenderRepaintBoundary.toImage()` 捕获像素数据，处理捕获失败（size 为 0 或 null）的边界情况，捕获成功后插入浮动预览 OverlayEntry
  - 验收要点：开始拖拽后异步捕获块内容为 `ui.Image`；size 为 0 时静默跳过不崩溃；捕获成功后可创建浮动层

- [x] P003: 实现跟随指针的悬浮预览 OverlayEntry <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - `_buildDragPreview(ui.Image image)`：构建 `RawImage` 包裹的半透明浮动预览 widget，包含：
    - `RawImage(image: image, opacity: _dragPreviewOpacity)`（默认约 0.85）
    - 外层 `DecoratedBox` 添加圆角、背景和阴影（`elevation: 8`, `borderRadius: 8`）
    - `IgnorePointer` 包裹避免预览遮挡其他块
  - 在 `_handlePointerMove` 中更新 `_dragPointerPosition` 并调用 `_dragPreviewEntry?.markNeedsBuild()`
  - 浮动预览位置 = 指针位置 + 固定偏移（如 dx: -16, dy: -12），防止手指/光标遮挡内容
  - 验收要点：拖拽越过阈值后出现浮动预览；预览跟随指针移动；预览不拦截指针事件；预览有半透明和阴影效果

- [x] P004: 拖拽结束/取消时清理浮动预览和快照资源 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 在 `_handlePointerUp` 和 `_handlePointerCancel` 的清理路径中，统一调用 `_removeDragPreview()` 移除 OverlayEntry
  - `_removeDragPreview()` 移除 `_dragPreviewEntry`、释放 `_dragSnapshot?.dispose()`、置 null
  - 在 `_BlockDragHandleButtonState.dispose()` 中也调用 `_removeDragPreview()` 防止泄漏
  - 验收要点：指针抬起后预览消失；指针取消后预览消失；dispose 时无泄漏；快照 `Image` 资源正确释放

- [x] P005: 视觉打磨与边界情况处理 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 预览透明度调优：拖拽中约 0.85，原位置块略微降低不透明度至约 0.3 作为位置提示（可选，由需求确认）
  - 预览尺寸限制：当块内容很高（如大表格/代码块）时，对预览设置 `clipBehavior: Clip.antiAlias` 和 `maxHeight`（如渲染视口高度的 0.4 倍），防止预览过大
  - 光标样式：拖拽中保持 `SystemMouseCursors.grabbing`
  - 快照捕获失败时（如非 RepaintBoundary 节点、渲染对象为 null）静默降级，只显示插入指示线而不崩溃
  - 验收要点：高块有最大高度裁剪；快照失败不影响拖拽排序功能；视觉过渡平滑

## 总体验收标准

1. **功能正确性**：拖拽块操作时，出现跟随指针的块内容悬浮预览；释放后提交排序并清理预览
2. **视觉质量**：预览半透明（约 0.85 不透明度）、有阴影、圆角；预览与指针保持合理偏移
3. **资源安全**：`ui.Image` 在拖拽结束/取消/dispose 时正确释放；OverlayEntry 无残留
4. **降级处理**：快照捕获失败时不影响拖拽排序核心功能
5. **代码质量**：`flutter analyze` 无新增错误或警告
