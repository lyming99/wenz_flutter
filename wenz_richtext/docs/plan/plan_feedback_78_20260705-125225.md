# 精简默认编辑器工具栏并折叠插入功能

## 需求概要

根据反馈 #78，默认桌面工具栏需要从当前铺开的全量按钮改为更简约的编辑入口：移除撤销/重做、表情、批注、缩进/缩退等可见按钮，将链接、公式和插入类操作收纳到单个“+”popup；标题/正文和对齐方式改为下拉选择；文字颜色在现有预设基础上支持用户选择具体颜色。代码影响主要集中在默认桌面工具栏实现和对应 widget 测试。

  - 验收要点：加粗、斜体、下划线、删除线、文字颜色、清除文字颜色、清除样式等核心文字编辑能力仍保留在主工具栏并维持选中态和禁用态。
