## 背景与影响范围

本项目是 Flutter 富文本编辑器组件。图片块默认渲染入口位于 `lib/src/widgets/wenz_rich_text_editor.dart` 的 `_defaultImageBlockRenderer`，实际图片 figure 由 `_ImageBlockContent` 绘制，并通过 `_MediaSelectionStroke` 在图片 frame 上绘制选中描边。

当前图片选中且可编辑时，`_ImageBlockContent._buildFrame` 会同时构建左右两个 `_ImageResizeHandle`，其视觉宽度由 `_kImageResizeHandleVisualWidth` 控制，呈现为图片左右边缘两条竖线。需求“图片块选择状态，不需要左右2条‘线’”按项目现状解释为：图片处于 object selection 时应只保留贴合图片 frame 的选中描边，不再被左右两条 resize 可视线干扰。

范围限定：
- 只调整图片块默认 widget 的选中态与 resize 边缘 affordance，不修改 `ImageBlockNode` schema、codec、插入/删除命令、`showWidth/showHeight` 字段语义和 `MediaResolver` 注入方式。
- 保留 `_MediaSelectionStroke` 的单一选中描边、图片对象工具栏、双击/按钮预览、caption、alignment 和只读/权限 gate。
- 优先保留 #71 已实现的图片按比例 resize 能力，但将“选中态可见左右线”与“边缘可拖拽命中区”解耦；若实现中需要彻底移除边缘拖拽入口，必须保留对象菜单中的图片尺寸设置与重置能力。

## 实施策略

最小改动路径是在 `_ImageResizeHandle` 或其调用层区分“命中层”和“视觉层”：图片选中后仍可根据 `canResize` 布置边缘拖拽命中区域、鼠标 cursor、语义和 selection exclusion，但默认 idle 选中态不绘制左右两条竖向可视线。拖拽过程中可继续依赖 frame 尺寸预览、选中描边跟随和 toolbar anchor 跟随表达反馈，避免增加新的常驻线条。

测试侧需要更新现有“dragging selected image edge resizes...”用例：不再依赖可见 `wenz-richtext-image-resize-left/right-*` 线条作为断言目标，而应覆盖“选中态无左右线、仍可从边缘命中区拖拽 resize、描边/toolbar/caption 跟随”的行为。文档侧同步把“选中图片显示左右手柄”的口径改为“选中图片不显示常驻左右线，resize 通过边缘命中区或现有尺寸菜单完成”。
