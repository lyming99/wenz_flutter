# 修复默认工具栏布局问题

## 需求概要

反馈 #99 指出默认工具栏存在布局问题。经代码核查，默认桌面工具栏 WenzDefaultDesktopToolbar 的 _DefaultDesktopToolbarLayout 用外层 Row(crossAxisAlignment: CrossAxisAlignment.start) 承载主格式分组（Expanded+Wrap）与尾部分组（无序列表 / 对齐 / 插入），尾部又被包在 Align(AlignmentDirectional.topEnd) 与按手算常量推导的固定宽度 _kTrailingToolbarWidth 的 SizedBox 中。由此产生三类布局缺陷：其一，当主分组在窄宽度下换行为多行时，尾部分组被钉在顶部、与主分组垂直方向错位并留下大片空白；其二，主/尾两个分组按顶部对齐而非居中对齐，行高一旦不一致（换行或加入表格结构按钮、注册表扩展项）中心线即不齐；其三，尾部预留宽度由手算常量推导，新增/删除尾部按钮或分隔符时会与实际内容宽度不同步，造成多余间隙或在极窄宽度下溢出。example 在所有宽度下都挂载该桌面工具栏（_buildEditorColumn 始终调用 buildDefaultDesktopToolbar），因此窄宽度下的换行错位会直接暴露。同属默认工具栏体系、新增的 WenzDefaultMobileToolbar 也需一并审查其主轨道高度/垂直居中与展开面板分节对齐。本次修复统一默认工具栏的主/尾分组垂直对齐、换行不溢出、尾部贴右且宽度跟随内容，并补充对应布局 widget 测试，不改变任何命令、权限置灰与菜单行为。

## 任务拆解

- [x] P001: 重构桌面默认工具栏主/尾分组布局（垂直对齐、换行、尾部宽度跟随内容） <!-- scope: lib/src/widgets/default_desktop_toolbar.dart -->
  - 验收要点：宽宽度单行渲染时，主格式分组与尾部分组（无序列表/对齐/插入）按中心线垂直居中对齐，而不仅是顶部对齐。
  - 验收要点：窄宽度下主分组换行为多行时，尾部分组随工具栏整体居中（或与首行一致对齐），不再浮在顶部留下空白。
  - 验收要点：尾部分组始终贴齐工具栏右端，插入元素按钮距右内边距保持预期 padding。
  - 验收要点：尾部分组的预留宽度由实际内容推导，不再依赖手算常量 _kTrailingToolbarWidth；新增/删除尾部按钮或分隔符后宽度自动跟随，无多余间隙、无被截断。
  - 验收要点：带 preserveWidth 的分隔符仍按预期占位，分隔符显隐不影响尾部按钮间距。
  - 验收要点：极窄宽度下不产生框架溢出异常，主分组可继续换行吸收空间。
  - 验收要点：表格上下文出现的表格结构按钮、注册表扩展按钮加入主分组后，换行与对齐行为保持一致。
