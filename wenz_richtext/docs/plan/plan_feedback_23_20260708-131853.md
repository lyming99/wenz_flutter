# 去除公式默认渲染背景色

## 需求概要

根据反馈 #23，默认公式渲染不再需要背景色。项目中公式包含行内公式 InlineEmbed 和块级 formula BlockEmbedNode 两条默认渲染路径：行内公式当前通过 _InlineFormulaView 和 _defaultInlineEmbedStyle 使用 secondaryContainer 背景，块级公式当前通过 _FormulaBlockView 的卡片背景与预览背景使用 formula/secondaryContainer 背景。计划应移除公式专属背景填充，同时保留数学排版、尺寸占位、点击编辑、语义、选区/组合输入提示以及明暗主题可读性；mention、emoji、普通 inline embed、通用 block embed、引用、表格、callout 等其它背景样式不应被误改。

## 任务拆解

- [x] P001: 去除行内公式默认背景填充 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：行内公式的 _InlineFormulaView 不再绘制 secondaryContainer 或其它底色，普通状态下公式周围没有彩色块、pill 或 chip 背景。
  - 验收要点：_defaultInlineEmbedStyle 中 formula 分支不再设置 backgroundColor，但仍保留必要的前景色、字体和 fallback 文本样式，确保浅色与深色主题下公式可读。
  - 验收要点：组合输入或编辑态需要的下划线、点击打开公式弹窗、Semantics 标签和值、表格单元格内行内公式渲染均保持可用。
  - 验收要点：行内公式占位尺寸、基线对齐、长公式/高公式高度估算、Math.tex 渲染和错误 fallback 不因移除背景而退化。
  - 验收要点：mention 的默认背景、emoji 原样渲染、未知 inline embed fallback、显式 TextAttributes.background 和正文修订/高亮背景不受影响。
- [x] P002: 去除块级公式卡片与预览背景色 <!-- scope: lib/src/widgets/wenz_rich_text_editor.dart -->
  - 验收要点：块级 formula BlockEmbedNode 不再使用 _formulaBlockBackgroundColor 或 secondaryContainer 作为公式卡片底色，默认展示区域不再出现公式专属背景色。
  - 验收要点：块级公式预览 DecoratedBox 不再绘制 secondaryContainer 背景；预览仍保留必要的布局约束、内边距、横向滚动和 display math 渲染。

  - 验收要点：块级公式的选择态、对象块工具栏、复制/删除/移动/编辑入口、点击打开公式弹窗和 Semantics 行为保持不变。
  - 验收要点：通用 BlockEmbedNode、文件块、代码块、callout、引用背景和表格背景继续沿用各自现有主题色，不被本次公式背景调整波及。
